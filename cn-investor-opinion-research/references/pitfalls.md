# 已知陷阱（中国投资人观点研究）

在收集运行前和运行中阅读。每条均在参考案例中造成了真实错误（鲍无可 2024–2026）。

## 1. 继任者归属错误（最危险）
基金季报由*当前*管理该产品的人署名。明星经理离职后，平台（理杏仁、天天基金等）通常仍以知名人物名称展示该产品，但较新的报告由**继任者**撰写（例如鲍无可离开后，邹立虎接管了景顺长城价值驱动）。
- 务必检查报告的署名经理姓名，而非仅看产品名称。
- 如果该人物已离开公募基金，其离职日期之后的所有"季报"均属于他人 — 排除并注明。

## 2. 微信（搜狗）时间过滤填充
`wechat-article-search` / `sogou_search.py` 的 `--time-range` / `--days` 过滤器对冷门姓名不可靠：当近期文章较少时，它经常返回旧文章来填充结果数量。
- 将微信结果视为线索，而非带日期证据。
- 在信任时间窗口之前，先在源页面上验证实际发布日期。

## 3. WebSearch 的 query_keyword_groups 格式
`query_keyword_groups` 必须是一个 JSON **字符串数组**：
`["词组一","词组二","词组三"]`。
格式错误的结构（例如传入字符串而非数组，或括号不匹配）要么报错，要么返回垃圾数据并浪费一次调用。请将其构建为干净的数组。

## 4. "无报告" ≠ "无数据" — 重建计划，不要停滞
对于转投私募的经理，基金报告从公众视野中消失。不要报告"未找到任何内容"。重新聚焦于路演实录/访谈/媒体，并将缺口记录为边界（"私募运作报告依法不公开"），而非失败。

## 5. 饱和度 vs. 真实缺口
新搜索仅返回已捕获信源的转载/衍生品 = 饱和度（停止）。但静默窗口（例如"7-8 月无新增发声"）必须明确声明为有记录的边界，而非假设。

## 停止信号（全部满足方可结束）
1. 饱和度 — 新角度命中相同的核心信源。
2. 层级覆盖 — 每个要求的层级至少有一个代表性信源。
3. 时间线闭合 — 要求的时间窗口连续，无未解释的缺口。
4. 明确边界 — 不可查找的内容已记录（私募报告不公开、静默月份、继任者报告已排除）。
