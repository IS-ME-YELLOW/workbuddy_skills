# Reliability grading rubric (cn-investor-opinion-research)

Grade every captured source before archiving. Tier drives filename prefix and
how freely the content may be quoted.

## Tier A — First-hand / self-stated (highest)
- Fund **定期报告经理展望** (季报/中报/年报 "管理人对市场展望" section), signed
  by the manager. Only exists while the person is at a public-fund house.
- **持牌机构官方路演纪要** (e.g. 中金财富《云会客厅》official transcript).
- **本人署名文章 / 公开信**.
- Usage: quote verbatim, treat as ground truth for that person's view.

## Tier B — Verbatim transcript
- Long-form dialogue **全文实录** (e.g. 聪明投资者 80-minute Q&A), even if
  published by a media outlet, because it preserves the person's own words
  turn-by-turn.
- Usage: quote verbatim; slightly below A only because it is edited/re-hosted.

## Tier C — Authoritative media
- Reporter-written pieces from 新华社系、中国证券报、财联社、中国基金报、钛媒体、
  东方财富、21 世纪经济报道, etc.
- These **quote** the person but the framing is the journalist's.
- Usage: extract the quoted passages as if A; treat surrounding analysis as C.

## Tier D — Social / second-hand interpretation
- 雪球 posts, 公众号 personal essays, 大智慧/同花顺 commentary that
  **interprets** the manager (e.g. "鲍无可靠安全边际跑赢98%同行").
- Usage: archive for context ONLY. Clearly tag which sentences are the person's
  own words vs the author's interpretation. Never present D-tier framing as the
  person's stated view.

## Worked example (鲍无可, 2024–2026)
- A: 2024Q1–Q4 + 2025Q1 景顺长城季报展望; 中金财富云会客厅官方纪要 (2026).
- B: 聪明投资者 80 分钟逐字实录 (2026).
- C: 中国证券报、钛媒体 2024-03 专访、东方财富 2024-11 三季报解读.
- D: 雪球 2024-07 深度、大智慧 2026 产品评论.

## Cross-year view-evolution note
When the window spans years, explicitly trace how a thesis evolved (e.g.
"出海" first appeared in 2024Q4 季报, re-emphasized in 2026 对话 → consistent;
"AI 谨慎" stated 2025Q1, quantified 2026 → consistent). This is the highest-value
output of a multi-year collection.
