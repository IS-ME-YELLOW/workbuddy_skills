# 刘富兵 · 国盛证券金融工程分析框架

本技能将国盛证券研究所副所长、金融工程首席分析师刘富兵的量化研究框架蒸馏为可执行的择时/配置/选品决策体系。
定位：**先择时（价格分段 + 六面图 + 宏观周期）→ 再配置（行业/风格/转债）→ 后选品（多因子/FOF）**。

## 使用流程（按顺序执行）

1. **读取最新观点**：先打开 `references/views.md` 顶部，确认刘富兵/国盛金工当前最新观点（截至日期）与机构归属。观点是时效的，勿直接使用历史快照。
2. **择时与仓位（第一层）**：运行 `scripts/screen.py`，计算价格分段择时（S1）与六面图综合分（S2）；再检查 LPPL 极端拐点（S3）与宏观六周期偏离/景气情绪（S4/S5）。计算规则与阈值详见 `references/decision-rules.md`。
3. **收益与风险预算（第一层·补）**：看 GK 模型预期收益与 ERP 分位（S6），决定权益风险预算。
4. **行业与风格配置（第二层）**：看行业轮动右侧/左侧象限（S7）、RS 主线（S8）与风格三维图谱（S9）。
5. **转债与基金（第三层）**：看转债定价偏离度轮动（S10）输出转债仓位；多因子指增与 FOF 选基规则见 `references/framework.md` 第三层，用 `westock-tool` 辅助筛选。
6. **输出规范**：所有观点引用必须注明日期（如"刘富兵（国盛证券金融工程）2026-08 观点"）；信号与观点冲突时优先遵循信号并说明分歧；参数来源标注（✅原文/⚠️外推/❌推断）必须保留。

## 数据获取

- 择时类（价格分段、六面图技术/拥挤度维度）：无公开 API 直连，用指数行情+MACD 分段工程代理（❌），`_meta` 标注降级。
- 宏观类（六周期：基钦/朱格拉/库兹涅茨/康波等、美元流动性、社融/M1/CPI/PPI）：用 `westock-data` 或 `neodata-financial-search` 查询宏观数据，计算周期偏离与景气指数。
- 估值类（席勒 ERP、PB、AIAE）：westock-data 查询指数估值。
- 行业类（行业动量、景气度、分析师预期、RS 指标）：westock-data + westock-tool 查询。
- 转债类（CCB/CCBA 定价偏离度）：无公开 API 直连，用转债指数相对理论价值工程代理（❌）。
- 个股/行业筛选：用 `westock-tool` 按 screen.py 输出的行业/风格方向做筛选。
- 指标口径、频率、所属框架详见 `references/indicators.md`。

## 脚本使用

```bash
python scripts/screen.py                  # 演示模式（内置合成数据，验证流程）
python scripts/screen.py --schema         # 查看输入数据契约（先跑这个）
python scripts/screen.py --data macro.json   # 用真实数据计算信号
python scripts/screen.py --data macro.json --json-out  # 输出机器可读 JSON
```

- **输入契约**：运行 `python scripts/screen.py --schema` 获取字段清单，按 required 字段准备数据（字段→月份数组，最新在末尾）。除调试外不要读取脚本源码。
- 信号 S1-S10 编号为**工程化设计**（刘富兵没有此编号体系），底层阈值来源见 `references/decision-rules.md` 各规则标注。

## 红线与注意事项

- 本技能输出为分析参考，非投资建议；量化框架历史表现不代表未来。
- 观点与规则分离：`references/views.md` 是时效快照（**观点时间线/口径校准层，不参与信号计算**），`references/` 是方法论，勿混用；信号基于 ✅ 原文规则 + 最新数据优先，观点冲突时输出分歧说明。
- **机构归属红线**：刘富兵任职国盛证券研究所（副所长/金融工程首席分析师）；引用观点须标注任职期归属，如发生离职/跳槽，其观点归属以任职期为准，禁止混用。
- **推断参数**：均线窗口 30/120/250、六面图综合分阈值 ±0.2、LPPL 偏离阈值 ±15%、周期偏离阈值 ≥2、ERP 分位 80/20 等均为 ❌ 推断最小假设，非分析师公布值，拿到真实参数应替换。
- **数据口径**：不同数据源绝对水平可能背离（如六面图综合分、ERP 绝对水平），仅分位/方向可用时不得跨口径比较绝对阈值；见 `_meta` 与 validation.md 标注。
- 时间窗口 2023.9-2026.8 内的方法论与观点为本技能知识边界；窗口外内容需另行检索核验。
- A 股惯例：涨红跌绿，货币符号用 ¥。
