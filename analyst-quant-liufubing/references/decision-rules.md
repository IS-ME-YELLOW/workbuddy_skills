# 刘富兵决策规则（decision-rules.md）

> 来源标注：✅ 原文 / ⚠️ 外推 / ❌ 推断（最小假设，可替换）。回测数字加 ~ 并注明"取自公开报告，以原文为准"。
> 本文件为可执行推理程序；时点观点一律见 views.md，不进规则区。
> 信号工程化编号（S1-S10）系本技能设计，对应 framework.md F1-F10。

## 规则 0：信号分级与总原则

- **信号强度**：`strong` = 规则基于 ✅ 原文阈值/框架且数据 ✅ 直连；`mid` = 规则框架 ✅ 但关键参数 ❌ 推断；`direction` = 仅方向性参考。
- **操作映射**（❌ 仓位比例为最小假设，可替换）：
  - strong 看多（如 S1 日线上涨确认 + 浪 1-3 结构）：权益超配档；
  - 综合中性（六面图 |score|<0.2 ❌）：标配档；
  - strong 看空/拐点预警（S3 正泡沫、S1 全面下跌确认）：减配档/防御。
- **输出顺序**：先读 views.md 最新观点校准，再运行 S1→S10，最后输出"信号+观点对照+分歧说明"。
- **观点冲突处理**：基于 ✅ 原文规则+最新真实数据的高置信信号优先并说明；依赖 ❌ 推断参数的信号不得机械压过 views.md，标"低置信分歧"。

## S1 价格分段择时（对应 F1）

- **触发条件**：任意主要指数价格序列可用。
- **计算步骤**：① 计算 30/120/250 日均线（❌ 窗口推断，代理 30分钟/日线/周线级别）；② 均线多头排列=该级别上涨、空头=下跌（❌ 推断）；③ 对价格做分段计数（同向运行段数量=浪结构代理 ❌）；④ 距 250 日高点回撤与分段数合成结束概率（❌ 推断）。
- **量化阈值**：250 日均线上方且 30>120>250 = 日线级别上涨（✅ 概念，❌ 实现）；浪数 1-3 = 趋势早期；≥7 = 临近尾声（⚠️ 原文案例归纳）；结束概率 >80% = 拐点临近（❌ 推断）。
- **信号输出**：`看多（趋势早期）/ 看多但临近尾声 / 中性 / 看空（下跌确认）/ 看空但接近拐点`。

## S2 择时雷达六面图（对应 F2）

- **触发条件**：六维度子信号字段齐全（I-07~I-21）。
- **计算步骤**：① 每维度内子信号（看多=+1/中性=0/看空=-1，❌ 赋分推断）等权平均；② 六维度等权合成综合分（❌ 等权最小假设）；③ 分档输出。
- **量化阈值**：综合分 >0.2 = 看多；<-0.2 = 看空；其间 = 中性（✅ 原文区间 [-1,1]，❌ 分档阈值）。
- **信号输出**：`看多 / 中性偏多 / 中性 / 中性偏空 / 看空` + 六维分数明细。

## S3 LPPL 极端拐点（对应 F3）

- **触发条件**：指数价格序列可用。
- **计算步骤**：① 价格偏离 12 月均线的倍数（❌ 代理 LPPLS 拟合强度）；② 偏离进入极端区且出现加速（二阶差分放大）→ 泡沫强度升高。
- **量化阈值**：偏离 >+15%（❌ 推断）= 正泡沫见顶预警；偏离 <-15%（❌ 推断）= 负泡沫抄底参照；阈值随极端态分级（极端/非极端 ⚠️）。
- **信号输出**：`正泡沫预警（减仓锁定）/ 负泡沫触发（分批抄底）/ 无极端信号`。

## S4 宏观六周期与偏离度（对应 F4）

- **触发条件**：cycle_real、cycle_implied（阶段 1-6）可用。
- **计算步骤**：① 偏离 = cycle_implied - cycle_real；② 结合阶段属性（扩张/退潮类，✅ 原文命名）判断"预期收缩/扩张"。
- **量化阈值**：隐含周期滞后真实周期（偏离为负且真实处扩张类）且 |偏离|≥2（❌ 推断）= 预期收缩+高偏离 → 看多风险资产（✅ 2026-07-17 案例）；同周期=低偏离 → 信号中性偏空（✅ 2026-07-03 案例）。
- **信号输出**：`看多风险资产 / 中性 / 看空风险资产`。

## S5 A股景气与情绪指数（对应 F4）

- **触发条件**：a_share_prosperity、a_share_sentiment 可用。
- **计算步骤**：① 景气指数 26 周趋势（上升=盈利周期向上，✅ 原文）；② 情绪综合信号（见底多+见顶空=多，✅ 原文）。
- **量化阈值**：景气上升周期=顺风（绝对阈值 ❌）；情绪综合=多/空/中性（✅ 原文三态）。
- **信号输出**：`景气向上+情绪多 = 强顺风 / 景气向下+情绪空 = 逆风 / 其余中性`。

## S6 GK 模型预期收益与 ERP（对应 F5）

- **触发条件**：erp_q（宽基 ERP 分位）、gk_exp_ret（未来一年预期收益）可用。
- **计算步骤**：① ERP 分位衡量估值性价比（✅ 原文战略配置篇）；② GK 预期收益横向比价（✅ 原文 2021 报告）。
- **量化阈值**：erp_q >80%（❌ 推断）= 高性价比超配；<20%（❌ 推断）= 低性价比减配；gk_exp_ret<0 = 回避该资产（⚠️ 原文 2021 案例）。
- **信号输出**：`超配权益 / 标配 / 减配权益` + 各资产预期收益比价。

## S7 行业轮动：右侧景气趋势 + 左侧困境反转（对应 F6）

- **触发条件**：行业趋势/景气度/拥挤度三维数据可用。
- **计算步骤**：① 右侧：三维打分（趋势-景气度-拥挤度，✅ 原文框架）；强趋势+低拥挤 = 加仓象限；② 左侧：库存周期见底+景气拐点（❌ 代理）→ 困境反转候选。
- **量化阈值**：趋势 z>0.5 且拥挤度分位 <50（❌ 推断）= 右侧买入象限（⚠️ 原文"强趋势+低拥挤"）；库存去化充分行业（钢铁/电子/化工等案例 ✅ 原文 2024-01）。
- **信号输出**：`右侧推荐行业清单 / 左侧反转候选清单 / 高拥挤减配提示`。

## S8 行业 RS 年度主线与共振（对应 F6）

- **触发条件**：行业 RS 指标可计算（相对强弱，✅ 原文《如何寻找当年的领涨行业》）。
- **计算步骤**：① 每年 4 月底更新 RS（❌ 计算口径代理）；② RS>90 行业=年度主线候选；③ 与 S7 持仓取交集=共振增强（✅ 原文 2011 以来年化超额 ~19.1%）。
- **量化阈值**：RS>90（✅ 原文）；共振行业加仓（✅ 原文"历史上有更大概率成为当年领涨行业"）。
- **信号输出**：`RS>90 主线候选清单 / 与轮动模型共振行业（重点配置）`。

## S9 风格赔率-趋势-拥挤度图谱（对应 F7）

- **触发条件**：风格因子三维数据（质量/成长/红利/小盘等）。
- **计算步骤**：① 每风格因子算赔率（估值分位倒置 ❌）/趋势（动量 ❌）/拥挤度（换手分位 ❌）；② 三维合成排名（✅ 原文图谱方法）。
- **量化阈值**：高赔率+强趋势+低拥挤 = 超配；低赔率+高拥挤 = 减配（⚠️ 原文 2024-07 图谱：小盘超高拥挤→减配；质量超低拥挤→超配大盘质量）。
- **信号输出**：`风格排名：质量/成长/红利/小盘 → 超配风格`。

## S10 转债定价偏离度轮动（对应 F8）

- **触发条件**：转债定价偏离度（cb_dev）可计算。
- **计算步骤**：① Z = 偏离度 / 过去 3 年标准差，±1.5σ 截尾（✅ 原文公式）；② 分数 = Z / (-1.5)；③ 转债权重 = 50% + 50%×分数（✅ 原文）。
- **量化阈值**：Z 高分位（偏离度处 2018 以来 >90% 分位 ⚠️）= 转债仓位信号为 0（✅ 2026-08 案例）；低分位 = 超配转债。
- **信号输出**：`转债仓位 0-100% / 转债 vs 股债组合轮动建议`。
