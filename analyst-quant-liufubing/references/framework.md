## 〇、框架总览（按方法论主体分层）

刘富兵的体系以"**价格分段 → 级别 → 结构**"的择时理论为枢纽，向上接宏观（六周期/景气情绪/海外流动性），向下接行业与风格（趋势-景气度-拥挤度、赔率-趋势-拥挤度），并延伸到转债定价与 FOF 选基，形成"择时—配置—选品"三层递进的量化闭环：

| 层 | 框架 | 一句话定位 |
|---|---|---|
| 第一层 择时 | F1 价格分段择时体系（级别×浪结构） | 30分钟/日线/周线级别确认+浪结构位置，判断趋势阶段与拐点 |
| 第一层 择时 | F2 择时雷达六面图 | 六维度 21 指标综合打分 [-1,1]，总量择时 |
| 第一层 择时 | F3 LPPL 趋势与极端拐点 | 金融物理学泡沫/崩盘预警，极端态抄底与见顶 |
| 第一层 择时 | F4 宏观与大类资产择时 | 经济六周期+宏观偏离度+美元流动性+A股景气/情绪指数 |
| 第二层 配置 | F5 GK 模型收益预测（股债性价比） | 收益三分解，未来一年预期收益横向比价 |
| 第二层 配置 | F6 行业配置体系 | 右侧景气趋势+左侧困境反转+RS 年度主线+共振增强 |
| 第二层 配置 | F7 风格配置：赔率-趋势-拥挤度图谱 | 质量/成长/红利/小盘因子三维打分与排名 |
| 第二层 配置 | F8 转债定价与轮动 | CCB 定价偏离度+转债&股债组合轮动 |

## F1 价格分段择时体系（核心辨识度）

- **定义**：以 MACD 分段模型（✅ 原文，刘富兵 2017 年国泰君安时期起迭代）对指数价格做分段，识别**级别**（30分钟/日线/周线）与**浪结构**（1浪/3浪/5浪/7浪/9-15浪），判断趋势所处阶段与拐点。
- **逻辑**：市场走势由嵌套的多级别分段构成；级别越高、浪结构越完整，趋势结束概率越高；"日线上涨只走 1 浪 → 短期结束概率低"，"周线下跌走完 3 浪/11 浪 → 结构基本完整"。
- **应用**：每周《量化周报》对主要指数与 28 个中信一级行业输出：①是否确认某级别上涨/下跌；②已走浪数；③上涨/下跌结束概率（短中期观点）。示例（均为 ✅ 原文观点）：
  - 2024-10-27："日线级别上涨并未结束，所有规模指数日线上涨只走了 1 浪结构，上涨结束概率平均不足 15%；26 个行业处于日线上涨中，其中 22 个只走了 1-3 浪"；"上证周线下跌已走完 3 浪，上证50/沪深300 周线下跌走完 11 浪；2024-01 底+2024-09 上旬构成双底"。
  - 2025-11-07："本轮日线上涨自 4 月 7 日以来持续 6 个多月、幅度约 30%，超 2/3 行业超涨，半数以上指数走出 9-15 浪复杂结构 → 本轮日线上涨临近尾声；中期周线级别上涨日线仅 3 浪，牛市刚刚开始"。
  - 2026-07-19："上证指数全周 -5.81%，规模指数全面确认日线级别下跌；28 个行业中 24 个日线下跌、17 个周线下跌；中证500/深证100/通信日线下跌只走 1 浪、科创50 未确认 → 调整不充分，短暂反抽后大概率再次探底"。
- **窗口内实例**：见 views.md 观点链（2024-01 双底 → 2025 牛市上半场 → 2026-05 提防冲高回落 → 2026-07 全面确认日线下跌 → 2026-08 30分钟级别调整）。
- **工程化要点**：MACD 分段参数（快/慢线窗口、分段合并规则）未公开，screen.py 用收盘价均线动量 + 分段计数代理（❌ 最小假设，可替换）。

## F2 择时雷达六面图

- **定义**：从**流动性/经济面/估值面/资金面/技术面/拥挤度**六个维度选取 21 个指标（✅ 原文口径），概括为"估值性价比/宏观基本面/资金&趋势/拥挤度&反转"四大类，生成 [-1,1] 综合择时分数（✅ 原文：2026 年报告为 [-1,1]；2024 年报告为 [-5,5]，区间口径曾有调整 ⚠️）。
- **逻辑**：权益表现受多维度共同影响，单指标易误判，六面图取各维度观点等权（❌ 等权为最小假设）合成。
- **应用**：综合分 > 0 偏多 / < 0 偏空 / 接近 0 中性（分档阈值 ❌ 推断）；每周更新。示例（✅ 原文）：2024-10-26 综合 1.04 看多；2026-05-23 综合 -0.12 中性（流动性 -0.25 / 经济 0.00 / 估值 -0.17 / 资金 0.00 / 技术 -0.50 / 拥挤 0.00）；2026-08-22 综合 -0.12 中性。
- **21 指标清单（✅ 原文口径，来自 2026-08-22 报告目录）**：
  - 流动性：货币方向因子、货币强度因子、信用方向因子、信用强度因子（4）
  - 经济面：增长方向、增长强度、通胀方向、通胀强度（4）
  - 估值面：席勒ERP、PB、AIAE（3）
  - 资金面：两融增量、成交额趋势（内资）；中国主权CDS利差、海外风险厌恶指数（外资）（4）
  - 技术面：价格趋势、新高新低数（2）
  - 拥挤度：期权隐含升贴水、期权VIX、期权SKEW、可转债定价偏离度（4）

## F3 LPPL 趋势与极端拐点

- **定义**：对数周期性幂律模型（Log-Periodic Power Law），源于金融物理学（Sornette），2012 年由刘富兵引入 A 股（✅ 原文）。
- **逻辑**：股市泡沫形成与破裂类似复杂系统"自组织临界性"（沙堆模型）；价格在对数周期幂律加速上升中逼近临界点，可预警顶部；反向用于负泡沫抄底。
- **应用**：成功案例（✅ 原文表述）：2008 石油泡沫与房地产泡沫、2009 年 A 股大盘、2015 年创业板等顶部预判；2012 年后多次预测 A 股顶部与底部；2024-02 流动性危机后低点被列为负泡沫抄底参照（郑兆磊蒸馏中亦引用此案，本技能独立标注）。
- **工程化要点**：LPPLS 拟合参数（m/ω/φ、阈值）未逐字公开，screen.py 用价格偏离均线倍数代理泡沫强度（❌ 最小假设，可替换）。

## F4 宏观与大类资产择时

- **定义**：一组宏观刻度指标：**经济六周期**（阶段1-6，含"货币扩张/货币退潮"等，✅ 原文命名）+**宏观偏离度**（真实周期 vs 资产隐含周期）、**美元流动性指数**、**海外情绪指标**（花旗风险厌恶指数、中国主权CDS利差）、**A股景气指数**、**A股情绪指数**（见底/见顶信号）。
- **逻辑**：真实周期与资产隐含周期之差反映市场预期方向（"预期收缩+高偏离 → 信号看多风险资产"）；景气指数定位盈利周期位置；情绪指数捕捉见底/见顶极端态。
- **应用**：示例（✅ 原文）：2026-07-17 真实周期=阶段6-货币扩张、资产隐含周期=阶段3-货币退潮 → 预期收缩+高偏离 → 看多风险资产；2026-07-03 双周期均阶段6 → 低偏离 → 看空风险资产；A股景气指数 2026-01-30 为 18.12（较 2023 年底 +12.69），2025-11-07 为 20.91，2026-07 为 21.42；A股情绪指数 2026-01-30 见底信号多、见顶信号空、综合多。
- **工程化要点**：六周期判定与偏离度算法未公开，screen.py 用货币/信用/增长代理变量近似（❌ 最小假设）。

## F5 GK 模型收益预测（股债性价比）

- **定义**：Grinold-Kroner 单期股权收益分解：股权名义收益 = 股息收益（Income）+ 名义盈利增长（Nominal Earning Growth）+ 重新定价（Repricing），即 `R ≈ D/P + (i+g) + ΔPE`（✅ 原文，2021《为什么我们相对看好中证500》）。
- **逻辑**：A 股为估值主导市场（沪深300 波动中估值波动占主要地位），美股为盈利主导市场（盈利波动占比近 80%，✅ 原文 2021 演讲）；长期看 A 股将向盈利驱动靠拢 → 收益预测应拆分驱动项。
- **应用**：对各宽基/资产输出"未来一年预期收益"，横向比价（2021-03 案例：上证50/沪深300/可转债预期收益转负、中证500 仍有 ~7.5% 预期回报 ✅ 原文）；月度《量化点评报告》战略配置篇使用（含转债、短久期/长久期国债预期收益）。
- **工程化要点**：盈利增速与估值变化率预测值需宏观情景假设（❌ 推断），screen.py 用股息率+盈利增速代理+ERP 分位替代 ΔPE。

## F6 行业配置体系（基本面量化系列）

- **定义**：三件套（✅ 原文，基本面量化系列）：
  1. **右侧景气趋势模型**：趋势-景气度-拥挤度三维评价，输出行业配置；
  2. **左侧困境反转模型**：库存去化充分+景气底部反转行业；
  3. **行业相对强弱 RS 指标**：每年 4 月底更新，RS>90 行业为年度主线候选（✅ 原文阈值）。
- **逻辑**："强趋势+低拥挤"代表聪明钱看好且未透支；轮动模型与主线模型共振时更大概率成为当年领涨行业（✅ 原文）。
- **应用与回测**（✅ 原文数字，加 ~）：
  - 右侧景气趋势模型 2023 绝对 ~4%、相对 Wind全A ~9%；2024H1 绝对 ~1.7%、超额 ~9.7%；叠加 PB-ROE 选股 2024H1 绝对 ~9.2%、超额 ~17.2%；
  - 左侧困境反转模型 2023 绝对 ~5%、相对中证800 ~16%；
  - "强趋势+低拥挤"轮动策略 2011 以来年化超额 ~13.2%、2023 ~12.8%；
  - RS 指标：涨幅前 10 行业平均 6.3 个出现信号；2023 信号后等权持有至年底相对中证800 超额 ~6%；
  - 轮动+主线取交集增强 2011 以来年化超额 ~19.1%（较原始轮动提升 ~5.9%）。
- **窗口内观点**：2024-01 右侧配置稳定高股息（电力/农林牧渔/交运/家电/石油石化/煤炭/钢铁/银行）+左侧"红利+成长"均衡（钢铁/电子/化工/农林牧渔/家电/汽车）；2024-04/07 主线"高股息+资源品+出海+AI"，RS>90 行业为煤炭/农林牧渔/电力公用/家电/银行/石油石化/通信/有色/汽车。
- **工程化要点**：景气度=盈利/库存代理，拥挤度=换手率分位（❌ 推断），趋势=价格动量。

## F7 风格配置：赔率-趋势-拥挤度图谱

- **定义**：对风格因子（质量/成长/红利/小盘等）从**赔率、趋势、拥挤度**三维打分，形成图谱与综合排名（✅ 原文，《七月配置建议：超配大盘质量》2024-07）。
- **逻辑**：高赔率+强趋势+低拥挤 = 可超配；低赔率+强趋势+高拥挤 = 减配/警惕。
- **应用**：2024-07 图谱（✅ 原文）：质量=高赔率-中等趋势-超低拥挤；成长=高赔率-中等趋势-低拥挤；红利=低赔率-强趋势-低拥挤；小盘=中等赔率-中等趋势-超高拥挤 → 结论"超配大盘质量、风格切向质量成长"。
- **工程化要点**：赔率=估值分位倒置，趋势=动量，拥挤度=换手/成交额分位（❌ 推断）。

## F8 转债定价与轮动

- **定义**：CCB/CCBA 可转债定价模型（含退市风险修正）+**定价偏离度**（转债价格/模型定价-1）衡量估值水平（✅ 原文，《可转债的赎回概率调整定价模型》《可转债定价模型与应用》）。
- **逻辑**：偏离度处于历史高分位 → 估值贵、转债相对股债组合性价比低 → 低配转债；反之超配。
- **应用**：转债&股债组合轮动（Z 值 = 偏离度/3 年标准差，±1.5σ 截尾，转债权重 = 50%+50%×分数，✅ 原文）；月度《可转债策略跟踪》输出六类策略：低估值/低估值+强动量/低估值+高换手/平衡偏债增强/信用债替代/波动率控制（✅ 原文）。
- **窗口内实例**：2026-07 急跌中转债估值被动拉升至历史极值（偏离度 17.3%），2026-08 主动压缩至 12.3%（仍处 2018 以来 ~96% 分位）→ 转债中性偏谨慎（✅ 原文 2026-08 月报）。
- **工程化要点**：CCB 定价需转债条款与利率曲线，screen.py 用转股溢价率+债底利差代理偏离度（❌ 推断）。

## F9 多因子体系与指数增强

- **定义**：多因子研究三方向（✅ 原文 2021 复旦演讲）：**因子挖掘 / 因子配权算法 / 因子再探索**；落地为国盛特色量价指增组合（300/500/1000 增强）。
- **应用与回测**（✅ 原文，加 ~）：2018 年以来年化超额沪深300增强 ~15.52%、中证500增强 ~18.40%、中证1000增强 ~27.16%；2026-07 一周 1000 增强超额 ~3.44%。
- **工程化要点**：量价因子明细未公开，screen.py 以动量/换手/波动率代理（❌ 推断）。

## F10 FOF 选基体系

- **定义**：量化 FOF 配置体系，深度研究基金持仓风格、特征与能力评估（✅ 原文）；"选基因子"系列（2026-06《基金经理能力圈：广度、稀缺度与标签化选基》）与多因子选基FOF组合。
- **应用与回测**（✅ 原文，加 ~）：多因子选基FOF组合年化 ~18.01%、相对偏股混合基金指数年化超额 ~7.57%（2026 年初以来超额 ~8.45%）。
- **工程化要点**：需基金持仓明细，screen.py 不落地（标注数据不可得，仅研究参考）。
