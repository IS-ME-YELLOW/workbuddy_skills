## 一、使用流程（先观点时效 → 再定价内核 → 再债市坐标 → 后策略落地）

1. **先读 `references/views.md` 顶部最新观点快照**（观点时效性第一原则：任何输出前核对最新观点，过期观点不得当作当前判断）
2. **定价内核定位**：大类资产统一三维框架（流动性 + 风险偏好 + 机构行为）+ 货币-信用四象限（framework.md 框架 1-2）
3. **债市坐标判断**：流动性框架（宽松类型识别）+ 资金面生命线 + 利率锚定 + 机构行为（框架 3-6）
4. **债牛长逻辑校验**：经济动能转换 + 票息资产稀缺化与理财净值化（框架 7-8）
5. **策略落地**：纯债行情三分 + 债基指数轮动 + 月度节奏三阶段 + 政策事件驱动（框架 9-12）
6. **运行信号**：`scripts/screen.py`（S1-S13 信号，见下）

## 三、数据获取

- **westock-data**：国债收益率（10Y、30Y、1Y）、DR001/DR007/R007、1Y AAA 存单利率、MLF/OMO 政策利率、信用利差、社融、M1/M2、PPI/CPI、分机构二级净买入、政府债净融资、非银存款
- **westock-tool / neodata-financial-search**：自然语言查询宏观与固收指标、转债估值（YTM/平价/隐含波动率）、理财申赎数据
- 平台降级方案见 analyst-distill `references/domain-adapters.md` §三（数据源不可用时如实标注，不得伪造数据）
- `screen.py --data` 输入字段清单（必需）：dr007 / r007 / omo7d / mlf / c10y / c1y / c30y / credit_spread / sf_yoy / fund_netbuy / bank_netbuy / nonbank_deposit；extras：month / day / credit_loose / policy_loose / deposit_pact / wealth_nav / wealth_redraw / supply_slow / ccy_pressure / cbg_net_issue
- 详细指标口径见 `references/indicators.md`（I-01 至 I-29）

## 四、脚本使用

```bash
python scripts/screen.py                            # 演示模式（合成数据，验证流程）
python scripts/screen.py --data data.json           # 真实数据（月度字段→数组，最新在末尾）
python scripts/screen.py --data data.json --json-out  # stdout 输出 JSON（--json-out 为布尔标志）
python scripts/screen.py --schema                   # 输出输入契约（布尔标志）
```

S 信号（工程化编号系本技能设计，非刘郁本人编号）：S1 货币-信用四象限｜S2/S3/S4 纯债行情三分｜S5 资金宽松类型｜S6 资金面生命线｜S7 利率锚上沿｜S8 利率锚下沿｜S9 交易盘转买｜S10 交易盘止盈｜S11 存款自律/非银存款｜S12 理财净值化赎回｜S13 月度节奏。阈值来源分级（✅原文/⚠️外推/❌推断）见 `references/decision-rules.md` 与脚本参数区。

## 五、红线与注意事项

1. **观点时效性**：任何输出先读 views.md 最新快照；年度点位区间每年随年度策略/中期策略强制更新（不可静态使用历史区间）。
2. **机构归属**：刘郁 2023.8-2024.2 任职广发证券、2024.3-2026.4 任职华西证券、2026.4 后任职兴业证券（拟任）；引用观点必须标注"截至 {日期} 刘郁（{任职机构}）观点"。**禁止把华西时期观点与兴业时期观点混用。**
3. **禁止虚假精确**：一切阈值/权重/参数带来源标注；❌ 推断值（振幅带宽、净买入阈值、分档等）为最小假设可替换，不得冒充原文。
4. **观点与规则分离**：信号计算不依赖观点快照；冲突时优先遵循信号并说明分歧。
5. **分析师独立性**：本技能仅含刘郁本人框架与观点，不与其他分析师对比。
6. **A股/债市惯例**：涨红跌绿、货币 ¥；债券收益率上行 = 债市走弱（价格反比）。
7. 本技能输出为分析参考，非投资建议。
