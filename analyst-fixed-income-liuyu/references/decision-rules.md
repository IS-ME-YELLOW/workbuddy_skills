# 刘郁债市投资决策规则（decision-rules.md）

> 本文件将刘郁框架转化为**可执行的规则**：信号触发条件 → 动作。
> Phase 3 的 `scripts/screen.py` 依据本文件实现。
> 数据源：westock-data / neodata-financial-search 可查询债券行情、宏观、资金面指标。

---

## 来源标注图例（全文件适用）

| 标记 | 含义 |
|---|---|
| ✅ 原文 | 刘郁公开研究/报告中**明确给出**的数值、口径或约定（注明出处/时间） |
| ⚠️ 外推 | 有公开依据（口径/方向明确），但**具体数值/分档未经逐字核对**，属合理近似，使用时按原文复核 |
| ❌ 推断 | 刘郁**未公布**，为实现"可脚本化"而作的假设（最小假设），拿到真实值应替换 |

## 规则 0：信号分级与总原则

- **强信号**（改变久期中枢/大类配置）：货币-信用四象限定位（规则 1）、资金面生命线转向（规则 4）、利率锚极值（规则 5）、经济动能转换阶段（规则 7）
- **中信号**（杠杆/结构/品种调整）：资金宽松类型识别（规则 3）、机构行为切换（规则 6）、理财净值化/存款自律（规则 8）、月度节奏阶段（规则 10）
- **弱信号**（战术节奏/品种轮动）：纯债行情三分（规则 2）、季节性规律（规则 11）、政策事件驱动（规则 12）
- 总原则（✅ 原文）：
  1. **资金面是债市生命线**——"资金不紧，债市不熊"（⚠️ 格言化表述，方向 ✅）；
  2. **大类资产统一于"流动性、风险偏好、机构行为"**（✅ 2025.8.30）；
  3. **"宽货币"主线**：货币政策适度宽松下债牛延续，单次降准降息仍存加力空间（✅ 2025.1）；
  4. **趋势性判断看资金与融资需求，节奏性判断看机构行为与政策预期差**（✅ 综合）。

## 规则 1：货币-信用四象限定位（大类配置总开关 ✅ 原文回测规则）

### 1.1 指标定义

- **货币维度**：R007/DR007 走势、降准降息、央行净投放（货币趋松/趋紧）；
- **信用维度**：社融同比增速方向（信用趋宽/趋紧）。

### 1.2 计算步骤（月度更新）

1. 计算 R007 20 日均值方向（环比下行 = 趋松）与 OMO/MLF 政策利率变化；
2. 计算社融同比增速方向（同比上行 = 趋宽）；
3. 判定四象限。

### 1.3 信号输出（✅ 回测数据，❌ 分档阈值）

| 象限 | 回测特征（✅ 原文） | 动作 |
|---|---|---|
| 货币趋松 & 信用趋宽 | 年化 6.31%、胜率 56.93% 最优 | **转债+权益进攻**（"配置转债较为理想" ✅） |
| 货币趋紧 & 信用趋宽 | 波动率 13.66% 最低、收益承压 | 纯债防御，转债/权益低配 |
| 货币趋紧 & 信用趋紧 | 回撤 8.84% 最小、大盘占优 | 纯债为主，短久期防御 |
| 货币趋松 & 信用趋紧 | 趋弱周期 | 控制仓位，票息策略 |

## 规则 2：纯债行情三分（品种选择 ✅ 原文）

- **触发条件（可计算）**：纯债行情状态判断——走强 / 盘整 / 回调。
- **量化代理**（❌ 推断，可替换）：以 10Y 国债 20 日均线方向 + 月内振幅判断：
  - 20 日均线持续下行且振幅 < 40BP（❌）= 走强；
  - 均线走平 = 盘整；
  - 20 日均线拐头向上且振幅 > 40BP（❌）= 回调。
- **信号输出**（✅ 原文映射）：

| 行情状态 | 占优品种（✅） |
|---|---|
| 走强 | **超长期利率债**（攫取债牛收益） |
| 盘整 | **3-5 年信用债**（性价比） |
| 回调 | **短久期利率债**（防御） |

## 规则 3：资金宽松类型识别（资金面持续性信号 ✅ 原文）

- **触发条件（可计算/可判断）**（✅ 2026.4.21《流动性框架之三》）：
  - **类型一（事件扰动型）**：特殊事件（地缘/疫情/违约）触发央行主动呵护 → 宽松持续时间短；
  - **类型二（动能缺失型）**：信贷需求不足、资金淤积、央行被动维持 → 持续时间长。
- **识别方法**（❌ 推断工程化）：
  - 若触发因素为事件且央行主动投放 → 类型一；
  - 若信贷需求弱（票据利率低、信贷开门红成色不足）+ 政府债发行慢 → 类型二。
- **信号输出**：
  - 类型二确认 → **加杠杆套息安全边际高**，资金面宽松延续；
  - 类型二终结触发（政府债发行放量 / 信贷需求回升 / 稳汇率迫切性上升）→ **提前降杠杆**；工程化上采用"供给放量 **且**（信贷回升 **或** 汇率压力）"双重确认（❌ 推断——Phase 4 验证 2026-08 发现单因子供给放量在 2023-11~2025-05 全程误报终结，2024 债牛期不触发方为合理）；
  - 央行连续回笼中长资金 → 1-2 个月后资金回归均衡（✅），降杠杆。
- **窗口实例**：2026 年资金面=两种类型综合（✅ 2026.4.21）。

## 规则 4：资金面生命线（杠杆/久期总开关 ✅ 方向，阈值 ⚠️/❌）

- **触发条件（可计算）**：资金利率中枢 vs 政策利率、资金面收紧信号。
- **计算步骤**：
  1. DR007 20 日均值 − OMO7D：偏离 > +15BP（❌ 推断带宽）→ 资金收敛；
  2. 央行是否连续回笼中长资金（MLF/买断式缩量、逆回购压降）；
  3. R001/R007 中枢趋势（2026.5：若维持 1.30%/1.40% 低位 → 买入机会；中枢上行 → 止盈 ✅）。
- **信号输出**：
  - 资金面宽松（DR007 低于 OMO 或贴近）→ **债牛延续，持有久期**（"资金不紧，债市不熊"）；
  - 资金收敛（偏离 > +15BP 或央行回笼中长资金）→ 降杠杆、缩短久期；
  - 资金利率中枢趋势性上行 → 无论长短端均需考虑及时止盈（✅ 2026.4 观点）。

## 规则 5：利率锚定（空间判断 ✅ 方向，阈值 ⚠️）

- **触发条件（可计算）**：10Y 国债 vs MLF 利率锚。
- **量化阈值**：10Y 高点约 **MLF+20-30BP**（⚠️ 外推，以原文复核）；2026 年 10Y 区间约 **1.6%-1.9%**（⚠️）。
- **信号输出**：
  - 10Y 接近/突破锚上沿（MLF+30BP）→ **配置价值显现，逢高配置**；
  - 10Y 贴近锚下沿（区间下沿 1.6%）→ **交易拥挤，防回调、止盈**；
  - 区间中枢（约 1.75%）→ 均衡，票息+波段。

---

## 规则 6：机构行为切换（节奏信号 ✅ 方向，量化 ❌）

- **触发条件（可观察）**（✅ 2024.12/2026.3）：
  - 配置盘（大行/保险）因负债成本下降持续买入 → 债市支撑；
  - 交易盘（基金/券商）情绪变化：卖出转买入（"买长卖短"）→ 情绪好转；骤然止盈 → 警惕回调；
  - 2025 学习效应 → 2026 机构对收益锁定更敏感 → 波动放大。
- **量化代理**（❌ 推断）：基金净买入连续 3 周转正 + 大行净买入稳定 → 情绪好转；基金净卖出放量 → 回调预警。
- **信号输出**：
  - 配置盘主导 → 压利率，持有久期；
  - 交易盘集体止盈 → 阶段性防守，降久期；
  - 交易盘由卖转买 → 情绪修复，可回补。

---

## 规则 7：经济动能转换与债牛长逻辑（趋势总开关 ✅ 原文）

- **触发条件（状态判断）**：融资需求结构（地产/基建 vs 新质生产力）与利率中枢方向。
- **量化代理**（❌ 推断）：地产投资同比持续为负 + 高技术产业投资增速 > 固投增速 → 动能转换确认。
- **信号输出**：
  - 动能转换确认 → **低利率大方向不变，债市长期持有**，但票息下降、回报率难超 4%（✅ 2024 年中长期债基中位数收益）、波动加大 → 波段+品种增强；
  - 地产/基建融资需求重新走强 → 债牛逻辑动摇（⚠️ 风险提示，非其当前判断）。

---

## 规则 8：存款自律与理财净值化（负债端信号 ✅ 原文）

- **触发条件（可观察）**（✅ 2025.1.2）：
  1. 非银同业存款自律新规/存款利率自律机制落地 → 非银资金利率中枢下行、票息行情加速（✅ 2024.12）；
  2. 理财回归净值化（收盘价/平滑估值/自建估值受限）→ 理财对利空高度敏感 → 抢跑赎回债基可能成常态 → 放大波动（✅）。
- **量化代理**（❌ 推断）：非银存款单月大幅下降（如 2024.12 大行 -3.44 万亿 ✅）+ 理财规模波动加大 = 负债端重构。
- **信号输出**：
  - 存款自律落地 → 票息资产稀缺化 → **增配低波票息资产**（短端/存单/高等级短久期信用）；
  - 理财净值化 + 赎回异动 → **负反馈预警，降杠杆、增流动性**；
  - 非银存款压降 → 大行缺负债 → 资金面不稳定性上升（✅ 2025.1）。

## 规则 9：债基指数轮动（组合构建 ✅ 原文）

- **触发条件（组合层面）**：配置仓 60% + 弹性仓 40%（✅ 2025.2）。
- **计算步骤**：
  1. 配置仓：可转债 + 超长利率债 + 3-5 年信用债等比例、恒定持有（✅）；
  2. 弹性仓：按"货币-信用四象限"（规则 1）+ 月度节奏（规则 10）动态调整。
- **信号输出**：弹性仓在"货币趋松&信用趋宽"时偏转债/权益；纯债盘整期偏 3-5 年信用；回调期偏短久期利率债。

---

## 规则 10：月度节奏三阶段（月内操作节奏 ✅ 原文）

- **触发条件（日历驱动）**（✅ 2026.3.4）：
  - **上旬**：两会/海外事件等增量信息繁杂 → 博弈成本高 → **套息策略占优**；
  - **中旬**：政策落地 + 宏观数据明朗 → 若政策克制、数据符合预期 → **追加久期窗口**；
  - **下旬**：跨季资金波动 → 信用策略**提前压降杠杆**；短端若因跨季调整 → **补仓机会**。
- **信号输出**：按月份阶段执行对应策略重心；与规则 4/5/6 叠加确认。

---

## 规则 11：季节性规律（节奏信号 ✅ 原文方向）

- **触发条件（日历驱动）**（✅ 2025.1.2）：
  1. **年初**：利率易现阶段性低点（降准降息落地 = 关键止盈点）；
  2. **两会前后**：方向选择期——会前两周与会中长端易小幅上行（"股强债弱"），利率高点或为布局机会；
  3. **8-9 月**：长端利率往往到达相对低位（政策部署习惯 + 银行信贷投放规律）→ 二季度利率多下行、三季度或迎年内低点。
- **信号输出**：年初低点不追；两会前轻仓、会议后按定调决策；二季度布局、三季度低点兑现。

---

## 规则 12：政策与事件驱动（节奏信号 ✅ 原文方向）

- **触发条件（事件驱动）**：
  1. **化债型财政**（✅ 2024.11）：带来短期供给冲击，但"宏观基本面出现跳跃性反转的概率有限"→ 供给冲击不改方向，逢高配置；
  2. **央行预期管理**（✅ 2025.1）：暂停购债=相机抉择，引导利率向"合理点位"靠拢 → 短端承压、长端影响有限；购债重启/加量 → 利多；
  3. **降准降息预期**（✅ 2025.1）：2025 年降准幅度至少持平 2024（100BP+）、降息或超 30BP——降准降息落地 = 利多兑现止盈点。
- **信号输出**：事件按"预期差"逻辑操作——利好落地防"利多出尽"，利空落地看"利空出尽"。

## 规则 13：观点更新模板（观点快照见 assets/views.md）

> **设计原则**：方法论是永久的，观点是时效的。刘郁观点随年度策略/月度报告/事件点评更新，本规则只保留**结构模板**（永久），具体观点快照存放在 `assets/views.md`（时间倒序，顶部最新，旧快照标"已过期"）。**使用前必须先读 views.md 顶部最新快照**。

### 13.1 更新触发时机

- **年度观点**（岁末年初，如 2025.1"宽货币主线不变"）
- **月度报告**（每月月初债市展望：内生/外生两主线 + 三阶段策略）
- **流动性框架系列**（专题更新）
- **事件点评**（央行操作、存款自律、两会、化债、地缘事件）
- **公开论坛/访谈**（框架级阐述）

### 13.2 六维结构模板（新观点按此结构提炼入库）

| 维度 | 内容要求 | 示例（2026.3 月报） |
|---|---|---|
| 行情状态 | 走强/盘整/回调 | "尚未跳脱震荡区间，多空力量交替主导利率定价" |
| 点位锚 | 10Y/30Y 区间 | 10Y 1.78-1.83% 区间运行；2026 全年 1.6%-1.9% |
| 资金面 | 宽松类型、DR/R 中枢 | 资金面强韧性；跨季呵护 |
| 机构行为 | 交易盘/配置盘动向 | 基金由卖转买"买长卖短"；交易盘骤然止盈 |
| 节奏 | 三阶段策略 + 季节性 | 上旬套息、中旬加久期、下旬降杠杆 |
| 风险点 | 什么会打脸 | 政策超预期调整、地缘冲突升级、理财赎回放大波动 |

### 13.3 入库与使用规则

1. 新快照插入 views.md 顶部，标注报告名/发布日期/机构/有效期；
2. 快照不与信号计算耦合；观点与信号冲突时优先遵循信号并说明分歧；
3. 引用观点必须注明"截至 {日期} 刘郁（{任职机构}）观点"——**2023.8-2024.2 属广发证券、2024.3-2026.4 属华西证券、2026.4 后属兴业证券（拟任）**；
4. **机构归属红线**：禁止把华西时期观点与兴业时期观点混用；2026.4 后以兴业证券口径引用。
