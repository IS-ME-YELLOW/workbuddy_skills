# 领域适配器（Domain Adapters）

> **定位**：回答"面对一个新领域/新类型分析师，框架怎么落地"。已有领域给翻译要点；未知领域给自适应路径；任何平台给降级方案。
> **原则**：验收清单（acceptance-checklist.md）是**唯一强制标准**，本文件全部内容均为**参考经验**，随蒸馏轮次持续扩充（每次完成新类型后回填）。

---

## 一、已有领域翻译要点（⚠️ 经验总结，持续扩充）

### 宏观分析师（已验证：郭磊、张瑜、李超）

宏观内部分两类，翻译要点不同：

**A. 周期/资金流派（郭磊、张瑜）**
- **框架分层**：总量（增长/通胀/信用）→ 结构（新旧经济/行业景气）→ 择时（月度状态信号）→ 配置（大类资产/风格）
- **信号形态**：以**月度状态信号**为主（如 M1-BCI-PPI 三因子、存款剪刀差），阈值多为"方向 + 分位/增速门槛"
- **数据侧重**：货币信用（M1/M2/社融/企业中长贷）、价格（PPI/CPI/BCI）、景气（PMI/BCI）、股债性价比
- **产出建议**：仓位（股/债）+ 风格（新旧/大小盘）+ 行业倾向，通常**不做个股选择**
- 脚本形态参考：`examples/macro-guolei`、`examples/macro-zhangyu`

**B. 决策层/博弈开关流派（李超）**
- **框架分层**：决策优先级（中美博弈>社会稳定>结构转型>增长）→ 流动性定价（利率区间锚）→ 风格开关（口诀化二元选择）→ 结构工具（赛道/主题）——**首层不是国内基本面而是地缘博弈**，这是与 A 类最大差异
- **信号形态**：**互斥开关型**为主（对抗↔合作、利率区间上沿↔下沿、利空显性化↔央行购金），比 A 类状态信号更离散；另含叙事类信号（口诀/年度策略标题）需转译为可观测条件
- **数据侧重**：中美事件时间线（无结构化源，须建人工打分表并标 ❌）、利率走廊/OMO 公告（✅公开锚）、央行购金（外汇局月度）、存款分项、主题指数（如 AI 指数做"硅基通胀"代理）
- **产出建议**：极简杠铃配置（如"50% 黄金 + 50% 科技"）+ 口诀开关（"对抗买红利、合作买科技"）；引用时须区分**框架级结论（区间锚/口诀，稳定）与参数级预测（点位/幅度，随时点漂移）**
- **李超案例的特殊验证经验**：区间锚精度可成为全框架最高置信参数（10Y 1.5-2% 锚 vs 实际均值 1.76%）；开关是"倾斜信号"而非方向信号（对抗期市场可上涨），三方对照时勿把开关触发误判为看空
- 脚本形态参考：`examples/macro-lichao`

### 策略分析师（已验证：张忆东、刘晨明、傅静涛）

**张忆东型（全球配置/多重共振型）**：
- **框架分层**：主要矛盾判断 → 全球资产定价（利率/汇率/风险溢价传导）→ 结构主线落地（风格/行业/主题）
- **信号形态**：**仓位 + 风格/结构建议**为主，择时锚多为估值/风险溢价/资金情绪（ERP 分位、卖空占比、南向结构）
- **数据侧重**：估值（ERP/PE 分位/AH 溢价）、资金流（南向/外资/ETF/两融）、海外利率汇率（美债/美元/人民币）、市场结构（解禁/换手/拥挤度）
- **产出建议**：仓位建议 + 风格（价值/成长、核心资产 vs 主题）+ 区域配置（如 A 股/港股）
- 脚本形态参考：`examples/strategy-zhangyidong`

**刘晨明型（趋势线择时/资产分类型）**：
- **框架分层**：大势研判（均线系统"牛市前提"）→ 三类资产分类（周期/稳定/成长）→ 风格第一性原理（利润增速差值）→ 交易择时（拥挤度/反应度）→ 选股落地（困境反转恢复率）
- **信号形态**：**仓位 + 三类资产结构 + 主线方向**；择时锚以均线比值（收盘/MA100、/MA20）与成交占比为核心，多数阈值带大样本统计值（99 次跌破复盘、35 次主线调整复盘）——阈值要连统计口径一起抄，不能只抄数字
- **数据侧重**：指数均线比值（日频→月末）、板块成交占比（注意全行业口径 vs 成分指数口径差异）、财报增速差（风格）、ETF 净流入、宏观传导链（财政→PPI→ROE）
- **特有陷阱**：①"由高位降至 X%"类阈值必须带"先经历过高位"的前提（刘晨明 S6 案例验证发现）；②择时信号有"牛市前提+无黑天鹅"的适用条件，需 extras 开关；③机构归属中途变化（天风→广发）须在所有产出中强制标注任职期
- **产出建议**：仓位（牛市前提下的再布局/规避）+ 三类资产谁占优 + 主线景气状态（延续/拐点预警）
- 脚本形态参考：`examples/strategy-liuchenming`

**傅静涛型（期限分层/牛熊阶段演进型）**：
- **框架分层**：方法论总纲（"看中期做短期，看长期做中期"）→ 期限分层性价比体系（长期隐含ERP/中期经风险调整收益率/短期超跌反弹）→ 牛熊阶段演进框架（三块拼图→结构牛1.0→过渡期→全面牛2.0 两段论）→ 供给侧资金面刻度（供给出清三锚点+存款搬家+公募净值 0.8→1.0→1.20 刻度链）→ 结构审美（高股息第三类审美随牛熊阶段切换）
- **信号形态**：**牛熊阶段定位 + 仓位 + 结构（主线 vs 防御）**；择时锚为分位类（❌ 推断代理为主），但含少量 ✅ 原文硬数字（公募净值 1.20、出清占比 45%、固定资产形成 2-3%、在建工程 -15%）——**这类"锚点硬数字"要在 Phase 1 检索时专门一轮挖出并记录出处**
- **数据侧重**：指数价格分位（代理 ERP/性价比）、TMT 成交占比（主线拥挤）、红利指数（防御腿基准）、半导体代理指数（输入性冲击）、公募净值与存款搬家（多为 ⚠️ 锚点插值）
- **特有陷阱**：①定性表述极多（"历史高位""相对低位"），全部转 ❌ 推断分位代理并显式标注可替换；②两段论/阶段类判断依赖 extras 人工输入（bull_phase/growth_mainline_available），阶段错判会传导到 S10 等结构信号——extras 必须按叙事逐月推断并标 ⚠️；③价格分位代理在深度调整后钝化（S9 案例：TMT -20.8% 后扩展分位仍 90%+），暴跌后须人工复核估值口径；④高置信低覆盖信号（S9 双条件 AND）触发可信、未触发不等于安全，须与 views.md 观点互补
- **产出建议**：牛熊阶段 + 仓位区间 + 结构三段式（主线进攻/过渡防御/高股息底仓，随 bull_phase 切换）
- 脚本形态参考：`examples/strategy-fujingtao`

### 固收分析师（已验证：张继强）——首个固收样本，新领域自适应路径走通

**张继强型（多因子打分+区间锚型，固收首席通用形态）**：
- **框架分层**：方法论总纲（固收多为"多因子打分"体系——张继强为"五碗面"：基本面/政策面/资金面/供求/情绪估值）→ 点位/区间锚（年度策略给出 10Y 上下限）→ 生态定位（低利率+高波动等市场状态判断）→ 策略工具排序（久期/杠杆/票息/品种/下沉/波段/权益暴露，随年度切换）→ 结构信号（曲线形态/信用利差/股债性价比）
- **信号形态**：**方向信号（多因子净分 ±阈值）+ 边界信号（区间上沿加仓/下沿止盈）+ 状态信号（生态状态机）** 三层并存；与策略分析师最大差异是"区间思维"——不是追趋势而是围绕锚做均值回复，故 S 信号成对出现（上沿↔下沿、偏多↔偏空、配股↔配债）
- **数据侧重**：收益率曲线（1Y/10Y/30Y 国债）、资金利率（DR007/OMO/存单）、社融与政府债供给（YTD 累计需差分！）、名义GDP、股息率溢价；周报体系分析师（固收普遍）→ 指标密度远高于宏观/策略，indicators.md 的"跟踪优先级分级"（每日/每周/每月/每季）是刚需
- **特有陷阱**：①**区间锚逐年大幅下移**（2.25-2.35%→1.5-1.8%→1.6-2.1%）——历史复算若统一用最新区间锚会产生前视偏差，validation.md 必须显式标注此局限；②OMO 政策利率路径须手工维护（⚠️ 锚点）；③债基久期/分歧度类微观数据无公开源，对应信号（拥挤度）整条降级，REQUIRED_FIELDS 要预留 OPTIONAL 机制；④央行预期管理（点名长债）是事件型 extras，无结构化数据，按事件时间线还原并标 ⚠️；⑤存单利率常用 SHIBOR 代理（❌），口径差异须与 _meta 双处标注；⑥季末资金收敛是季节性的，会把多因子净分打成假偏空（2024-12 案例：S2 1M 误报）——事件复算时结合季节性信号复核
- **产出建议**：久期（拉长/中性/缩短）+ 杠杆 + 曲线与品种 + 信用下沉尺度 + 股债配置比例（固收的"仓位"是久期而非股票仓位）；策略排序引用须带年度（排序逐年变）
- 脚本形态参考：`examples/fixed-income-zhangjiqiang`


## 二、新领域自适应路径（应对开放类型：金工/行业/买方/机构……）

**核心原则：不强行套已有分层，按该分析师自己的方法论主体提炼。**

> ✅ **首例验证（2026-08，固收·张继强）**：本路径已实际走通一次。关键心得：①第 1 步的"领域特有指标体系"检索是成败关键——周报型固收分析师的指标密度极高（33 个 vs 宏观/策略约 20 个），跟踪优先级分级必不可少；②第 5 步"信号形态可扩展"落地为成对区间信号（上沿↔下沿）+ 多因子净分 + 生态状态机三层，S 编号体系无缝承接；③意外的收获是事件时点复算在固收格外好用（区间锚类观点天然可被"是否破区间"客观验证，6 事件中 4 个完全一致）；④意外的主要成本是口径代理（股息率溢价/SHIBOR/手工 OMO 路径）显著多于宏观/策略，三层来源标注的工作量要预留。

1. **Phase 1 加一轮"领域特有跟踪指标体系"检索**：除标准 4 组检索主题外，必须检索"该分析师常用的指标/数据/模型工具"，作为 indicators.md 的原料（例：固收→收益率曲线/利差/久期/信用利差；金工→因子/IC/换手；买方→组合约束/风险预算/回撤控制）
2. **框架分层以分析师原话为准**：Phase 2 提取时，先列出分析师自己在研报/访谈中使用的分类词（如"自上而下/自下而上""核心+卫星"），据此定 framework.md 的分层章节，**不复制**宏观/策略的分层标题
3. **产出结构以验收清单为准**：references×3 + assets×3 + screen.py 的结构对任何类型不变（这是领域无关的部分）；变化只在内容翻译
4. **examples 只参考结构最近的**：无同类样例时读 `examples/strategy-zhangyidong`（结构最全）学"标注纪律与深度手感"，**禁止照搬领域内容/阈值/框架名**
5. **信号形态可扩展**：固收可用"曲线信号/利差信号"、金工可用"因子信号/拥挤度信号"——S 编号体系不变，信号名称随领域
6. **完成后回填（强制）**：① 复制文档类 7 文件进 `examples/{skill-name}/`；② 更新 `examples/README.md` 索引表；③ 在本文件"已有领域"节补写该领域翻译要点 → 该类型从此拥有自己的 example，样本库自适应增长

## 三、平台降级方案（目标：任何平台都能跑）

| 能力 | WorkBuddy（完整版） | 降级做法（无对应工具时） |
|---|---|---|
| 金融数据 | westock-data / westock-tool / neodata 直连 | Phase 4 数据缺口按 ⚠️观点锚点/❌工程代理 标注，注明"数据源不可用"；验证结论只做方向性判断 |
| 技能校验 | package_skill.py（"Skill is valid"） | 按 acceptance-checklist.md §1/§9 人工逐条勾选替代机器校验 |
| skill 安装 | 写入 `~/.workbuddy/skills/` + zip 打包 | 产物以"目录 + zip"交付，由用户自行安装/导入 |
| 汇报通道 | 对话内图文 + present_files | 同（对话即交付通道） |

**平台无关核心**（任何平台都自包含）：五阶段流程（SKILL.md）+ 验收清单（acceptance-checklist.md）+ 脚本规范与骨架（scripts-conventions.md + screen_template.py）+ 示范样本（examples/）。**数据源与打包工具是增强项，不是必需品。**

## 四、跨领域冲突处理

- 同一分析师横跨多领域（如宏观+策略）：按其主要市场角色定 specialty，另一面写进 profile.md 差异化节
- 新领域与已有领域结论冲突：不调和、不覆盖，如实记录双方口径差异（validation.md 口径差异节）
- 领域特有红线（如机构合规、买方保密）：在成品 SKILL.md 红线节单独列出，不进通用模板
