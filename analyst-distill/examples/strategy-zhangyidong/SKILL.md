# 张忆东 · 策略分析框架

本技能将张忆东（全球首席策略、核心资产概念创造者）的策略研究框架蒸馏为可执行的选股/配置决策体系。
定位：**先找特定时间阶段的主要矛盾（矛盾→定价→结构），再落 A 股/港股/全球配置**。

## 使用流程（按顺序执行）

1. **读取最新观点**：先打开 `assets/views.md` 顶部，确认张忆东当前最新观点（截至日期 + 所属机构）。观点是时效的，勿直接使用历史快照。
2. **主要矛盾判断（第一层）**：调用 `references/framework.md` 第一层，用"主要矛盾论 + 三时段框架"定位当下主要矛盾（如 2026H1 = AI 上游硬件 → 2026H2 = AI 应用扩散）；用历史复盘（1998→1999-2000 纳斯达克类比）判断所处阶段。
3. **全球资产定价（第二层）**：运行 `scripts/screen.py`，计算风险溢价分位（ERP 5%→0）、港股三重共振、卖空占比、信用创造、美债-美元传导链等信号。计算规则与阈值详见 `references/decision-rules.md`。
4. **结构主线落地（第三层）**：结合 SMART 三主线（S 安全资产/MA 制造出海/RT 硬科技）、AI 应用扩散时钟、南向风格切换，确定行业方向与港股/A 股配置。
5. **输出规范**：所有观点引用必须注明日期与机构（如"张忆东（海通国际）2026-08 观点"）；信号与观点冲突时优先遵循信号并说明分歧；参数来源标注（✅原文/⚠️外推/❌推断）必须保留。

## 数据获取

- 估值类（ERP/PE/股息率）：用 `westock-data` 查询万得全A/沪深300/恒指/标普 500 指数与 10Y 国债收益率，自算 ERP（市盈率倒数 − 无风险利率）；席勒 PE 参考公开数据。
- 情绪类（港股卖空占比、两融、ETF 流向）：westock-data 或 neodata-financial-search；卖空占比可用港股卖空成交额/总成交额。
- 资金流（南向/北向/外资）：westock-data 港股通/沪深股通资金流；南向行业流向用于风格判断。
- 海外类（10Y 美债、美元指数、USDCNY）：westock-data 或 neodata 查询。
- 信用类（社融/信贷/M1/M2/企业中长贷）：westock-data macro 指标。
- 盈利类（工业企业利润）：westock-data `profit` 指标。
- 解禁/IPO：westock-data 或公开资料。
- 指标口径、频率、所属框架详见 `references/indicators.md`。
- 个股/行业筛选：用 `westock-tool` 按 screen.py 输出的条件（如 SMART 三主线龙头）做筛选。

## 脚本使用

```bash
python scripts/screen.py                  # 演示模式（内置示例数据，验证流程）
python scripts/screen.py --data macro.json  # 用真实数据文件计算信号
python scripts/screen.py --json-out        # 输出机器可读 JSON
```

- screen.py 输入：数据 JSON（`as_of` 数据截止日 + `history` 各字段按月数组 + `extras`）；输出：S1-S12 信号表 + 仓位/结构/港股建议。
- 信号 S1-S12 编号为**工程化设计**（张忆东没有此编号体系），底层阈值来源见各规则标注。
- 数据来源：优先 westock-data / neodata 查询结果，由调用方填入 JSON。


## 红线与注意事项

- 本技能输出为分析参考，非投资建议；宏观框架历史表现不代表未来。
- 观点与规则分离：`assets/views.md` 是时效快照（含机构归属变化），`references/` 是方法论，勿混用。
- **机构归属**：2025-12-31 前张忆东在兴业证券，2026-02 起在海通国际——引用观点必须标注时间与机构。
- **参数来源标注**：所有阈值带 ✅/⚠️/❌ 标注——推断值（❌）不冒充原文，拿到真实值应替换；SMART 回测数字（超额 39% 等）为 ⚠️ 以原文为准。
- 时间窗口 2023.8-2026.8 内的方法论与观点为本技能知识边界；窗口外内容需另行检索核验。
- A 股/港股惯例：涨红跌绿，货币符号用 ¥/HK$。
