## 二、方法论特征

- **五碗面总纲**：基本面定大趋势 → 政策面（货币政策为核心）定拐点 → 资金面定波动 → 供求定短期表现 → 情绪估值定安全边际；落脚于方向/空间/波动/结构，归结为**胜率与赔率**。
- **框架迭代意识**：强调"五碗面随经济格局持续迭代"（CPI → 信贷金融数据 → 房地产周期 → 中美博弈/新旧动能），反对本本主义与经验主义；"要区分趋势性/结构性变化与周期性/短期扰动"。
- **机构行为视角**：资产荒（金融扩表+融资萎缩）、存款搬家、理财净值化、大行放贷小行买债等微观结构变量是近年利率定价的关键。
- **风格**：主张简洁、有力的逻辑框架，报告逻辑性强、接地气；观点鲜明、勇于认错。

## 五、风险与注意事项

1. **机构归属红线**：张继强 2004-2018 中金 → 2018.10 华泰。窗口内（2023.8 起）观点均属华泰证券，但引用其早期框架性论述（如转债框架、2019 低波动判断）时为中金/华泰交接期前后，须核对当时任职。职务（副所长/所长）随内部调整变化，以最新公告为准。
2. **区间锚逐年下移**：点位区间不可静态外推，每年新年度策略发布后必须更新 screen.py 参数区（RANGE_HIGH/RANGE_LOW）。
3. **股债性价比规则时效**：20/80 分位回测规则出自 2019 年资产配置月报，低利率时代分位中枢系统性上移，直接套用会长期偏向"配股"，需滚动窗口复核。
4. **低利率时代框架边界**：久期策略赔率系统性变差，历史牛市经验（如拉久期扛回调）不可线性外推。
