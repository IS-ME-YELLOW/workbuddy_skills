# 张继强（华泰固收）债市分析框架技能

> 华泰证券研究所副所长（后升任所长，以最新公告为准）、总量研究负责人、固收首席、董事总经理；新财富白金分析师（2021）、14 次新财富最佳分析师（7 次第一）。执业证书编号：S0570518110002。
> 时间窗口：2023.8–2026.8（资料以窗口内公开研究为准）。
> ⚠️ 机构归属：2004-2018 中金公司 → 2018.10 至今华泰证券；引用观点须标注时间与机构。

## 一、使用流程（先观点时效 → 再体检 → 再择时 → 后配置）

1. **先读 `assets/views.md` 顶部最新观点快照**（观点时效性第一原则：任何输出前核对最新观点，过期观点不得当作当前判断）
2. **债市体检**：五碗面逐项打分（基本面/政策面/资金面/供求面/情绪估值面）→ 判断方向（framework.md 框架 1-2）
3. **周期定位**：新旧动能转换阶段 + 市场生态（趋势牛/震荡/低利率高波动）→ 确定策略排序（框架 9-11）
4. **择时与空间**：10Y 在年度区间锚的位置（上沿配置/下沿止盈）+ 资金面松紧 + 季节性窗口
5. **配置落地**：久期/杠杆/品种（曲线形态、二永、转债）+ 股债性价比切换（权益暴露）
6. **运行信号**：`scripts/screen.py`（S1-S12 信号，见下）

## 二、触发场景速查表

| 用户问什么 | 调用 | 关键锚 |
|---|---|---|
| 债市往哪走？ | 五碗面 + 名义 GDP | 五碗面净分；名义增速方向 |
| 10Y 到顶/到底了吗？ | 年度点位区间锚 | 2026：上限 2.0-2.1%、下限 1.6-1.7%；下半年核心区间 1.70-1.90% |
| 现在拉久期还是缩久期？ | 区间锚 + 生态定位 + 策略排序 | 上沿拉久期、下沿止盈 |
| 加杠杆吗？ | 资金面 | DR007 vs OMO、存单-DR007 息差 |
| 买什么期限/品种？ | 曲线形态 + 品种选择 | 陡峭化、30-10Y 利差 50BP、二永/转债需求变化 |
| 股债怎么配？ | 股债性价比 | 沪深300股息率/10Y 利率分位：高于 80% 分位配股、低于 20% 分位配债 |
| 什么时候防回调？ | 拥挤度 + 季节性 + 政策面 | 久期分歧度、6-8 月供给高峰、10 月变盘、央行发声 |
| 张继强怎么看 XX？ | assets/views.md | 最新快照（顶部） |

## 三、数据获取

- **westock-data**：债券/国债收益率（10Y、30Y、1Y）、DR007/R007、存单利率、沪深300 股息率、社融/M2、名义 GDP（宏观指标）
- **westock-tool / neodata-financial-search**：自然语言查询宏观与固收指标、股债性价比分位
- 平台降级方案见 analyst-distill `references/domain-adapters.md` §三（数据源不可用时如实标注，不得伪造数据）
- `screen.py --data` 输入字段清单（必需）：bond10y / bond30y / bond1y / dr007 / omo7d / ncd1y / ngdp_yoy / sf_yoy / gov_supply / div_yield_ratio / fund_duration / fund_duration_disp；extras：policy_stance / cb_guidance / asset_shortage / eco_stage

## 四、脚本使用

```bash
python scripts/screen.py                            # 演示模式（合成数据，验证流程）
python scripts/screen.py --data data.json           # 真实数据（月度字段→数组，最新在末尾）
python scripts/screen.py --data data.json --json-out  # stdout 输出 JSON（--json-out 为布尔标志）
python scripts/screen.py --selftest                 # 自测：逐月复算统计信号覆盖
```

S 信号（工程化编号系本技能设计，非张继强本人编号）：S1/S2 五碗面方向｜S3/S4 区间上沿配置/下沿止盈｜S5 资金面收敛｜S6 超长端波段｜S7/S8 股债性价比极值｜S9 季节性窗口｜S10 政策拐点｜S11 交易拥挤｜S12 低利率高波动生态。阈值来源分级（✅原文/⚠️外推/❌推断）见 `references/decision-rules.md` 与脚本参数区。

## 五、红线与注意事项

1. **观点时效性**：任何输出先读 views.md 最新快照；年度区间锚每年 11-12 月随新年度策略强制更新（不可静态使用历史区间）。
2. **机构归属**：张继强 2004-2018 任职中金、2018.10 起任职华泰；引用观点必须标注"截至 {日期} 张继强（华泰证券）观点"。职务表述（副所长/所长）以最新公告为准。
3. **禁止虚假精确**：一切阈值/权重/参数带来源标注；❌ 推断值（五碗面计分权重、分位窗口、拥挤度阈值等）为最小假设可替换，不得冒充原文。
4. **观点与规则分离**：信号计算不依赖观点快照；冲突时优先遵循信号并说明分歧。
5. **分析师独立性**：本技能仅含张继强本人框架与观点，不与其他分析师对比。
6. **A股/债市惯例**：涨红跌绿、货币 ¥；债券收益率上行 = 债市走弱（价格反比）。
7. 本技能输出为分析参考，非投资建议。
