## 框架总览：四层结构

郭磊的框架体系是一个从**总量**到**结构**、从**择时**到**配置**的递进体系。选股/配置时按以下顺序调用：

```
第一层 总量判断（经济在周期什么位置）
   └─ 第二层 结构判断（新旧经济如何分化 → 选哪条赛道）
        └─ 第三层 择时信号（当前胜率/赔率状态 → 何时买）
             └─ 第四层 配置落地（股债商金仓位 → 买什么）
```

- **第一层（总量）**：四周期叠加、供需比、储蓄率→ROE→名义GDP→增长广谱性、三大要素优势、减速带
- **第二层（结构）**：K型分化/硅基-碳基平衡、利率锚旧权益锚新、叙事经济学
- **第三层（择时）**：M1-BCI-PPI三因子、胜率-赔率、5+1择时
- **第四层（配置）**：估值-宏观偏离度、宏观因子风险平价

## 第一层：总量判断框架

### 1. 四周期叠加（康波 + 库兹涅茨 + 朱格拉 + 库存）

- **定义**：任何时点的宏观经济都是四个不同长度周期的叠加结果。判断"现在处于周期叠加的什么阶段"是总量判断的起点。
- **四周期**：
  - 康波周期（50-60年）：通用技术变革驱动。郭磊判断 2020s 处于**新一轮康波的前段**（可再生能源、AI、具身智能 = 本轮的动力部门），不是上一轮康波的萧条期；关键要素为 Token（词元），继煤、铁、石油、芯片之后浮出水面。
  - 库兹涅茨周期（15-25年）：房地产/建筑业周期。中国本轮上行期 1999 年启动、2021 年触顶，2022 年以来处于迅速调整期，**尚未确认见底**（一级投资/二级销售/三级租金均未确认底部）；郭磊预计建筑业见底"初步预计明年"（即 2027 年前后，随化债结束与地产调整到位）。
  - 朱格拉周期（7-10年）：设备更新/资本开支周期。当前与康波导入期的 AI 基础设施投资共振。
  - 库存周期（3-4年）：产成品库存的短周期波动，与 PPI 高度相关。
- **选股应用**：
  - 康波上行段 + 导入期 → 新经济部门（AI/算力/新能源/高端制造）景气向上；
  - 库兹涅茨下行段 → 地产链、传统建筑业、地方财政敏感行业持续承压；
  - 库存周期位置 → 判断周期品盈利弹性与 PPI 方向。
- **2023-2026 实例**（时点观点，详见 assets/views.md）：2026 年中期报告《长波与分化》明确"康波上行 + 库兹涅茨下行"的对冲格局 → 高技术制造、出口链强；建筑业、传统制造、居民部门资产负债表弱。这是新老资产背离的根源。

### 2. 供需比框架（需求代理 vs 供给代理）

- **定义**：价格走势由供需对比决定。郭磊用需求代理指数与供给代理指数的比值刻画宏观供需格局。
- **口径**：
  - 需求代理 = 40% 固定资产投资 + 40% 社会消费品零售 + 20% 出口（同比加权）⚠️ 外推：公开有"加权"口径，具体 0.4/0.4/0.2 未逐字核对
  - 供给代理 = 工业增加值（同比）
  - 供需比 = 需求代理 / 供给代理
- **逻辑**：供需比上行 → 供不应求 → 价格（PPI）有上行压力 → 企业盈利改善；供需比下行 → 供强需弱 → 价格收缩 → 盈利承压。（✅ 原文）
- **2025-2026 实例**：2026 年 4-5 月供给端（工业增加值+服务业生产指数均值 4.3%/4.4%）明显强于需求端（固投 -9.4%、社零 -0.2%），供需比下行 → 郭磊判断"通胀不是主要矛盾，需求是主要矛盾" → 政策重心在扩内需，PPI 对 CPI 传导有限。
- **选股应用**：供需比持续下行阶段，规避上游周期品与产能过剩行业，关注政策驱动的需求修复链；供需比回升初期，周期品弹性最大。

### 3. 储蓄率→ROE→名义GDP→增长广谱性

- **定义**：一条从储蓄到资产定价的传导链。
  - 高储蓄率 → 资本形成能力 → 名义GDP增速 → 企业ROE → 股市盈利底；增长广谱性（增长的行业分布宽度）决定市场赚钱效应。
- **关键概念——增长广谱性（Broad-based Growth）**：不仅看总量增速，更看增长的行业分布是否广泛。广谱性高 → 盈利面广 → 指数级别行情；广谱性低（K型）→ 结构行情，指数与个股背离。
- **选股应用**：用"增长广谱性"判断市场风格——广谱性上行买宽基/价值，下行聚焦结构性赛道。2025 年报告《重塑广谱性增长》提出政策目标即修复增长广谱性；2026 年"下半年随着财政支出加快，增长广谱性边际上升"→ 支持从科技单边转向均衡配置。

### 4. 三大要素优势

- **定义**：中国经济增长的长期供给侧优势：**工程师红利**（高教育存量人口）、**存量人口红利**（人口规模带来的市场纵深与分工优势，替代刘易斯拐点后的数量红利）、**延迟满足红利**（高储蓄倾向支撑高投资率）。
- **选股应用**：工程师红利 → 高端制造/研发密集行业长期占优；存量人口红利 → 消费分级、下沉市场、服务消费；延迟满足红利 → 资本品、基础设施、长期资产定价的支撑。

### 5. 减速带框架

- **定义**：全球经济面临"逆全球化"带来的效率减速带（供应链重组、关税、技术封锁抬高交易成本），与财政扩张带来的对冲红利并存。
- **选股应用**：减速带逻辑下，内需链、自主可控、国产替代、区域贸易（对南方国家出口）获得超额逻辑；全球贸易链敞口大的传统出口股估值承压。2026 年出口高增长的三大背景之一即"对南方国家出口份额上升"。

## 第二层：结构判断框架

### 6. K型分化 / 硅基-碳基平衡

- **定义**：
  - **K型分化**：新经济与旧经济、高收入与低收入、AI 受益者与受损者的分化走阔。中国经济 K 型来自"康波上行 + 库兹涅茨下行"的对冲；美国 K 型来自高利率放大资产负债表差异 + AI 放大利润表/就业差异。
  - **硅基-碳基平衡**：硅基经济（AI/算力）决定供给，碳基经济（消费/就业/地产）决定需求，二者之间需要内生平衡，总量稳定性是两者的"浮标"。
- **选股应用**：K 型阶段新老资产折溢价拉大 → 新经济做进攻（确定性溢价）、旧经济做防守（不确定性折价→高股息/现金流/物理刚需）。关注 K 型收敛的拐点信号（就业数据、消费数据、固投）。

### 7. 利率锚旧、权益锚新

- **定义**（《利率反映旧经济，权益定价新经济》，2024 下半年提出）：利率跟随**旧经济**（库兹涅茨周期）走，10 年期国债收益率同步于**建筑业 PMI**；股票跟随**新经济**（康波周期）走，沪深300 同步于**高技术行业 PMI**。
- **原因**：旧经济依赖间接融资（银行→利率），新经济依赖直接融资（股市）。
- **2023-2026 实证**：2024 下半年以来股债走势背离（股上、利率下）正是"权益锚新、利率锚旧"的体现。
- **选股应用**：
  - 债市方向看建筑业 PMI / 地产链景气（旧经济锚）；
  - 股市风格看高技术行业 PMI / 新一代信息技术行业 PMI（新经济锚）；
  - 若建筑业 PMI 见底回升 → 利率上行压力 + 旧经济（价值/地产链/基建链）修复机会。

### 8. 叙事经济学

- **定义**：资产价格除基本面外受"叙事"（市场共识故事）驱动，叙事有生命周期：**萌芽 → 认同 → 狂热 → 消退**。郭磊用 CSAD（羊群因子）量化叙事交易强度。
- **选股应用**：
  - 叙事萌芽/认同期 → 主题股超额收益最大；
  - 狂热期（CSAD 极端、成交集中度极端）→ 警惕逆转；
  - 消退期 → 回吐风险，回归基本面定价。
  - 2024"924"以来叙事交易单边化 → 科技/主题高波动；2026 年商品叙事收敛 → "结构性资产荒"资金向科技集中。

## 第三层：择时框架

### 9. M1-BCI-PPI 三因子择时体系（最量化，见 decision-rules.md 完整步骤）

- **定义**：宏观择时 = 增长周期（BCI）+ 货币周期（M1同比）+ 价格周期（PPI 滤波后周期项）三因子加权，综合得分 >0 看多权益、<0 看空。（三因子构成 ✅ 原文；权重 ❌ 推断，详见 decision-rules.md 1.2）
- **可选扩展**：加入叙事因子 CSAD → "M1-BCI-PPI-CSAD"。（✅ 原文思路）
- **绩效（回测 2009.1 起，月度 15 日调仓，得分正全仓/负空仓）**：⚠️ 外推——取自公开报告数字，加了"±"表示近似，以原始报告为准
  - 沪深300 基准：年化 10.4%±、夏普 0.53-0.55、月胜率 78%±；
  - 中证1000 基准：年化 16.7%±、夏普 0.73、月胜率 79%±。
- **选股应用**：择时得分决定了组合的贝塔敞口（仓位），得分转正阶段做多权益/提高仓位。

### 10. 胜率-赔率框架（胜率看边际，赔率定位置）

- **定义**：
  - **胜率** = 未来一段时间方向正确的概率，看**边际变化**（三因子/基本面数据的边际方向）；
  - **赔率** = 当前位置的性价比，看**估值位置**（历史分位）。
- **融合模型**：股债性价比择时 = "M1-BCI-PPI"（胜率） + 中枢改进后的"10年期国债利率 − 万得全A(除金融石油石化)股息率"（赔率）；<10% 历史分位 = 权益极具性价比的强信号。（融合思路 ✅ 原文；<10% 阈值 ✅ 原文；40%/60% 分档 ⚠️ 外推）
- **选股应用**：胜率与赔率共振向上时加仓；胜率向下、赔率向上时逢低布局高股息；两者均向下时防御。（⚠️ 外推：按"胜率看边际、赔率定位置"原则整理，非逐字）

### 11. 5+1 择时框架（高成长叙事的择时）

- **定义**：对高增长叙事的板块，择时看六个维度：**基本面、政策、流动性、风险偏好、海外环境 + 供给格局**。
- **选股应用**：六维共振向上 → 高景气赛道主升；任一维度恶化（如海外加息、政策收紧）→ 高估值成长股回撤风险。

## 第四层：配置框架

### 12. 估值-宏观偏离度（P/E − 名义GDP增速）

- **定义**：全 A 估值（P/E）跟随业绩（名义GDP增速）上台阶改变运行区间。用"P/E − 名义GDP增速"衡量市场定价相对基本面的位置。（✅ 原文）
- **阈值**：+1 倍标准差 = 经验警示位；+2 倍标准差及以上 = 极致位（风险收益比差）。（✅ 原文）
- **选股应用**：偏离度进入 +1σ 以上区间 → 降低整体仓位、增配低估值/高股息防御；回落到均值以下 → 权益配置价值上升。

### 13. 宏观因子风险平价（增长/通胀/叙事/流动性四因子）

- **定义**：把资产收益拆解为宏观因子暴露，按风险平价（risk parity）思想构建股/债/商/金组合。四大宏观因子：**增长、通胀、叙事（羊群）、流动性**。
- **框架输出**：超配/低配/平配方案。
  - 2026 展望实例（时点观点，详见 assets/views.md；2026-01《快慢变量分野，新老资产收敛》）：**超配股票与商品、低配债券、平配黄金**；
  - 理由：增长/通胀走出复苏趋势且波动下降，叙事松动且波动上升，流动性度过最宽松阶段。
- **选股应用**：模型提示的因子环境 → 权益仓位中枢；商品（周期股）与债券的相对配置比例；黄金作为对冲因子的平配。
