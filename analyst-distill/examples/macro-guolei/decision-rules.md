# 郭磊投资决策规则（decision-rules.md）

> 本文件将郭磊框架转化为**可执行的规则**：信号触发条件 → 动作。
> Phase 3 的 `scripts/screen.py` 依据本文件实现。
> 数据源：westock-data / neodata-financial-search 可查询宏观指标。

每条规则的参数都标了来源，**防止"虚假精确"**——推断值绝不冒充原文引用：

| 标记 | 含义 |
|---|---|

| ⚠️ 外推 | 有公开依据（口径/方向明确），但**具体数值/分档未经逐字核对**，属合理近似，使用时按原文复核 |

## 规则 0：信号分级与总原则

- **强信号**（改变仓位/风格的信号）：M1-BCI-PPI 择时分、股债性价比 <10% 分位、估值-宏观偏离度 ±1σ/2σ
- **中信号**（结构调整信号）：供需比方向、PMI 新旧锚背离、叙事周期阶段
- **弱信号**（赛道选择信号）：细分行业景气、高频代理指标
- 总原则：**胜率看边际，赔率定位置**——先判断方向概率（胜率），再判断当前位置值不值（赔率），两者共振才下重手。（✅ 原文）

## 规则 1：M1-BCI-PPI 月度宏观择时（核心规则，可完全脚本化）

### 1.1 三因子定义

| 因子 | 变量 | 方向 | 含义 |
|---|---|---|---|
| 增长周期 | BCI（长江商学院企业经营状况指数） | 上行=正贡献 | 企业景气边际 |
| 货币周期 | M1 同比（%） | 上行=正贡献 | 流动性/活性货币 |
| 价格周期 | PPI 同比经滤波后的周期项 | 上行=正贡献 | 名义价格/盈利周期 |

（三因子构成 ✅ 原文，郭磊"宏观择时"系列公开模型）

### 1.2 计算步骤（月度更新）

1. 取当月 BCI、M1 同比、PPI 同比三个原始序列；
2. 对 PPI 同比做**滤波**（HP 滤波/带通滤波）提取周期项，去除趋势与噪声；（滤波方法 ✅ 原文，具体 λ 参数 ❌ 推断）
3. 对三个序列做标准化（z-score，滚动窗口）后，计算各因子的**边际变化方向与强度**（如近 3 个月斜率/环比变化，郭磊口径为"对择时强度的贡献"，即标准化后的因子变化值）；（z-score 标准化 ✅ 原文口径；窗口长度 ❌ 推断）
4. 综合得分 = w1×增长因子贡献 + w2×货币因子贡献 + w3×价格因子贡献；**权重 ❌ 推断**——郭磊公开仅给"三因子加权"与每期因子贡献值，**从未公布权重**，脚本默认等权（最小假设），如获得真实权重可直接替换；
5. **调仓规则**：每月 15 日调仓；得分 > 0 → 全仓权益（沪深300 或中证1000 基准）；得分 ≤ 0 → 空仓/现金。（✅ 原文约定）

> ⚠️ **关于因子贡献值示例**：郭磊月度报告确实会给出三因子贡献分（如"增长 -0.05、货币 +0.02、价格 +0.04"量级），
> 但**具体小数以当期报告原文为准**，本文件不固化任何示例数值，避免以推断冒充引用。

### 1.3 扩展：加入叙事因子（可选，降低夏普但更稳健）

- 叙事因子 = CSAD（羊群因子，个股收益离散度反向指标）的周期项；
- 综合得分 = M1-BCI-PPI 得分 + w4×CSAD 贡献 → "M1-BCI-PPI-CSAD"。（扩展思路 ✅ 原文）
- 经验：加入 CSAD 后收益略降但回撤更小（⚠️ 外推：回测数字取自资料记录，未逐字核对，仅供参考）。

### 1.4 回测基准绩效（供校验脚本用）⚠️ 外推

| 基准 | 版本 | 年化 | 夏普 | 月胜率 | 备注 |
|---|---|---|---|---|---|
| 沪深300 | M1-BCI-PPI | ~10.4% | ~0.54 | ~78% | 2009.1 起，月度15日调仓 |
| 中证1000 | M1-BCI-PPI | ~16.7% | ~0.73 | ~79% | 2009 起 |
| 沪深300 | +CSAD | ~5.7% | ~0.28 | ~67% | 更稳健 |

> 这些是郭磊团队公开报告中的模型历史回测数字，表中加了"~"表示近似引用；以原始报告为准。

### 1.5 信号输出

- 得分 > 0：**权益积极** → 提高仓位、beta 敞口上行；（✅ 原文）
- 得分 ≈ 0 且三因子方向分歧：**中性** → 均衡配置，不加杠杆；（⚠️ 外推）
- 得分 < 0：**防御** → 降低仓位，增配债券/高股息。（✅ 原文）

## 规则 2：胜率-赔率股债性价比择时

### 2.1 赔率指标（位置）

- **指标**：经中枢调整后的"10年期国债利率 − 万得全A(除金融石油石化)股息率"（✅ 原文）
- **观测口径**：2015 年以来历史分位 + 滚动 3 年标准差倍数（口径 ✅ 原文）
- **阈值**：
  - 分位 < 10% → 权益**极具性价比**（强买信号）；（✅ 原文，公开反复出现）
  - 分位 10%-40% → 权益性价比偏高（偏买）；（⚠️ 外推：郭磊未明确 40% 分界，为可执行性补充）
  - 分位 40%-60% → 中性；（⚠️ 外推）
  - 分位 > 60% → 权益相对债券不便宜（偏防御）；（⚠️ 外推）
  - 滚动 3 年标准差 < -2σ（如 2025 年初的 -2.22 倍）→ 权益极具吸引力。（口径 ✅ 原文；**"-2σ"硬阈值 ⚠️ 外推**，-2.22σ 实例 ✅ 原文）

### 2.2 融合决策（胜率 × 赔率矩阵）⚠️ 外推

> "胜率看边际、赔率定位置、共振下重手"为 ✅ 原文原则；下方九宫格是按其逻辑整理的**结构化外推**，非逐字引用。

| | 赔率好（分位<40%） | 赔率中性 | 赔率差（分位>60%） |
|---|---|---|---|
| **胜率向上** | ★ 重仓权益 | 标配权益 | 逢高减配、结构性做多 |
| **胜率中性** | 逢低布局 | 均衡 | 防御 |
| **胜率向下** | 高股息防守、等待右侧 | 减仓 | 大幅防御、债性资产 |

- 2026.1 实例：赔率 59.3% 分位（中性偏贵）、胜率积极但强度趋平 → 结论"权益优势主要来自胜率面"，不追高、逢低布局。（✅ 观点实例，见 assets/views.md）
- 2025.8-9 实例：赔率 50.5% 分位（上期 29%），胜率将改善 → 综合得分阶段性支撑股市，权益仓位 59.8%。（✅ 观点实例）

### 2.3 补充参考

- "BCI 融资环境 − BCI − PPI"三因子作为胜率口径的备选（融资环境因子替代 M1）。（✅ 原文提及备选口径）

## 规则 3：估值-宏观偏离度（市场位置预警）

- **指标**：万得全A P/E − 名义GDP增速（%）（✅ 原文）
- **阈值**：
  - 偏离度 > +1 倍标准差 → **警示位**：降低仓位、转向低估值/高股息；（✅ 原文）
  - 偏离度 ≥ +2 倍标准差 → **极致位**：强防御，历史性减仓信号；（✅ 原文）
  - 偏离度回落至均值以下 → 权益配置价值回升。（✅ 原文）
- 逻辑：全 A 估值跟随名义增速换锚，"P/E 脱离名义增速"= 情绪定价占主导，回归概率高。（✅ 原文）

---

## 规则 4：供需比规则（风格与周期品开关）

- **指标**：供需比 = (0.4×固投同比 + 0.4×社零同比 + 0.2×出口同比) / 工业增加值同比
  - 权重 **⚠️ 外推**：公开有"需求代理=固投+社零+出口**加权**"的口径，但 0.4/0.4/0.2 具体权重未能逐字核对到原文，为研究报告口径的近似；
- **决策**：（方向 ✅ 原文）
  - 供需比**上行** → 价格（PPI）上行 → 顺周期/上游/周期品盈利扩张 → **超配周期与顺周期价值**；
  - 供需比**下行**（供强需弱）→ 价格收缩 → 规避产能过剩行业与上游，**聚焦政策驱动的内需修复链与高景气新经济**；
  - 供需比止跌回升的拐点 → 周期股左侧布局时点。
- 2026 状态：供强需弱（供给 4.3% vs 需求固投 -9.4%/社零 -0.2%）→ 防御周期品，等待财政落地推动需求修复（三季度观察）。（✅ 观点实例）

## 规则 5：新旧经济锚规则（风格切换）

- **指标**：建筑业PMI（旧经济锚）vs 高技术行业PMI（新经济锚）（✅ 原文，《利率反映旧经济，权益定价新经济》）
- **决策**：（方向 ✅ 原文）
  - 高技术PMI 上行 + 建筑业PMI 下行（当前形态）→ **成长/科技占优**，利率中枢下行（债牛）；
  - 高技术PMI 走弱 → 科技拥挤风险，减配高估值成长；
  - 建筑业PMI 见底回升 → **价值/地产链/基建链修复** + 利率上行压力；
  - 新经济二阶信号：新一代信息技术行业PMI + "海外大厂营收−资本开支增速−国内出口"验证链（出口仍加速=二阶拐点未现=AI 链中期占优）。（✅ 原文）
- 2026.8 最新：科技为中期共识压舱，但海外进入准加息周期、AI 供求由紧转缓 → **逐步增配价值类，推动适度均衡**。（✅ 观点实例）

## 规则 6：叙事周期规则（主题与拥挤度）

- **指标**：CSAD 羊群因子、全A 240日宽度、前5%个股成交额占比（✅ 原文）
- **叙事四阶段**：萌芽 → 认同 → 狂热 → 消退（✅ 原文）
- **决策**：（方向 ✅ 原文；**具体量化阈值 ❌ 未量化**——郭磊用"CSAD 极端""成交集中度极端"等定性表述，未公布硬阈值，脚本中"CSAD 分位>90%=狂热"为实现假设）
  - 叙事认同期 → 积极参与主题；狂热期 → 减仓兑现；
  - 宽度持续收窄 + 成交集中度极端 → 结构性风险（如 2026.8"宽度下降后的叙事流转"）；（✅ 观点实例）
  - 宽度压力释放 + 叙事收敛 → 均值回归机会（2026.8 四条积极线索之一）。（✅ 观点实例）

## 规则 7：年度/中期配置观点更新模板（观点快照见 assets/views.md）

> **设计原则**：方法论是永久的，观点是时效的。郭磊的配置观点随数据与政策持续更新，
> 因此本规则只保留**六维结构模板**（永久），具体观点快照一律存放在 `assets/views.md`
> （按时间倒序，顶部为最新，旧快照标注"已过期"）。
> **使用前必须先读 assets/views.md 顶部的最新快照**，勿直接套用历史观点。

### 7.1 更新触发时机

郭磊发布以下类型报告后，须更新 `assets/views.md` 顶部：
- 年度策略展望（约每年 1 月）
- 中期策略展望（约每年 6 月）
- 月度大类资产配置展望（每月中旬）
- 重要周度述评（观点明显变化时）

### 7.2 六维结构模板（新观点按此结构提炼入库）

| 维度 | 内容要求 | 示例（2026 中期，见 views.md） |
|---|---|---|
| 大类配置 | 股/债/商/金相对排序（风险平价输出） | 超配股与商品、低配债券、平配黄金 |
| 权益风格 | 成长/价值、大盘/小盘的倾向 | 科技压舱 + 价值增配（适度均衡） |
| 结构方向 | 看好的产业与产业链逻辑 | 硬件制造链（集成电路/自动数据处理设备出口）、出口链、对南方国家出口 |
| 政策主线 | 财政/货币/产业政策的落地节奏 | 广义财政落地（超长期特别国债+新型政策性金融工具 8000 亿）、补消费短板 |
| 风险点 | 影响假设成立的关键风险 | 海外第六轮货币收紧周期（1994 以来）；"沃什冲击"；固投不及预期；地缘 |
| 节奏 | 年内经济/市场的路径假设 | 中国 GDP 二季度低点（4.3%），三季度随财政落地修复 |

### 7.3 入库规则

1. 新快照插入 `assets/views.md` 顶部，标注：报告名/发布日期/有效期；
2. 被覆盖的旧快照移入"历史参考"区，标注"已过期"；
3. 快照不与 S1-S12 信号计算耦合（信号只依赖方法论规则）；
4. 若观点出现方向性反转（如大类配置从超配转向低配权益），在快照顶部加粗提示。

### 7.4 使用规则

- 对话/报告中引用观点时，必须注明"截至 {日期} 的郭磊观点"；
- 观点与信号冲突时（如观点看多但 S1-S12 发出防御信号），优先遵循信号并说明分歧原因。

## 规则 8：信号触发汇总表（screen.py 输出框架）❌ 工程化设计

> **重要**：郭磊**没有** S1-S12 这套编号体系。下表是把散落在规则 1-7 的方法论**编码为可执行信号**的工程化翻译——编号与触发条件为本设计，底层阈值来源见各规则标注。

| 信号编号 | 触发条件 | 动作 | 强度 |
|---|---|---|---|
| S1 | M1-BCI-PPI 得分由负转正 | 权益仓位上调至进攻档 | 强 |
| S2 | M1-BCI-PPI 得分由正转负 | 权益仓位下调至防御档 | 强 |
| S3 | 股债性价比分位 < 10% | 逢低重仓优质权益 | 强 |
| S4 | 估值-宏观偏离度 > +1σ | 减仓、增配高股息 | 强 |
| S5 | 估值-宏观偏离度 ≥ +2σ | 大幅防御 | 强 |
| S6 | 供需比由降转升 | 增配周期/顺周期 | 中 |
| S7 | 高技术PMI 上行+建筑业PMI 下行 | 科技成长占优 | 中 |
| S8 | 建筑业PMI 见底回升 | 增配价值/地产链，利率上行对冲 | 中 |
| S9 | 叙事进入狂热期（CSAD 极端） | 主题兑现减仓 | 中 |
| S10 | 叙事收敛+宽度压力释放 | 均值回归布局窗口 | 中 |
| S11 | 固投同比持续下行（供强需弱加剧） | 规避产能过剩上游，聚焦内需政策链 | 弱-中 |
| S12 | "海外大厂营收−资本开支−国内出口"链二阶拐点 | AI 链减配至标配 | 弱-中 |
