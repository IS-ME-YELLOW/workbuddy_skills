## 框架总览：四层结构

张瑜的框架体系与郭磊（总量周期派）不同，是**"资金流 + 结构 + 主题叙事"派**：先识别宏观核心矛盾，再用存款分布读资金流向，用价格锚读供需，最后落到股债与行业比较。按以下顺序调用：

```
第一层 总量判断（当下宏观的核心矛盾是什么 → 三螺旋/双周期困境）
   └─ 第二层 资金流判断（钱在谁手里、往哪走 → 存款三部门框架）
        └─ 第三层 价格与结构判断（供需拐点与产业胜负手 → 五价格锚 + 中游制造）
             └─ 第四层 大类配置落地（股/债/金天平 → 看股做债 + GIORI）
```

- **第一层（总量矛盾）**：三螺旋、双周期困境、经济二分法、2014-2017 政策剧本
- **第二层（资金流）**：企业居民存款剪刀差、居民存款/M2、非银存款、流动性分层
- **第三层（价格与结构）**：以"价"定"价"五锚、新旧经济、中游胜负手
- **第四层（配置）**：股债夏普比率差 vs 债股收益差、存款搬家三支箭、黄金 GIORI

## 第一层：总量矛盾识别框架

### 1. 三螺旋框架（《解开三螺旋——2025 年度策略》，2024.11）

- **定义**：中国宏观的核心矛盾是三个自我强化的螺旋交织：**经济下行（利润-就业）+ 财富缩水（房价-信贷）+ 预期疲软（不敢消费-更弱利润）**。打破任何一环即可解套。（✅ 原文）
- **量化诊断**（✅ 原文，测算值）：
  - 去库存需求：工业企业产成品库存需去化 **1.4–4.3 万亿**；
  - 去产能需求：工业产能去化 **1.4%–2.0%**；
  - 财政力度：广义赤字率需达 **9.6%–11.0%**。
- **五大"解套"验证信号**（✅ 原文）：① 财政乘数回升；② 居民-企业存款循环重启；③ M1 真实回升（旧口径）；④ 一线城市房价企稳；⑤ PPI 同比转正。
- **选股应用**：五信号兑现数量 = 螺旋松解程度 → 决定权益仓位从防御到进攻的档位；信号未兑现前，配置偏防守（高股息/债）。

### 2. 双周期困境框架（《挣脱——2024 年度策略》，2023.12）

- **定义**：中国经济陷入"**绝对高实际利率 + 相对低名义利率**"的双周期困境——实际利率抑制实体需求，名义利率又已偏低、无进一步宽松空间。挣脱路径有三：① 等待海外降息（被动）；② 财政发力扩名义（慢）；③ **打出通胀预期（最优）**。（✅ 原文）
- **四大验证信号**（✅ 原文）：① 政策性银行超额投放 >0.8–1% GDP；② 企业居民存款剪刀差回升；③ M1 回升；④ 产能利用率回升。
- **选股应用**：与三螺旋五信号同用，构成"困境-挣脱"计分板；信号齐备 = 名义增速弹性恢复 → 周期与顺周期进攻。

### 3. 经济二分法（《寻找看不见的增长——2023 年中期策略》，2023.6）

- **定义**：把经济增长拆为**内生动能**（居民消费/民间投资）与**逆周期**（基建/政府支出）。政策大转向只发生在"内生动能掉档"时——红线（内生）逼近底线，稳增长才被迫出手。（✅ 原文）
- **配套概念——投资者可见 vs 不可见需求**（✅ 原文）：上市公司业绩只对应"可见需求"（地产销售、对欧美东盟出口、基建类支出、限额以上社零）；"不可见需求"（对俄中东非洲出口、民生类支出、限额以下社零）不进利润表。二者背离解释"体感经济"与 A 股盈利的裂口。
- **选股应用**：判断政策发力时点（内生增速逼近底线 = 稳增长加码前夜）；A 股盈利预测用可见需求口径而非总量 GDP。

### 4. 2014-2017 政策剧本框架（《"隧道的微光"》，2023.9 秋季策略会演讲）

- **定义**：当下（低地产+高基建+财政失血+美国高利率）与 2014-2017 宏观高度相似，政策推进遵循同一剧本四步：**① 债务置换降利息负担 → ② 融资方式创新（当年 PPP/今政策性金融工具，支出权上收中央）→ ③ 活跃资本市场 → ④ 地产端大招（当年棚改货币化/今城中村改造）**。前三步无效时第四步被倒逼出台。（✅ 原文）
- **政策倒逼点测算**（✅ 原文）：地产存量 280 万亿，**房价每跌 3–4% ≈ 一年名义 GDP 增量**，即全体增量被存量减值吞噬、宏观"平表"——这是政策质变触发线。
- **选股应用**：判断政策节奏所处步骤 → 预判下一步工具（如 2023.9 提示城中村改造）；步骤④临近 = 地产链/大盘价值博弈窗口。

## 第二层：资金流判断框架（张瑜最具辨识度的贡献）

### 5. 企业居民存款剪刀差（核心框架，2022 底-2023 初首创）

- **定义**：**剪刀差 = 企业存款同比 − 居民存款同比**。居民存款高增 = 居民不消费不投资、企业收不到钱；剪刀差回升 = 资金从居民回流企业 = 经济循环重启的最领先信号。（✅ 原文）
- **领先性**（✅ 原文）：
  - 领先 **PMI 约 6 个月**；
  - 领先 **万得全 A 净利润约 12 个月**；
  - 领先 **PPI 约 9–12 个月**。
- **窗口内实例**（✅ 观点实例，见 assets/views.md）：2024.8 起剪刀差见底回升，至 2026.5 已连续 21 个月向上修复 → 对应 2025 年下半年起 PMI 与 2026 年利润改善。
- **选股应用**：剪刀差 = 权益市场的"利润底"前瞻器。回升周期中段做多权益（此时利润尚未兑现、市场未定价）；剪刀差见顶回落领先利润顶约一年，作为减仓预警。

### 6. 居民存款/M2 与非银存款框架

- **居民新增存款/新增 M2**（✅ 原文）：衡量货币的"流通效率"与居民从"存"到"花"的意愿转换。比值回落 = 风险偏好改善 → 股票估值上行。2025.7–2026.2 居民新增存款同比**少增约 2 万亿**（✅ 观点实例）。
- **非银-居民存款剪刀差**（✅ 原文）：非银存款（证券保证金等）高增 = 欠配资金入市前兆，与万得全 A 成交额正相关。
- **存款搬家"三支箭"**（✅ 原文，看股做债系列 2025.6-7）：居民资金入市三阶段——**超额存（预防性储蓄堆积）→ 正常存（储蓄常态化）→ 花（入市/消费）**。第二支箭向第三支箭切换时，股市进入资金驱动主升。
- **选股应用**：三支箭位置 = 估值弹性开关——第三阶段利好高 beta 成长与券商；非银存款异动 = 成交额放大前兆，利好流动敏感型风格。

### 7. 流动性分层框架（《新舟已现，流"水"分层》，2026.6）

- **定义**：总量宽松口径失效，须分三层独立观测：**① 银行间流动性**（央行-大行层，量价工具）；② 资本市场流动性**（居民-非银层，即存款搬家）；③ 实体经济信用**（企业-居民层，即剪刀差）。三层可长期背离——"水"分层流动。（✅ 原文）
- **选股应用**：三层组合诊断资产环境：
  - ②强+③强 = 盈利与资金双牛（权益最优）；
  - ②强+③弱 = 流动性牛/估值牛（成长/主题占优，如 2025 下半年）；
  - ②弱+③强 = 基本面牛但缺增量资金（红利/价值占优）；
  - 双弱 = 债性资产占优。

### 8. 央行行为的条件规则（2026.3 金融数据点评）

- **定义**：央行政策利率调降的**必要条件 = PPI 同比回落 + 工业企业利润同比转负**。两个条件不同时满足，降息概率低。（✅ 原文）
- **选股应用**：作为债券仓位的事件型开关（详见 decision-rules.md 规则 6）。

## 第三层：价格与结构判断框架

### 9. 以"价"定"价"框架（《以"价"定"价"——2024 年中期策略》，2024.5）

- **总纲**：**此刻价比量重要**——价偏弱阶段，供需走向均衡比量高增更重要；"价"决定权益的三重弹性（增长弹性、盈利弹性、估值弹性）。（✅ 原文）
- **五价格锚**（✅ 原文，每个价格对应一个宏观结构问题）：

| 价格 | 角色 | 回答的问题 | 信号含义 |
|---|---|---|---|
| 煤炭价格 | **吹哨人** | 供需何时均衡走出低通胀 | 煤价向上异动 = 通胀/利润回升的最领先信号之一，**股债趋势性切换的关键指标** |
| 粗钢价格 | **识别器** | 新旧动能转换拖累期是否结束 | 装备制造占粗钢需求 34.3%、房屋建筑 26.6%；钢价回升 = 转型利润压制痛苦期结束 |
| 光伏价格 | **测压仪** | 贸易摩擦压力 | 光伏价稳/涨价 = 摩擦不再是物价约束 |
| 化工价格 | **排头兵** | 新一轮供给侧改革推进 | 石化化工低于基准水平产能约 30%；化工广泛涨价 = 新供改落地 |
| 房价 | **开关器** | 地产循环重启 | 见框架 10 |

- **领先信号补充**（✅ 原文）：在《挣脱》四信号（政策行投放/剪刀差/M1/产能利用率）基础上，2024.5 补充**煤炭价格 + 供给侧改革推进**两个信号。
- **选股应用**：五锚各自触发对应行业机会——煤价异动 → 周期/资源股；钢价回升 → 中游制造利润改善；化工涨价 → 供给侧受益化工龙头；房价企稳 → 地产链。

### 10. 地产循环双指标框架（2023.9 演讲 + 2024.5 中期策略）

- **定义**：地产新均衡的两个可验证信心指标（✅ 原文）：
  - **盖房子的人**：土地溢价率（开发商拿地 = 知行合一的信心）；
  - **买房子的人**：**居民购房超额收益率**（购房预期收益率 − 理财收益率）；2023.9 时购房一年跑输现金约 3 个点。
- **决定变量**（✅ 原文）：居民借贷决策取决于**实际房贷利率**而非名义；资产配置决策取决于购房超额收益率。
- **房价止跌条件**（⚠️ 外推：框架方向 ✅ 原文，"13 轮胜率约 85%"的具体数字来自公开演讲转述，以原文复核）：**房贷利率 < 租金收益率**；全球 13 轮经验中约 3 次同步、8 次领先（胜率 ~85%）。
- **选股应用**：两指标双双转正前，地产链只做政策博弈不做过剩产能；转正后地产链盈利修复行情。

### 11. 新旧经济框架 + 黄金交叉（2026.5 CMF 演讲）

- **定义**（✅ 原文）：
  - **新经济** = 信息传输/软件/租赁商务服务业 + 8 个装备制造行业；
  - **旧经济** = 房地产/建筑业 + 9 个原材料制造行业。
- **黄金交叉**（✅ 观点实例）：新经济在 **GDP（2025）、投资（2024）、营收/利润（2024）** 全面超越旧经济——中国经济的结构转型已过临界点，"旧尺难刻新舟"。
- **选股应用**：宏观叙事锚——旧经济指标（地产投资等）对总量解释力趋势性下降，估值锚切换到新经济；指数结构中新经济权重高的（创业板等）长期占优。

### 12. 中游制造产业比较框架（《旧尺难刻新舟，胜负定于中游》，2026.5）

- **定义**：过去 20 年中国经济"胜负手"三次转移：**2005-2015 上游（资源品）→ 2016-2021 下游（消费白马）→ 2025 起中游（装备制造）**。中游是 3-5 年维度的胜负手，地位类同 2016-2021 的消费。（✅ 原文）
- **核心逻辑**：**"需求在分散，供给在集中"**——需求端多元化（内需+新兴市场+设备更新），供给端中游行业集中度提升、产能格局最优。（✅ 原文）
- **月度代理指标**（⚠️ 外推：构造思路 ✅ 原文有"中游供需状态"提法，具体公式"需求同比−投资同比"为合理近似）：**中游供需状态 = 中游需求同比 − 中游投资同比**，作为产能利用率的月度代理。
- **配套判断（2026.5 后续观点）**：股>债、中游>消费、创业板>宽基。（✅ 观点实例）
- **选股应用**：行业配置第一排序规则——超配装备制造/中游（机械、电力设备、汽车、电子制造），规避下游消费与上游过剩原材料。

## 第四层：大类配置框架

### 13. 看股做债框架：股债夏普比率差 vs 债股收益差（2025.6-7 系列）

- **定义**：股债相对配置价值用两个互补指标（✅ 原文）：
  - **股债夏普比率差** = 股票夏普 − 债券夏普（滚动窗口）；衡量风险调整后收益的相对吸引力；
  - **债股收益差** = 10Y 国债收益率 − 万得全 A 股息率；衡量静态收益差。
- **2025 年特征**（✅ 观点实例）：两指标出现"**十年级别大背离**"——2025.11 股债夏普比率差 1.34（十年 72% 分位，股占优）而债股收益差 -0.03%（十年 11.9% 分位，债券静态收益已低于股息）。解读：低利率时代债券收益中枢下移，股息成为收益底线 → **权益配置价值觉醒**。
- **选股应用**：夏普差高位 + 收益差深负 = 债券资金被迫转配权益（类固收+策略、红利资产最受益）；两指标同向收敛 = 股债跷跷板正常化。

### 14. 股债跷跷板与债市趋势规则（2023.9 演讲 + 2025 看股做债）

- **规则一**（✅ 原文）：**政府杠杆率增速 − 居民杠杆率增速之差转负之前**，不必担心债券趋势性大反转（政府主导加杠杆+货币宽松期间，利率易下难上——国际经验同理）。
- **规则二**（✅ 原文）：债务置换（化债）进程过半之前，利率大幅上行 = "自加镣铐"，政策不可容忍。
- **规则三**（✅ 原文，2025）：存款搬家第三阶段（花）启动后，**不出现股债双牛——股牛债偏熊**；债券的超额来自久期博弈而非趋势。
- **选股应用**：债市仓位由规则一至三联合判定；股债双杀风险仅在"杠杆率增速差转负 + 通胀预期重启"同时出现时需警惕。

### 15. 黄金 GIORI 框架（2023.12 起"十年战略看多"，2025.5 方法论）

- **定义**：**GIORI（黄金隐含秩序重构指数）** = 黄金实际价格对 1974-2025 年五个宏观变量（通胀、赤字率、实际利率、央行购金、美元权重）OLS 回归的**残差**（R²=0.64 ✅ 原文）。残差 = 常规模型无法解释的"秩序重构"定价——地缘、去美元化、超范围冲突。
- **判断**（✅ 原文）：2023.12 俄乌冲突后黄金已脱钩美国实际利率（此前金融危机以来紧跟）；GIORI 目前处 **1970 年代以来最高值** → 十年维度战略看多。
- **选股应用**：GIORI 高位 = 黄金战略配置期（框架方向 ✅ 原文；具体仓位比例 ❌ 推断，见 decision-rules.md）；残差回落 = 秩序定价退潮，减持。

| 场景 | 调用框架 | 关键信号 |
