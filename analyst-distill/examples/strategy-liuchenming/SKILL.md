# 刘晨明（广发证券）策略分析框架

刘晨明，广发证券首席策略分析师（约 2024 年初由天风证券策略首席加入广发；2023 新财富策略研究第一名）。核心方法论："策略研究回答两个问题——该不该配置 A 股（大势），配置哪些类别的资产（结构）"。

## 一、使用流程（先读观点 → 体检 → 择时 → 风格 → 配置）

1. **读 `assets/views.md` 最新观点**（第一原则：观点时效性。任何输出前先核对最新快照，过期观点不得当作当前判断）。
2. **市场体检**：读 `references/indicators.md` 按跟踪优先级收集数据（第一优先级：全A均线系统、TMT成交占比、市场反应度、风格比值、ETF净流入、主线净利润增速）。
3. **大势择时**：调用 S1（百日线再布局）/S2（二十日线抄底）/S9（ETF净流入底部）判断仓位方向；用 S8（财政-PPI-ROE）判断基本面周期位置。
4. **风格判断**：调用 S5（利润增速差值）确定三类资产（周期/稳定/成长）谁占优；用 S3（成交占比）/S4（反应度二七法则）做交易层面择时；S6/S7 判断主线景气拐点与渗透率位置。
5. **结构落地**：三类资产分别调用——周期类看 S8+S11（困境反转恢复率）、稳定类看 S4+S12（红利现金替代）、成长类看 S6+S7+S10（景气拐点/渗透率/调整充分性）。
6. **输出**：仓位建议 + 三类资产配置结构 + 主线方向，并标注观点与信号分歧（若有）。

## 三、数据获取

按 `references/decision-rules.md` 数据-规则映射附录准备 JSON 字段：
- **指数行情/均线比值**（ratio_ma100/ratio_ma20/tmt_index）：westock-data 指数行情（日频→月末值，注意倒序反转）
- **财报增速**（profit_growth_gap/profit_growth_tmt/recovery_np）：westock-data 财报数据
- **宏观数据**（ppi_yoy/deposit_1y）：westock-data 宏观
- **成交额占比/ETF净流入**（tmt_turnout_pct/etf_inflow_daily_bn）：板块与 ETF 资金流数据
- **市场反应度**（reaction_*）：需按 7 指标合成（framework.md F8），数据不可得时人工输入并标注 ⚠️
- **渗透率/财政力度**（penetration_rate/fiscal_impulse）：第三方报告与两会后测算，人工输入
- 数据缺口处理：按 domain-adapters 降级方案标注"数据源不可用"，只做方向性判断，禁止合成值冒充

## 四、脚本使用

```bash
# 演示模式（合成数据，验证流程）
python scripts/screen.py

# 真实数据
python scripts/screen.py --data data.json

# 机器可读 JSON 输出（布尔标志，打到 stdout）
python scripts/screen.py --data data.json --json-out
```

输入 JSON schema 见 decision-rules.md 映射附录（history 为"字段→月份数组"转置结构，最新在末尾；extras 含 bull_market/black_swan/focus）。

## 五、红线与注意事项

1. **机构归属变化红线**：刘晨明约 2024 年初由天风证券跳槽至广发证券。引用观点必须注明"刘晨明（天风证券/广发证券·任职期）+ 日期"，两期观点不得混称机构（详见 assets/profile.md）。
2. **观点时效性红线**：任何输出先核对 views.md 最新快照；时点观点（如"2026.07 AI 进二退一"）不得当作当前判断。
3. **信号与观点分离**：信号计算不依赖观点快照；冲突时优先遵循信号并说明分歧。
4. **阈值来源纪律**：一切阈值带 ✅/⚠️/❌ 标注（见 decision-rules.md）；❌ 推断参数（如 S5 的 3 个月窗口）写明"最小假设，可替换"。
5. **必要非充分**：反应度低位对周期类资产需等待宏观政策催化；困境反转低 PB 是加成条件非触发条件。
6. **技能边界**：本技能仅覆盖刘晨明本人框架与观点；其他策略分析师框架请调用对应技能，本技能不包含、不评判他人框架。
7. **回测数字**：策略回测数字（如困境反转年化 42.3%）一律加"~"并注"取自公开报告，以原文为准"。
