# 傅静涛（申万宏源证券）策略分析框架

傅静涛，申万宏源证券研究所 A 股策略首席分析师、总量研究部联席总监，11 年策略研究经验（2015-2017、2019-2024 新财富最佳分析师等）。核心方法论："**看中期做短期，看长期做中期**"——基本面趋势投资 + 关键假设表推演，长/中/短期性价比分开讨论。

## 一、使用流程（先读观点 → 体检 → 阶段定位 → 择时 → 结构）

1. **读 `assets/views.md` 最新观点**（第一原则：观点时效性。任何输出前先核对最新快照，过期观点不得当作当前判断）。
2. **市场体检**：读 `references/indicators.md` 按跟踪优先级收集数据（第一优先级：隐含ERP与中美ERP比较、经风险调整收益率与短期性价比、公募净值刻度、供给出清行业占比、增量资金赛道集中度）。
3. **牛熊阶段定位**：调用 S5（牛市三拼图计分）+ S6（供给出清拐点）判断处于底部区域 / 结构牛 1.0 / 过渡期 / 全面牛 2.0（两段论框架 F4）。
4. **择时**：底部区域判定用 S1（长期性价比）+ S2（中期性价比）+ S4（底部特征计分）；反弹时点用 S3（短期超跌反弹）+ S11（输入性冲击识别）；结构高位预警用 S9（两段论过渡预警）。
5. **资金面确认**：S7（居民配置迁移空间）+ S8（赚钱效应阈值）验证增量资金正循环条件。
6. **结构落地**：有成长主线做成长（业绩消化估值能力是生命线）；无主线/过渡期用 S10（高股息审美切换）配红利低波；全面牛 2.0 阶段"周期搭台、成长唱戏"。
7. **输出**：阶段判断 + 仓位方向 + 结构建议，并标注观点与信号分歧（若有）。

## 三、数据获取

按 `references/decision-rules.md` 数据-规则映射附录准备 JSON 字段：
- **指数估值/ERP**（erp_pctile/us_erp_pctile/mainline_value_pctile）：westock-data 指数行情与估值数据（注意：不同数据源 ERP 绝对水平可能背离，仅分位/方向可用，绝对阈值不可跨口径比对）
- **财报增速/供给指标**（fa_formation_growth/cep_growth/capex_growth/supply_clear_pct/profit_growth_2fei）：westock-data 财报数据（供给出清占比需自算或以观点锚点输入并标注）
- **宏观数据**（ngdp_growth/居民存款）：westock-data 宏观
- **资金面**（fund_nav_peak/融资余额/被动规模）：基金净值统计与资金流数据，不可得时人工输入并标注 ⚠️
- **海外**（sox_drawdown_3m/美债收益率）：海外指数行情
- **情绪/分位合成**（risk_adj_pctile/short_term_value/破净与低价股占比分位）：需自行合成，数据不可得时人工输入并标注 ⚠️
- 数据缺口处理：按 domain-adapters 降级方案标注"数据源不可用"，只做方向性判断，禁止合成值冒充

## 四、脚本使用

```bash
# 演示模式（合成数据，验证流程）
python scripts/screen.py

# 真实数据
python scripts/screen.py --data data.json

# 机器可读 JSON 输出（布尔标志，打到 stdout）
python scripts/screen.py --data data.json --json-out
```

输入 JSON schema 见 decision-rules.md 映射附录（history 为"字段→月份数组"转置结构，最新在末尾；extras 含 bull_phase/growth_mainline_available/liquidity_easing/narrative_up/activity_cooling）。

## 五、红线与注意事项

1. **机构归属**：窗口期内（2023.08-2026.08）傅静涛始终任职申万宏源证券，无机构变更；引用观点统一标注"傅静涛（申万宏源）+ 日期"。注意与申万宏源首席策略分析师王胜、首席经济学家赵伟区分，观点不得混称。
2. **观点时效性红线**：任何输出先核对 views.md 最新快照；时点观点（如"2026 下半年全面牛"）不得当作当前判断。
3. **信号与观点分离**：信号计算不依赖观点快照；冲突时优先遵循信号并说明分歧。
4. **阈值来源纪律**：一切阈值带 ✅/⚠️/❌ 标注（见 decision-rules.md）；大量分位阈值系 ❌ 推断最小假设（原文为"历史高位/相对低位"定性表述），可替换；ERP 绝对阈值不可跨数据源比对。
5. **必要非充分**：性价比高位是反弹必要条件，需流动性缓解/政策催化兑现；美债收益率下行是打开指数上行空间的必要条件；底部特征计分是必要条件组而非充分条件。
6. **大周期上行不怕等**：中期看多基调下，波折期信号解读偏"蓄力"而非"反转"（傅静涛 2026.06 原则）。
7. **技能边界**：本技能仅覆盖傅静涛本人框架与观点；其他策略分析师框架请调用对应技能，本技能不包含、不评判他人框架。
8. **盈利预测数字**：全A两非增速预测（2024 +6.7%、2025 基准 +6.5%、2026 +14% 等）均为时点预测，进 views.md 不进规则，引用需注明预测时点。
