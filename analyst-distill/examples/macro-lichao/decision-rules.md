# 李超投资决策规则（decision-rules.md）

> 本文件将李超框架转化为**可执行的规则**：信号触发条件 → 动作。
> Phase 3 的 `scripts/screen.py` 依据本文件实现。
> 数据源：westock-data / neodata-financial-search 可查询宏观与行情指标。

## 规则 0：信号分级与总原则

- **强信号**（改变仓位/大类配置/风格切换）：中美博弈事件分级开关、利率区间档位切换、存款搬家确认、黄金四大利空触发
- **中信号**（结构调整/加减仓）：股息率-票息比价差、利率走廊与 DR001 位置、杠铃两端再平衡、央行购金持续性
- **弱信号**（战术/验证）：信息杠杆（搜索热度）、出口结构、K型物价结构验证、国际股息率比较
- 总原则（✅ 原文）：
  1. **"中美博弈是第一变量"**——风险偏好开关优先于一切估值与盈利比较；
  2. **"中美对抗买红利、中美合作买科技"**——杠铃两端切换口诀；
  3. **"债券票息过低时高股息红利股成为替代品"**——红利端定价机制；
  4. 行情性质是**流动性驱动**（利率下行），估值弹性大于盈利弹性。

## 规则 1：中美博弈风险偏好开关（核心规则，风格切换）

### 1.1 输入

- 中美关系事件序列（指标 21）：关税/出口管制/实体清单/金融制裁 = 对抗类；高层磋商/协议达成/管制豁免 = 合作类。

### 1.2 事件分级（❌ 推断：李超给出开关逻辑 ✅ 原文，但未公布事件量化分级表，以下为工程化设计，最小假设可替换）

| 级别 | 事件示例（❌ 推断分档） | 分值 |
|---|---|---|
| 强对抗 | 新增大范围关税/制裁升级、台海/军事冲突边缘 | −2 |
| 一般对抗 | 个别实体清单、摩擦性言论、管制扩围 | −1 |
| 中性 | 无重大事件、例行表态 | 0 |
| 一般合作 | 磋商重启、阶段性协议、豁免延长 | +1 |
| 强合作 | 重大协议落地、系统性关税下调 | +2 |

### 1.3 计算步骤（滚动月度窗口）

1. 汇总近 3 个月事件分值（窗口 ❌ 推断：原文未公布，默认 3 个月，可替换）；
2. 计算净分值 = Σ对抗/合作事件分值；
3. 与上一窗口比较方向。

### 1.4 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 对抗升级 | 净分值 < 0 且较上期恶化 | **切换向红利端**：红利超配、科技减配（✅ 原文口诀） |
| 合作缓和 | 净分值 > 0 且较上期改善 | **切换向科技端**：科技超配、红利减配（✅ 原文口诀） |
| 中性徘徊 | 净分值 ≈ 0 无方向 | 维持现有杠铃比例 |

## 规则 2：利率区间三档择时（权益/债券仓位总开关）

### 2.1 指标定义

- 10Y 国债收益率（指标 1）：**区间 1.5%–2.0%，中枢 1.75%**（✅ 原文，2025 系列报告）

### 2.2 计算步骤（月度更新）

1. 取当月 10Y 均值与月末值；
2. 判定档位：上沿以上 / 区间内 / 下沿以下；
3. 判断方向：近 3 个月斜率（❌ 推断：原文未公布确认窗口，默认 3 个月，可替换）。

### 2.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 流动性极致 | 10Y < 1.5%（区间下沿以下） | 权益弹性最大档：成长/久期资产进攻（流动性驱动行情高潮段） |
| 双牛延续 | 1.5%–2.0% 区间内、方向向下 | 股债双牛持有：均衡杠铃 + 债券久期中性偏多 |
| 趋势预警 | 10Y > 2.0%（区间上沿以上）且持续 ≥2 个月（N ❌ 推断） | **双牛逻辑受损**：减久期、降权益估值弹性敞口（10Y 有效上破 2% = 框架假设失效警戒线 ✅ 原文区间含义） |
| 中枢下台阶 | 突破前低、中枢自 1.75% 下移 | 红利比价逻辑再强化（见规则 3），红利端加仓 |

## 规则 3：股息率-票息比价（红利端仓位）

### 3.1 指标定义

- **比价差 = 央企红利指数股息率 − 10Y 国债收益率**（指标 13）
- 定价机制 ✅ 原文："债券票息过低时高股息红利股成为替代品"（资产荒比价逻辑）
- 参照锚：央企股息率约 4.4%（2026.04 ✅ 原文）；10Y 中枢 1.75% ✅ 原文 → 隐含比价差约 2.6 个百分点（⚠️ 外推：差值为上述两 ✅ 原文数值之差，李超未单独发布该差值序列）

### 3.2 计算步骤（月度更新）

1. 更新央企股息率与 10Y 收益率，计算比价差；
2. 计算比价差的近 12 个月分位（分位窗口 ❌ 推断，默认 12 个月，可替换）；
3. 叠加国际比较（指标 14）：中国 vs 美/欧/日股息率优势是否维持。

### 3.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 比价优势走阔 | 差值 > 近 12 个月 70% 分位（阈值 ❌ 推断） | 红利端加仓（"新黄金"逻辑强化） |
| 比价中性 | 差值处 30%–70% 分位 | 红利标配（杠铃防守端基准仓） |
| 比价优势收窄 | 差值 < 30% 分位，或国际比较优势显著收窄（中国股息率向他国收敛） | 红利减配预警（票息回升或股息率被买低） |

## 规则 4：存款搬家确认（权益增量资金开关）

### 4.1 指标定义（✅ 原文，存款搬家系列：三大跟踪指标）

1. **存款结构变化**：居民存款同比增速自高位回落（指标 7）；
2. **利率比价**：存款利率与理财/权益预期收益比价恶化（指标 6）；
3. **风险偏好代理**：非银存款高增（指标 10）+ 百度指数搜索热度跳升（指标 9，"信息杠杆" ✅ 原文）。

### 4.2 计算步骤（月度更新）

1. 检查指标 1：居民存款增速是否连续 ≥2 个月回落（N ❌ 推断，可替换）；
2. 检查指标 2：期间是否有存款利率下调（事件型）；
3. 检查指标 3：非银存款同比是否上行 + 当月百度指数较前 3 个月均值升幅是否 >50%（阈值 ❌ 推断：原文有"信息杠杆"定性概念，无量化阈值，可替换）；
4. 同步验证：成交额中枢抬升（指标 11）。

### 4.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 搬家确认 | 三指标中 ≥2 项触发 + 成交额放大 | **权益仓位上调**；结构偏向高 beta 成长、券商（增量资金偏好弹性） |
| 蓄水期 | 非银存款上行但存款增速未回落 | 预备档：维持仓位、加密跟踪频率 |
| 未启动 | 三指标均未触发 | 流动性行情仅靠机构资金：红利/确定性资产占优 |

> ⚠️ 历史参照：李超复盘历史 7 轮存款搬家（✅ 原文），每轮节奏不同；信息杠杆使本轮快于历史。具体轮次数据以系列报告原文为准。

## 规则 5：黄金配置规则（央行购金框架）

### 5.1 指标定义

- 第一驱动：**央行购金量**（指标 16，季度）；目标价：**伦敦金 5600 美元**（✅ 原文）
- 框架前提：金价脱离美国实际利率锚（✅ 原文）——实际利率（指标 18）仅作脱钩度验证，不作方向输入

### 5.2 计算步骤（季度更新 + 事件驱动）

1. 央行购金量连续两个季度为正且未显著衰竭 → 战略持有条件成立（"连续两季"为 ❌ 推断确认条件，可替换）；
2. 监测四大利空（✅ 原文）：① 金融危机流动性抛售；② 美国能源体系重构；③ 机器人广泛应用；④ 人造黄金——任一出现实质性进展（如实验/政策落地报道）即标记预警；
3. 交叉验证：金价与实际利率是否重新同向（脱钩失效预警）。

### 5.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 战略持有 | 购金持续 + 无利空显性化 | 黄金配置仓持有（50/50 底仓的黄金腿，✅ 原文方案） |
| 减仓预警 | 四大利空任一显性化 | 黄金减仓（利空清单 ✅ 原文；触发判定的"显性化"标准 ❌ 推断） |
| 框架失效预警 | 金价与实际利率重新稳定同向（连续 2 个季度，N ❌ 推断） | 重回传统框架定价，重新评估 |

## 规则 6：利率走廊与资金面确认（中信号）

- **输入**：DR001（指标 2）相对走廊位置；走廊宽度（指标 3：70BP→50BP，✅ 原文）
- **规则**（方向 ✅ 原文，分档 ❌ 推断）：
  - DR001 持续贴近走廊下沿（近 20 日均值 < 走廊中枢 −50% 宽度）→ 资金面宽松确认，利好债市 Carry 与权益贴现率；
  - 走廊收窄事件落地 → 资金利率波动下降 → 债市久期策略友好度提升；
  - DR001 快速上穿走廊上沿 → 流动性收紧预警，降杠杆、缩久期。

## 规则 7：杠铃结构维持与再平衡（默认配置结构）

- **默认结构**（✅ 原文）：科技（进攻端）+ 红利（防守端）二元杠铃；**不配置中间风格**（传统消费/周期，除非层级 ③ 政策脉冲）
- **切换**：由规则 1（中美开关）驱动两端比例；
- **再平衡**（❌ 推断：李超未公布再平衡纪律，最小假设可替换）：单端市值占比偏离目标 ±10 个百分点 → 再平衡回目标比例；再平衡频率月度。
- **叠加底仓**（✅ 原文）：50% 黄金 + 50% 科技的简单方案可作为大类底仓（与杠铃的红利端并列使用时注意黄金仓位与杠铃框架的口径统一，❌ 推断：两套方案叠加的具体合并规则原文未公布）。

## 规则 8：8+9 赛道行业筛选（科技端选股池）

- **池定义**（✅ 原文）：八大战略性新兴产业 + 九大未来产业；**人形机器人为终极赛道**
- **筛选步骤**：
  1. 候选行业是否落在 8+9 清单内（✅ 原文清单）；
  2. 与出口性价比三逻辑（平替/新兴市场出海/产业革命快车，✅ 原文）取交集者优先——交集 = 既有政策资源又有全球份额逻辑；
  3. 人形机器人产业链单列最高叙事权重（方向 ✅ 原文；权重数值 ❌ 推断）。
- **输出**：科技端超配行业清单；不满足 1 的行业仅战术参与。

## 规则 9：K型结构验证（框架健康度检查，弱信号）

- **验证口径**（框架 ✅ 原文；以下代理指标构造 ❌ 推断：原文用叙事表达，无标准化公式）：
  - 硅基通胀代理：算力/AI 硬件价格与资本开支（指标 30）上行；
  - 碳基通缩代理：服务价格与普通劳动力密集品价格（CPI 服务分项，指标 27）走弱。
- **判定**：两者同时成立 → K型框架有效，杠铃策略继续；若硅基端涨价消失 → 科技端盈利逻辑弱化（降进攻端弹性）；若碳基端再通胀 → 利率下行主逻辑受扰（触发规则 2 预警检查）。

## 规则 10：类平准基金兜底应对（极端下跌承接）

- **前提**（✅ 原文）：类平准基金（中央汇金等）构成 A 股尾部风险对冲，系统性崩盘概率被制度性压低。
- **触发判定**（❌ 推断：原文无量化定义，最小假设可替换）：主要宽基指数自近期高点回撤 >20% 且快速（≤2 个月），伴随官方资金增持公告或 ETF 异常放量 → 判定"兜底区"。
- **动作**：兜底区内**逢低承接而非止损**（✅ 原文方向）；承接标的优先杠铃两端（红利端确定性 + 科技端弹性）；兜底区解除（收复触发跌幅一半）后恢复正常规则。

## 规则 11：观点更新模板（观点快照见 assets/views.md）

> **设计原则**：方法论是永久的，观点是时效的。李超观点更新高频来源为月度宏观数据点评与政策事件解读，年度/中期策略为框架级更新。本规则只保留**结构模板**（永久），具体观点快照存放在 `assets/views.md`（时间倒序，顶部最新，旧快照标"已过期"）。**使用前必须先读 views.md 顶部最新快照**。

### 11.1 更新触发时机

- 年度策略（约 11-12 月，题目化：如《破局突围》《无限风光在险峰》《直挂云帆济沧海》）
- 中期策略（约 5-6 月，如《柳暗花明：股债双牛》）
- **月度宏观数据点评**（金融数据、PMI、物价、政治局会议/中央经济工作会议解读——观点微调最频繁来源）
- 专题系列（存款搬家系列、利率走廊系列、"新黄金"系列、黄金系列）

### 11.2 六维结构模板（新观点按此结构提炼入库）

| 维度 | 内容要求 | 示例（2026 年度，见 views.md） |
|---|---|---|
| 大类配置 | 股/债/金排序与行情性质 | 股债双牛延续；50% 黄金+50% 科技底仓 |
| 风格判断 | 红利 vs 科技两端比例与开关状态 | 杠铃；按中美博弈事件切换 |
| 结构方向 | 看好赛道（8+9 清单内） | 人形机器人（终极赛道）、AI、大健康 |
| 流动性判断 | 利率区间位置 + 存款搬家阶段 | 10Y 1.5-2% 区间；搬家进行时 |
| 宏观主题 | 年度叙事主线 | 经济走 K 型、资产举杠铃 |
| 风险点 | 框架失效条件 | 10Y 上破 2%；黄金四大利空；中美强对抗失控 |

### 11.3 入库与使用规则

1. 新快照插入 views.md 顶部，标注报告名/发布日期/有效期；
2. 快照不与信号计算耦合；观点与信号冲突时优先遵循信号并说明分歧；
3. 引用观点必须注明"截至 {日期} 的李超观点"。
