## 框架总览：四层结构

李超是**"决策层视角 + 流动性定价"派**宏观分析师：以政府决策的优先级序列读政策（四层次框架），以利率下行理解本轮行情性质（股债双牛），以中美博弈定风险偏好与风格开关（杠铃切换），最后落到赛道与工具（8+9 赛道、新黄金、黄金、兜底机制）。按以下顺序调用：

```
第一层 大局判断（政策与博弈的优先级 → 四层次决策框架 + 中美GDP追赶模型）
   └─ 第二层 流动性判断（行情性质与资金来源 → 利率下行股债双牛 + 利率走廊 + 存款搬家）
        └─ 第三层 风格判断（风险偏好与结构分化 → K型经济 + 二元杠铃 + 风险偏好开关）
             └─ 第四层 结构与工具（买什么、用什么兜底 → 8+9赛道 + 新黄金 + 出口性价比 + 黄金 + 类平准基金）
```

- **第一层（大局）**：四层次决策框架、中美名义GDP追赶模型
- **第二层（流动性）**：利率下行·股债双牛、利率走廊跟踪、居民存款搬家体系
- **第三层（风格）**：K型经济（硅基通胀碳基通缩）、科技+红利二元杠铃（中美博弈开关）
- **第四层（结构与工具）**：新质生产力二分法与 8+9 赛道、"新黄金"资产、出口性价比红利、黄金央行购金框架、类平准基金兜底、50/50 简单配置方案

## 第一层：大局判断框架

### 1. 四层次决策框架（总纲，贯穿全部研究）

- **定义**：中国政策决策的优先级序列——**① 中美博弈（最高）→ ② 社会稳定 → ③ 结构转型 → ④ 经济增长（最低）**。理解任何政策行为，先判断它服务于哪一层级。（✅ 原文，方法论总纲）
- **逻辑**：决策层视角推演——增长目标的优先级低于转型与稳定，因此"稳增长"不会无条件加码；政策发力时点与力度由更高层级约束决定（如博弈烈度、就业民生底线）。李超团队有政府背景履历，惯以"政策会怎么想"而非"市场想要什么"推演。（✅ 原文）
- **选股/配置应用**：判断政策超预期/低于预期的方向——市场用增长逻辑线性外推政策易误判；结构性政策（服务转型层级）持续性强于总量刺激（服务增长层级）→ 结构主线（新质生产力）优先于总量主线（周期博弈）。
- **窗口内实例**：2024.9.24 金融组合拳出台前后，李超以"社会稳定层级承压（就业、财富缩水）"解释政策转向的层级来源，而非单纯稳增长诉求（✅ 观点实例，见 assets/views.md）；2026.08 政治局会议解读强调"存量政策效能"——增量政策让位于已出台政策的效果释放，正是"增长层级优先级低"的体现（✅ 观点实例）。

### 2. 中美名义GDP追赶模型（长期大局锚）

- **定义**：以名义GDP比值刻画中美博弈的长期张力：假设美国名义增速 5%、人民币升值至 6.4，推演 **2027 年中美名义GDP比值约 70%**。（✅ 原文，报告测算；数字以原文复核）
- **逻辑**：追赶速度决定博弈烈度——比值逼近阈值时，美方遏制动机最强，科技封锁、贸易摩擦、金融制裁等"第一层级"事件频率上升；反之差距拉开则缓和。（✅ 原文方向）
- **选股/配置应用**：比值趋势 = 风险偏好长期底色。追赶加速期 → 红利/自主可控/军工占优；追赶放缓期 → 科技合作链、出海链修复。事件层面供规则 1（风险偏好开关）调用。
- **窗口内实例**：2024–2026 年窗口内美方对华科技限制反复加码，李超多次以追赶模型解释"博弈烈度中枢抬升"，支撑其红利底仓+科技弹性的杠铃结构（✅ 观点实例）。

## 第二层：流动性判断框架（李超行情观的主体）

### 3. 利率下行·股债双牛框架（本轮行情性质的总判断）

- **定义**：中国处于长端利率系统性下行周期，**10Y 国债收益率区间 1.5%–2%、中枢 1.75%**；利率下行同时驱动债券牛市与股票贴现率下行 → **股债双牛、流动性驱动行情**（区别于盈利驱动的分子行情）。（✅ 原文，2025 系列报告）
- **逻辑**：经济 K 型、名义增长中枢下移 → 资产荒 → 配置资金被迫追逐确定性收益；利率既是债券的价、也是股票的贴现率，双牛同源。（✅ 原文）
- **选股/配置应用**：① 行情性质判定——流动性驱动下，估值弹性大于盈利弹性，成长/久期资产受益；② 择时——利率区间三档定仓位（详见 decision-rules.md 规则 2）；③ 利率中枢每一次下台阶，红利资产比价逻辑强化一次（见框架 10）。
- **窗口内实例**：2025 年《柳暗花明》系列明确定调"股债双牛"，2025.11 提示"切换在冬季"（风格切换时点判断，✅ 观点实例，具体时点表述以当期报告原文为准）。

### 4. 利率走廊与货币政策观察框架

- **定义**：跟踪央行价格型调控的微观机制：2024.07 利率走廊新机制走廊宽度 **70BP** → 2026.06 收窄至 **50BP**；以 **DR001 相对走廊的位置**读资金面松紧，以走廊宽度变化读央行调控精细化意图。（✅ 原文，利率走廊系列三篇；数字以原文复核）
- **配套——货币政策四层新意**（✅ 原文）：① 总量与结构的组合运用；② 推动物价温和回升；③ 汇率稳定（盯 CFETS 一篮子）；④ 金融稳定（防空转、稳杠杆）。政策利率调降的预期管理依次看这四层。
- **选股/配置应用**：资金面松紧（DR001 贴近下沿=宽松）确认流动性环境；降准降息预测（2026 展望口径：50BP 降准 + 20BP 降息 ⚠️ 外推，以原文复核）作为久期与风格的催化事件。
- **窗口内实例**：2026.06 走廊收窄至 50BP，李超解读为流动性管理精度提升、资金利率中枢趋稳，利好债市 Carry 与权益贴现率稳定（✅ 观点实例）。

### 5. 居民存款搬家体系（增量资金判断）

- **定义**：居民超额储蓄向权益市场迁移的过程判断体系：**历史 7 轮存款搬家复盘** + **三大跟踪指标**（存款结构变化、利率比价、风险偏好代理）+ **四大观测视角**；并提出 **"信息杠杆"** 概念——移动互联网时代（百度指数等搜索行为）信息传播对搬家进程的加速放大。（✅ 原文，存款搬家系列三篇）
- **逻辑**：存款利率随利率下行走低 → 存款与权益/理财收益比价恶化 → 居民分批迁移；信息杠杆使每轮搬家速度快于历史可比轮次。（✅ 原文）
- **选股/配置应用**：搬家确认 = 权益增量资金 = 流动性行情从"机构抱团确定性"扩散到"居民追逐弹性"；触发条件与确认步骤见 decision-rules.md 规则 4。受益排序：高 beta 成长 > 券商 > 宽基。
- **窗口内实例**：2024.9.24 后成交额放大、开户与"基金"搜索热度跳升，李超以信息杠杆解释行情扩散速度超预期（✅ 观点实例）。

## 第三层：风格判断框架

### 6. K型经济框架（"硅基通胀、碳基通缩"）

- **定义**：经济不是整体通缩或通胀，而是 **K 型分化**：硅基链条（AI、算力、机器人——机器提供的产品与服务）**通胀**（涨价）；碳基链条（人提供的劳动与服务）**通缩**（价格下行）。（✅ 原文，2026 年度展望《直挂云帆济沧海》与 2026.07.30 演讲）
- **逻辑**：技术革命时期，机器替代人工 → 机器产出的资本品/算力供不应求涨价，人工服务供给过剩降价 → 总量平、结构分化。
- **选股/配置应用**：资产配置必须"举杠铃"（两端：通胀受益的硅基资产 + 现金流稳定的红利资产），中间地带（既无涨价也无稳定现金流的传统资产）最受损。行业验证用 PPI 结构与算力价格（见 indicators.md）。
- **窗口内实例**：2026 年度展望定调"经济走 K 型、资产举杠铃"，为 2026 全年配置主叙事（✅ 观点实例，见 assets/views.md）。

### 7. 科技+红利二元杠铃框架（核心配置结构）

- **定义**：默认配置结构为两端——**科技**（进攻端：新质生产力赛道）+ **红利**（防守端：央国企高股息"新黄金"）；核心择时口诀：**"中美对抗买红利、中美合作买科技"**——中美博弈烈度是两端切换的**风险偏好开关**。（✅ 原文）
- **逻辑**：对抗升级 → 外部不确定性上升、风险偏好收缩 → 资金退守确定性现金流（红利）；合作缓和 → 风险偏好扩张、贴现率下行弹性兑现 → 科技进攻。（✅ 原文）
- **选股/配置应用**：两端相对仓位由中美关系事件序列驱动（事件分级与切换规则见 decision-rules.md 规则 1/规则 7）；杠铃之外不配置中间风格（消费、传统周期仅在层级 ③ 政策脉冲时战术参与）。
- **窗口内实例**：2024–2026 窗口内美方科技管制升级阶段红利跑赢、双边磋商缓和窗口科技反弹，反复验证开关逻辑（✅ 观点实例；具体区间表现以当期报告原文为准）。

## 第四层：结构方向与工具框架

### 8. 新质生产力二分法与 8+9 赛道框架

- **定义**：产业结构二分——**传统生产力**（周期/消费/金融）vs **新质生产力**（大科技/大制造/大健康）；新质生产力具体化为 **8+9 赛道：八大战略性新兴产业 + 九大未来产业**，其中**人形机器人为"终极赛道"**。（✅ 原文，2024 年度展望《破局突围》系列）
- **逻辑**：结构转型是决策第三层级（高于增长），产业政策资源持续向新质生产力倾斜；传统生产力仅在更高层级承压时获得阶段性总量政策。
- **选股/配置应用**：科技端（杠铃进攻端）选股池 = 8+9 赛道映射的行业与主题（AI 算力、商业航天、低空经济、人形机器人、生物制造、量子科技等）；终极赛道人形机器人给最高叙事权重（⚠️ 外推：权重表述为方向性，具体标的与仓位以原文复核）。
- **窗口内实例**：2024 年度展望以 8+9 赛道为全年主线，此后人形机器人产业链成为 2025–2026 反复提示的产业级机会（✅ 观点实例）。

### 9. 出口性价比红利框架

- **定义**：中国出口的核心竞争力是"性价比"，三大产业逻辑：**① 平替**（国产替代进击）、**② 新兴市场出海**（一带一路/东南亚/中东非的份额扩张）、**③ 产业革命快车**（搭上 AI 等新一轮产业革命的供应链）。（✅ 原文）
- **逻辑**：性价比 = 同等质量更低价格 → 在全球购买力分化（发达市场消费降级+新兴市场增量）环境中份额持续提升。
- **选股/配置应用**：制造端选股的产业筛选器——三逻辑任一成立的行业（消费电子平替链、工程机械/汽车新兴市场链、AI 硬件供应链）优先；与 8+9 赛道取交集的标的最佳。
- **窗口内实例**：2024–2025 年新兴市场出口份额与 AI 硬件出口链高景气为该框架的持续验证（✅ 观点实例）。

### 10. "新黄金"资产框架（红利端的具体内容）

- **定义**：低利率时代的高股息央国企红利资产 + 国企资源品 = **"新黄金"**——承担传统黄金的"确定性价值贮藏"职能；量化锚：**中国央企红利指数股息率约 4.4%（2026.04）vs 美国 2.59% / 欧洲 3.58% / 日本 2.48%**。（✅ 原文，"新黄金"系列报告）
- **逻辑**：**债券票息过低时，高股息红利股成为替代品**——股息率-票息比价是核心定价机制（资产荒逻辑）；国际比较下中国红利资产股息率优势显著，吸引全球配置型资金。（✅ 原文）
- **选股/配置应用**：红利端（杠铃防守端）选股池 = 银行、公用事业、通信运营商等央国企红利 + 国企资源品（上游）；仓位由股息率-10Y 票息差驱动（decision-rules.md 规则 3）。
- **窗口内实例**："新黄金"系列 2026 年持续提示红利资产的比价优势，2026.04 的 4.4% vs 2.59% 为最新锚点（✅ 观点实例）。

### 11. 黄金央行购金框架（工具端：黄金）

- **定义**：本轮黄金定价脱离传统实际利率锚，**央行购金是第一驱动**——去美元化背景下各国央行持续增持黄金储备重构资产配置；目标价：**伦敦金 5600 美元**。（✅ 原文，黄金系列；目标价以原文复核）
- **逻辑**：实际利率框架解释力失效（金价与实际利率脱钩）→ 定价权重转移至官方购金与货币信用重构——黄金正在成为新货币体系的"锚资产"之一（2026.08 李超进一步提出 AI 美元货币锚观点，美元体系自身在寻找新锚）。（✅ 原文方向）
- **四大利空风险**（✅ 原文）：① 金融危机流动性抛售（现金挤兑式卖出）；② 美国能源体系重构（美元找到新实物锚）；③ 机器人广泛应用（生产率革命重塑货币需求）；④ 人造黄金（技术突破冲击供给）。
- **选股/配置应用**：跟踪央行购金量与金价-实际利率脱钩度（decision-rules.md 规则 5）；四大利空任一显性化 → 减仓，否则战略持有。A股映射：黄金股、贵金属资源品（与"新黄金"资源品交叉）。
- **窗口内实例**：2024–2026 窗口内央行购金与金价脱钩实际利率持续验证，5600 美元目标价为窗口末端最新口径（✅ 观点实例）。

### 12. 类平准基金与尾部风险框架 + 50/50 简单配置方案

- **定义（类平准基金）**：以中央汇金等为代表的类平准基金在市场极端下跌时买入兜底，构成 A 股**尾部风险的对冲机制**——系统性崩盘概率被制度性压低。（✅ 原文）
- **定义（50/50 方案）**：李超给出的极简配置方案：**50% 黄金 + 50% 科技股**——分别对应秩序重构（货币信用）与技术革命（增长叙事）两大时代主题。（✅ 原文，方向性方案）
- **逻辑**：有兜底 → 极端下跌是机会而非风险；两大主题是未来十年确定性最高的方向。
- **选股/配置应用**：① 极端下跌（快速深跌+类平准基金出手信号）→ 逢低承接而非止损（decision-rules.md 规则 10）；② 50/50 为"懒人底仓"，与杠铃框架（规则 7）叠加使用：杠铃定风格结构，50/50 定大类底仓。
- **窗口内实例**：2024 年初流动性危机式下跌后类平准基金入场、市场见底修复（✅ 观点实例）。
