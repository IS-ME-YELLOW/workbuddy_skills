## 【当前有效】2026-08 政治局会议解读："存量政策效能"

- **发布**：2026-07 底政治局会议，2026-08 点评 | 李超/浙商宏观团队
- **核心观点**：政策重心从增量加码转向**存量政策效能释放**——已有政策工具的组合效果进入兑现阶段，短期不急于再出大招。
- **配套解读**：2026.08 七月信贷数据点评延续"宽货币→宽信用传导需时间"判断；提出 **AI 美元货币锚**观点——美元体系在寻找新锚（AI 生产率），与黄金货币锚重构叙事互为印证。
- **配置含义**：增量政策预期降温 → 维持杠铃结构不动；流动性宽松格局未变（支撑股债双牛前提）。
- **有效期**：至下一次政治局会议/中央经济工作会议解读

## 【当前有效】2026-07-30 建投读书会演讲（K型分化）

- **发布**：2026-07-30 | 李超
- **核心观点**：系统阐述 **K 型经济**——硅基通胀、碳基通缩；经济不是单边的通缩或复苏，而是链条间分化；资产配置必须举杠铃（科技+红利两端）。

## 【当前有效】2026 年度展望《直挂云帆济沧海》：经济走 K 型、资产举杠铃

- **发布**：2025-11/12 | 李超
- **核心观点**：
  1. **经济走 K 型**：硅基（AI/算力/机器人）链条通胀，碳基（人工服务）链条通缩；
  2. **资产举杠铃**：科技 + 红利二元配置，口诀"中美对抗买红利、中美合作买科技"；
  3. **新黄金**：央企红利股息率约 4.4%（2026.04 更新口径）vs 美 2.59%/欧 3.58%/日 2.48%，全球比价优势显著；
  4. **黄金**：央行购金驱动的战略看多延续，伦敦金目标 5600 美元；
  5. **简单方案**：50% 黄金 + 50% 科技股底仓；
  6. 货币政策展望：50BP 降准 + 20BP 降息（⚠️ 以原文复核）。
- **配置含义**：全年主线 = K型 + 杠铃 + 新黄金 + 黄金。
- **有效期**：2026 年度（中期未有框架级更新）

## 演化主线（供快速理解）

**"牛市旗手" → "流动性双牛" → "K型杠铃"**：

1. **2023（夺回牛市）**：政策转向判断先行，牛市叙事建立——风格最进攻的时期；
2. **2024（破局突围/924）**：以四层次框架解释政策转向来源；8+9 赛道 + 出口性价比成为结构主线；利率下行逻辑开始主导叙事；
3. **2025（股债双牛）**：方法论成熟期——10Y 区间定档、存款搬家体系化（三指标+信息杠杆）、中美开关口诀化；
4. **2026（K型杠铃）**：叙事完成体——K型分化为宏观底色，杠铃为配置答案，新黄金（红利）与黄金（央行购金）双"金"并立，50/50 极简方案收口。

> 演化特征：从"方向判断"（看多/看空）逐步沉淀为"结构判断"（怎么配），宏观叙事始终服务于配置结构——这也是本技能 decision-rules.md 以风格切换与仓位规则为主体的原因。
