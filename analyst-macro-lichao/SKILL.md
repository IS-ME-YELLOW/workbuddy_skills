# 李超 · 浙商宏观分析框架

本技能将浙商证券首席经济学家李超的宏观研究框架蒸馏为可执行的选股/配置决策体系。
定位：**先定大局开关（中美博弈定风险偏好），再测流动性（利率与存款搬家定行情性质），后落杠铃结构（科技+红利两端切换）**。

## 使用流程（按顺序执行）

1. **读取最新观点**：先打开 `references/views.md` 顶部，确认李超当前最新观点（截至日期）。观点是时效的，勿直接使用历史快照。
2. **大局开关诊断（第一层）**：调用 `references/framework.md` 框架 1（四层次决策框架）与框架 7（风险偏好开关），按 `references/decision-rules.md` 规则 1 汇总近 3 个月中美事件净分值，判定当前是"对抗升级/合作缓和/中性徘徊"——这决定杠铃倒向哪一端，优先级高于一切估值与盈利比较。
3. **流动性体检（第二层）**：运行 `scripts/screen.py`，检查：10Y 国债所处档位（1.5%-2% 区间、中枢 1.75%）、利率走廊与 DR001 资金面、存款搬家三大指标（居民存款增速/非银存款/百度指数信息杠杆）+ 成交额验证。流动性决定行情性质（股债双牛是否延续）与权益弹性档位。
4. **风格与结构（第三层）**：结合 S1/S2 开关信号与 S5 股息率-票息比价，确定科技/红利两端比例；科技端选股池用 8+9 赛道筛选（规则 8），红利端用"新黄金"逻辑（央企红利 + 资源品）；S12 验证 K 型结构是否健康。
5. **配置落地（第四层）**：结合 `references/views.md` 最新观点与信号汇总，输出：权益仓位档位、杠铃两端比例、黄金配置（央行购金框架 + 5600 美元目标 + 四大利空监测）、50% 黄金 + 50% 科技底仓方案；极端下跌时按 S11 类平准基金兜底区"逢低承接而非止损"。
6. **输出规范**：所有观点引用必须注明日期（如"李超 2026-08 政治局会议解读"）；信号与观点冲突时优先遵循信号并说明分歧；参数来源标注（✅原文/⚠️外推/❌推断）必须保留。

## 数据获取

- 利率类（10Y 国债收益率、DR001、OMO 7D、存款利率）：用 `westock-data` 或 `neodata-financial-search` 查询中债收益率曲线与银行间回购利率；日频数据取月均。
- 存款类（居民存款同比、非银存款同比）：westock-data 查询金融机构信贷收支表月度数据。
- 行为类（百度指数、A股成交额）：百度指数需外部获取（信息杠杆代理）；成交额用 westock-data 查询沪深两市。
- 红利类（央企红利指数股息率）：westock-data 查询央企红利类指数；国际比较（美/欧/日股息率）需外部数据源。
- 黄金类（央行购金量、伦敦金、实际利率）：世界黄金协会季度数据 + 行情查询；四大利空为事件型，靠新闻跟踪。
- 中美事件序列：无结构化数据源，按 decision-rules.md 规则 1 的事件分级表人工打分（❌ 推断分档）。
- 指标口径、频率、所属框架详见 `references/indicators.md`。
- 个股/行业筛选：用 `westock-tool` 按 screen.py 输出的条件做筛选（科技端限 8+9 赛道，红利端限央企红利/资源品）。

## 脚本使用

```bash
python scripts/screen.py                  # 演示模式（内置合成数据，验证流程）
python scripts/screen.py --data macro.json  # 用真实宏观数据文件计算信号
python scripts/screen.py --json-out        # 输出机器可读 JSON（布尔标志）
```

- screen.py 输入：宏观数据 JSON（13 个 history 字段 + 4 个 extras，schema 见脚本头部说明）；输出：S1-S12 信号表 + 仓位/杠铃/黄金/流动性建议。
- 信号 S1-S12 编号为**工程化设计**（李超没有此编号体系），底层阈值来源见各规则标注与脚本参数区。
- 数据来源：优先 westock-data / neodata 查询结果，由调用方填入 JSON。

- 本技能输出为分析参考，非投资建议；宏观框架历史表现不代表未来。
- 观点与规则分离：`references/views.md` 是时效快照，`references/` 是方法论，勿混用。
- **机构归属**：李超 2020 年由华泰证券加盟浙商证券至今（执业编号 S1230520030002）。本技能知识窗口（2023.8-2026.8）内全部为浙商期间；引用观点须注明"李超（浙商证券）{日期}观点"；若其未来任职变化，须重新核验归属。
- **观点时效**：李超更新频率高（月度宏观数据点评与政策会议解读即可能微调），任何使用前必须核对 views.md 顶部最新快照。
- **参数来源标注**：所有阈值带 ✅/⚠️/❌ 标注——推断值（❌，如事件分级表、分位阈值、再平衡带宽）不冒充原文，拿到真实值应替换。
