# 黄伟平债市投资决策规则（decision-rules.md）

> 本文件将黄伟平框架转化为**可执行的规则**：信号触发条件 → 动作。
> Phase 3 的 `scripts/screen.py` 依据本文件实现。
> 数据源：westock-data / neodata-financial-search 可查询债券行情、宏观、资金面指标。

## 规则 0：信号分级与总原则

- **强信号**（改变久期中枢/大类配置）：核心矛盾阶段切换（规则 1）、物价回升斜率确认（规则 2）、长债定价锚切换（规则 6）、资产性价比排序极值（规则 12）
- **中信号**（杠杆/结构/品种调整）：货币政策框架状态（规则 3）、资金面收敛（规则 4）、存单利差脉冲（规则 5）、期限利差压缩（规则 7）、二永债利差分位极值（规则 8）、机构行为异动（规则 11）
- **弱信号**（战术节奏/波段）：布林带交易（规则 9）、品种利差轮动（规则 10）
- 总原则（✅ 原文）：
  1. **债市研究的落脚点是利率水平，利率本质取决于宏观流动性高度**（✅ 2026.6 访谈）；
  2. **研判债券资产的核心是判断核心矛盾处于哪个阶段**——"过去几年债市核心矛盾的切换：从信用收缩到资产配置再平衡""当前债市核心矛盾进入新阶段：物价+资金流向开始受市场关注"（✅ 2025.11）；
  3. **长债定价锚已从政策利率转向货币市场利率**（✅ 2026.6）；
  4. **机构行为是边际定价核心**——"配置盘先行、交易盘跟进"（✅ 2024.12）。

## 规则 1：核心矛盾阶段定位（方向总开关 ✅ 框架原文，工程化判定 ❌）

### 1.1 指标定义

债市核心矛盾三阶段（✅ 原文）：
- **信用收缩阶段**：社融增速回落、地产下行、资产荒 → 债牛主线；
- **资产配置再平衡阶段**：低利率下股债性价比/存款搬家主导 → 债市波动加大；
- **物价+资金流向阶段**：通胀回升斜率 + 存款分流 → 债市逆风期。

### 1.2 计算步骤（月度更新）

1. 读社融同比（I-29）、PPI/CPI（I-27/28）、存款搬家信号（I-33）；
2. 判定阶段（❌ 推断工程化，可替换）：
   - 社融同比下行且 PPI 低位 → 信用收缩阶段；
   - 社融企稳、利率低位、存款搬家明显 → 资产配置再平衡阶段；
   - PPI 触底回升斜率变陡（连续 2 个月环比改善）→ 物价+资金流向阶段。

### 1.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 信用收缩 | 社融下行 + PPI 低位（❌ 推断阈值） | 债牛主线，持有久期 |
| 资产配置再平衡 | 社融企稳 + 利率低位 + 存款搬家（❌） | 波段操作，关注股债比价 |
| 物价回升 | PPI 连续 2 月环比改善 + 斜率陡（❌） | 防守，缩短久期（2-3 季度为重点） |

## 规则 2：物价回升斜率（逆风期开关 ✅ 原文）

- **触发条件（可计算）**：PPI/CPI 同比走势进入"三阶段回升"路径。
- **计算步骤**：
  1. 观察 PPI 同比是否触底反弹（基数原因，✅ 第一阶段）；
  2. 观察货币政策协同 + 反内卷政策落地（✅ 第二阶段）；
  3. 观察 PPI 向 CPI 传导（✅ 第三阶段）。
- **量化代理**（❌ 推断，可替换）：PPI 同比连续 2 个月环比为正 + CPI 同比回升 = 斜率确认。
- **信号输出**：
  - 斜率陡峭确认（重点 2-3 季度）→ **债市防守，缩短久期**（"通胀持续抬升，债市或迎来较长时间的逆风期" ✅ 2025.11）；
  - 斜率平缓/未确认 → 债市压力有限，维持中枢判断。

## 规则 3：货币政策框架状态（传导效率信号 ✅ 原文）

- **触发条件（可计算/可观察）**（✅ 2026.7 货币政策框架转型分析）：
  1. **DR001 是否在利率走廊内**（走廊 = 政策利率 ±25BP，2026 收窄至 50BP 宽度）；
  2. **短端向长端传导是否顺畅**（资金调控"时间"换利率"空间"）；
  3. **金融市场稳定**（宏观审慎管理）。
- **计算步骤**：
  1. 计算 DR001 与 OMO7D 的偏离（绝对利差；2023 年均 37BP → 2024-26 年 9/13/9BP ✅）；
  2. 计算 R001-DR001 利差（流动性分层；2023 年 15BP → 2024-26 年 11/8/6BP ✅）。
- **信号输出**：
  - 传导顺畅（利差收窄至低中枢）→ 货币政策框架成熟，资金利率波动减小，套息空间压缩；
  - 传导不畅（利差走阔）→ 资金面波动加大，降杠杆；
  - 走廊收窄/政策利率新工具切换（如隔夜逆回购成主利率）→ 资金利率中枢下行确认（✅ 2026.6 陆家嘴论坛后）。

## 规则 4：资金面松紧（杠杆开关 ✅ 方向，阈值 ⚠️/❌）

- **触发条件（可计算）**：DR007（20 日均值）相对 OMO7D 的偏离 + 大行净融出季节性。
- **计算步骤**：
  1. 计算 DR007 20 日均值 − OMO7D；
  2. 观察大行净融出是否超季节性；
  3. 判断：DR007 持续高于 OMO7D + 大行净融出收缩 → 资金收敛；DR007 低于 OMO7D + 净融出超季节 → 资金宽松。
- **量化阈值**（❌ 推断带宽，可替换）：偏离 > +15BP = 资金收敛；偏离 < −15BP = 宽松。
- **信号输出**：
  - 资金收敛 → 降杠杆，缩短负债端久期；
  - 资金宽松 → 加杠杆套息窗口（"资金利率或持续低位运行" ✅ 2026.4 华西流动性框架同思路，黄伟平 2026.6"流动性冗余在银行间市场明显"✅）。
- **窗口实例**：2026 年上半年超预期宽松（✅ 2026.6）；"央行净回笼中长资金 → 1-2 个月后资金回归均衡"（✅ 黄伟平 2026.6 分析框架）。

## 规则 5：存单利差脉冲（负债压力信号 ✅ 原文）

- **触发条件（可计算）**：1Y AAA 存单 − OMO7D 利差脉冲走阔。
- **计算步骤**：
  1. 计算 1Y AAA 存单利率 − OMO7D；
  2. 观察央行投放-存单量价组合（加量投放后存单仍放量提价 = 结构性融资压力 ✅）。
- **量化阈值**（⚠️ 外推，以原文复核）：利差脉冲走阔至近年高分位（❌ 推断：滚动 1 年 80% 分位）→ 负债压力释放后配置窗口。
- **信号输出**：
  - 存单利差脉冲走阔 + 提价放量 → **负债压力显现，短端有配置价值，逢调整配置存单/短债**；
  - 利差低中枢窄幅 → 套息空间有限，不追短端。

## 规则 6：长债定价锚切换（估值信号 ✅ 原文）

- **触发条件（可计算）**：政策利率 vs 资金利率两个锚下的长债估值分歧。
- **计算步骤**（✅ 2026.6 中期策略）：
  1. 从**政策利率锚**视角：10Y − OMO7D 判断长债估值（中低水平 ✅）；
  2. 从**资金利率锚**视角：10Y − DR007（或资金利率中枢）判断估值（中高水平 ✅）；
  3. 两者分歧 = 定价锚切换进行时。
- **信号输出**：
  - 政策利率未动但资金利率实质下行 → 长债定价锚已切换至资金利率，**10Y 下探仍有支撑**（不因政策利率未降而看空）；
  - 资金利率中枢回升 → 长债估值压力显现，防守。

---

## 规则 7：期限利差压缩空间（曲线信号 ✅ 原文）

- **触发条件（可计算）**：10-1Y、30-10Y 期限利差位置。
- **计算步骤**（✅ 2026.6）：
  1. 10-1Y：回到 2024 年前水平 → 存在压缩空间；
  2. 30-10Y：回升到 2022 年水平 → 压缩空间更大；
  3. 结合名义经济权重（2024 以来名义经济在期限利差定价权重抬升 ✅）。
- **量化阈值**（⚠️ 外推）：10-1Y 处于近 3 年 70% 分位以上 + 30-10Y 处于 60% 分位以上（❌ 推断）→ 曲线偏陡、长端相对有吸引力。
- **信号输出**：
  - 期限利差偏宽 + 基本面预期偏乐观 → **超长/长久期性价比抬升**（呼应规则 12）；
  - 利差压缩至低位 → 止盈长端。

---

## 规则 8：二永债信用利差分位（品种择时 ✅ 原文回测规则）

- **触发条件（可计算）**：二永债信用利差滚动 1 年分位数。
- **计算步骤**：
  1. 计算 5Y AAA- 二永债信用利差（I-20）；
  2. 计算滚动 1 年分位数（I-21）。
- **量化阈值**（✅ 原文 2026.8.3）：**分位 70% 附近接近见顶（可参与）、10% 附近接近见底（获利了结）**。
- **信号输出**：

| 分位 | 含义 | 动作 |
|---|---|---|
| > 70% | 利差接近见顶 | 配置/参与信号（类利率品种高性价比） |
| 10-70% | 中性区间 | 持有为主，不追不杀 |
| < 10% | 利差接近见底 | 获利了结，警惕反弹 |

---

## 规则 9：二永债布林带交易（波段信号 ✅ 原文）

- **触发条件（可计算）**：信用利差布林带（均线 ±2σ，❌ 推断 σ 倍数，可替换）。
- **量化阈值**（✅ 方向 2026.8.3）：
  - 触及**上轨** = 超卖（利差有下行动力）→ **潜在参与信号**；
  - 触及**下轨** = 超买（利差触底反弹压力）→ **潜在获利了结信号**。
- **背景约束**：布林带对长端二永交易同样有效（✅）；与分位信号（规则 8）叠加确认。

## 规则 10：品种利差轮动（结构信号 ✅ 原文）

- **触发条件（可计算）**：永续-二债品种利差、二债-中票等品种利差。
- **量化阈值**（✅ 2026.8.10 品种轮动报告）：

| 永续-二债利差 | 含义 | 动作 |
|---|---|---|
| > 15BP | 品种利差高位 | **积极超配永续**（弹性 1.4-1.5 倍 ✅） |
| 8-15BP | 中性偏高 | 适度超配 |
| < 8BP | 低位 | 超额收益不显著，均衡配置 |

- **补充**（✅ 2026.8.3）：品种利差中枢整体下移（比价 104-106% → 101-103%），除绝对值外跟踪**缩小时间区间的分位数或布林带**有效性更高（⚠️）。

## 规则 11：机构行为异动（边际定价信号 ✅ 方向，量化 ❌）

- **触发条件（可观察）**（✅ 2026.6 中期策略）：
  1. 保险机构是否欠配（2026.6 判断"并未欠配"）；
  2. 公募基金久期拥挤度（"较为拥挤但短期并不一定反转"）；
  3. 理财哑铃策略（大量净买入 30Y）；
  4. 银行负债端量增价降 → 买债积极性抬升（大行更显著）；
  5. 固收+基金扩容（2025 下半年快速扩容）。
- **量化代理**（❌ 推断）：基金净买入连续 3 周为负 + 保险净买入转正 = 利差见底回升特征（✅ 二永债框架的机构特征描述）。
- **信号输出**：
  - 交易盘拥挤（久期一致拉长）→ 防回调，但"短期不一定反转"——不机械做空；
  - 配置盘力量增强（银行/保险增配）→ 压利差行情延续，持有久期；
  - 理财赎回异动 → 负反馈预警，降杠杆。

## 规则 12：资产性价比排序（久期/品种总开关 ✅ 原文）

- **触发条件（状态判断）**：综合框架 1/2/6/7 判断当前资产性价比排序。
- **当前排序**（✅ 2026.6 中期策略原文）：**超长期国债 > 长久期国债、政金债 > 普信债、二永债 > 存单**。
- **节奏框架**（✅ 2026.6）：6-12 月长债利率"倒 N"形——
  - 6-7 月：10Y 1.70-1.80%，压利差行情，可持有久期；
  - 7 月下旬-9 月：回调风险（稳增长政策加力），10Y 1.75-1.85%，防守；
  - 四季度：10Y 回落至 1.65-1.75%，政策高峰过去后重新进攻。
- **工程化定位**（❌ 推断）：按当前月份落入的区间段执行对应久期策略；区间参数每年随年度/中期策略更新（规则 13）。

## 规则 13：观点更新模板（观点快照见 assets/views.md）

> **设计原则**：方法论是永久的，观点是时效的。黄伟平观点随年度策略/中期策略/专题报告/事件点评更新，本规则只保留**结构模板**（永久），具体观点快照存放在 `assets/views.md`（时间倒序，顶部最新，旧快照标"已过期"）。**使用前必须先读 views.md 顶部最新快照**。

### 13.1 更新触发时机

- **年度策略**（约 11 月，申万投资年会，题目化：如 2026 年"波折中寻机"）
- **中期策略/夏季策略**（约 6 月，更新下半年区间锚：如 2026.6《K型深化+宽松范式重塑》）
- **专题框架报告**（二永债框架、存单框架、货币政策转型、预期差择时等）
- **事件点评**（陆家嘴论坛、政治局会议、央行操作变化、负反馈）
- **公开访谈/年会发声**（框架级阐述）

### 13.2 六维结构模板（新观点按此结构提炼入库）

| 维度 | 内容要求 | 示例（2026 中期策略） |
|---|---|---|
| 核心矛盾 | 当前债市核心矛盾阶段 | "物价+资金流向"；K 型分化 |
| 点位锚 | 10Y/30Y 区间、节奏形态 | 6-7 月 1.70-1.80%、8-9 月 1.75-1.85%、Q4 1.65-1.75%；"倒N"形 |
| 流动性范式 | 资金面状态、定价锚 | 宽松范式重塑；长债定价锚转向货币市场利率 |
| 政策取向 | 货币/财政组合 | "宽货币+宽财政+稳信用"；物价回升 2-3 季度 |
| 策略排序 | 资产性价比排序 | 超长 > 长久期 > 普信二永 > 存单 |
| 风险点 | 什么会打脸 | 货币政策转向超预期、机构负债成本抬升超预期、降息后利多出尽、财政超预期 |

### 13.3 入库与使用规则

1. 新快照插入 views.md 顶部，标注报告名/发布日期/机构/有效期；
2. 快照不与信号计算耦合；观点与信号冲突时优先遵循信号并说明分歧；
3. 引用观点必须注明"截至 {日期} 黄伟平（{任职机构}）观点"——2023.8-2024 属兴业证券、2024 至今属申万宏源；
4. **年度点位区间参数（规则 12）每年随新年度/中期策略强制更新**。

## 规则 14：信号触发汇总表（screen.py 输出框架）❌ 工程化设计

> **重要**：黄伟平**没有** S1-S13 这套编号体系。下表是把散落在规则 1-13 的方法论**编码为可执行信号**的工程化翻译——编号与触发条件为本设计，底层阈值来源见各规则标注。

| 信号编号 | 触发条件 | 动作 | 强度 |
|---|---|---|---|
| S1 | 核心矛盾进入"物价+资金流向"阶段（PPI 连续 2 月环比改善） | 债市防守，缩短久期 | 强 |
| S2 | 物价回升斜率确认（PPI→CPI 传导启动） | 防御为主，久期中性偏短 | 强 |
| S3 | 货币政策框架成熟（DR001-OMO 利差 <10BP，传导顺畅） | 资金波动减小，套息空间压缩 | 中 |
| S4 | 资金收敛（DR007 20 日均值 > OMO + 15BP 或大行净融出收缩） | 降杠杆 | 中 |
