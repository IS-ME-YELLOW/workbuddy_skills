## 框架总览：三层递进结构

黄伟平框架是**"核心矛盾定位 + 流动性范式 + 资产定价锚 + 机构行为 + 品种策略"派**。其方法论本身经历"通胀 → 通胀+增长 → 流动性 → 新质生产力/机构行为与资产配置"的演化（✅ 2024.11 申万宏源官方访谈"走近申万宏源研究人"），因此他的框架强调整体判断**债市核心矛盾处于哪个阶段**，再用**流动性范式**（货币政策框架转型）解释利率中枢，用**机构行为**解释边际定价，最后落到**资产性价比排序与品种选择**。按以下顺序调用：

```
第一层 决策内核（核心矛盾定位：信用收缩 → 资产配置再平衡 → 物价+资金流向）
   └─ 第二层 定价范式（货币政策框架转型 → 流动性范式 → 长债定价锚切换 → 期限利差）
        └─ 第三层 结构定价（机构行为 + 结构性资产荒 + 供需）
             └─ 第四层 策略落地（资产性价比排序 → 二永债宏观-中观-微观定价 → 存单/曲线/品种）
                  └─ 输出：久期/杠杆/品种/期限建议 + 波段节奏（倒N形）
```

## 第一层：决策内核

### 1. 债市核心矛盾切换框架（✅ 原文）

- **定义**（✅ 2025.11.18 申万 2026 投资年会、2026.6 夏季策略会）：黄伟平认为债市研究的首要问题是"当前核心矛盾是什么"。过去几年债市核心矛盾的切换路径：
  - **信用收缩**（2021-2024 债牛主因：地产下行、信用收缩、资产荒）；
  - **资产配置再平衡**（2025：低利率环境下资产配置的性价比开始深刻影响债市；"2025 年信用周期的框架难以解析债市表现"）；
  - **物价+资金流向**（2026：核心矛盾进入新阶段，物价影响贯穿全年、资金流向（存款搬家）重塑需求结构）。
- **逻辑**：不同阶段下，解释债市的变量不同——信用收缩阶段看社融与地产；资产配置再平衡阶段看股债比价与存款搬家；物价+资金流向阶段看通胀斜率与负债结构。用错阶段的框架会系统性误判。
- **配置应用**：任何债市判断前，先定位当前核心矛盾阶段，再选择对应阶段的观测变量集。
- **窗口内实例**：2026 年"物价+资金流向"定位（✅ 2025.11 年会）；"2025 年信用周期框架难以解析债市"（✅）。

### 2. 物价（通胀）回升路径框架（✅ 原文）

- **定义**（✅ 2025.11 年会、2026.6 中期策略）：2026 年债市最核心变量是**物价**，影响贯穿全年，重点在 **2-3 季度**。通胀回升需经历三阶段：
  1. **基数原因导致物价触底反弹**；
  2. **货币政策协同发力 + 反内卷政策落地 → 物价加速修复**；
  3. **实现 PPI 向 CPI 传导**。
- **逻辑**：通胀回升斜率（而非水平）决定债市逆风期长度；"通胀持续抬升，债市或迎来较长时间的逆风期（重点在 2-3 季度）"（✅）。
- **配置应用**：物价回升斜率陡峭（2-3 季度）→ 债市防守、缩短久期；斜率平缓 → 债市压力有限。
- **窗口内实例**：2026 年 2-3 季度通胀回升斜率陡峭判断（✅ 2025.11 年会）；2026 年二季度 PPI 同比仍负、CPI 温和（⚠️ 以当期数据为准）。

## 第二层：定价范式

### 3. 货币政策框架转型监测框架（✅ 原文）

- **定义**（✅ 2026.7《货币政策框架转型分析》）：围绕 2024 年陆家嘴论坛潘功胜"数量型→价格型"转型，黄伟平构建完整监测体系：
  - **价格信号**：政策利率（OMO7D）为唯一价格信号，引导其他市场利率；
  - **短端**：临时隔夜正/逆回购锚定政策利率，形成货币市场利率走廊并**不断收窄**（2026 年陆家嘴论坛从 70BP 收窄至 50BP）；
  - **中端**：买断式回购引导同业存单利率与规模，影响银行负债成本（"买断式回购替代部分银行同业存单融资需求"）；
  - **长端**：由短及长形成平稳向上的收益率曲线（"央行通过资金调整'时间'完成市场利率调整的'空间'"）；
  - **信贷**：未来贷款利率可能锚定国债收益率（"强化国债收益率曲线的基准作用"）。
- **逻辑**：货币政策框架决定利率调控的传导效率与资金利率波动区间；政策利率长期不动不等于实质不变（"政策利率没有降息但有实质性降息的效果"✅）。
- **配置应用**：跟踪三个重点目标——①DR001 是否在利率走廊内；②短端向长端传导是否顺畅；③金融市场稳定。
- **窗口内实例**：2026 年"隔夜逆回购操作利率将培养成主要政策利率"（✅ 2026.6 陆家嘴论坛后分析）；利率走廊 70→50BP 收窄（✅）。

### 4. 流动性观察体系（✅ 原文）

- **定义**（✅ 《后疫情时代债券市场主逻辑分析》四模块之一 + 2026 中期策略）：从价格与数量两个维度观察银行间流动性：
  - **价格指标**：DR001/DR007 与政策利率的相对位置、利率走廊位置；
  - **量指标**：国有大行净融出规模（"超出季节性规律，显示流动性冗余在银行间市场明显"✅）；
  - **央行操作**：MLF/买断式逆回购中标利率逐步下行、缩量续作（"在投放工具充足、常规回笼工具相对有限的情况下，维持流动性适度稀缺和调控有效性"✅）；
  - **流动性分层**：大行→中小银行→非银；R-DR 利差衡量分层（2023 年 R001-DR001 绝对利差均值 15BP → 2024-2026 年降至 11/8/6BP ✅）。
- **逻辑**："资金松紧时间成为央行态度的重要参考点"（✅）——2025Q1 收紧 3 个月后 10Y 上行 13BP 至 1.81%；2026 年上半年收紧流动性抬高长债利率中枢。
- **配置应用**：资金持续宽松+大行净融出高位 → 加杠杆套息窗口；资金收敛+央行回笼中长资金 → 1-2 个月后资金回归均衡，降杠杆。
- **窗口内实例**：2026 年上半年"流动性冗余在银行间市场明显"（✅ 2026.6）；"资金面从紧缺到充裕"范式切换（✅ 2026 夏季策略）。

### 5. 长债定价锚切换框架（✅ 原文）

- **定义**（✅ 2026.6 中期策略《K型深化+宽松范式重塑》）：长债定价锚已从**政策利率**转向**货币市场利率**：
  - "政策利率对市场约束有限，长债定价锚转向货币市场利率"；
  - "从政策利率定价锚视角看，长债利率估值处于中低水平；但从资金利率定价锚视角看，长债利率估值仍相对合理，处于中高水平"；
  - 长期看，"名义经济走势与长债利率中枢相匹配，背后是资本投资回报率的映射"。
- **逻辑**：货币政策框架转型后，政策利率不动但资金利率实质下行（"没有降息但有实质性降息的效果"），长债定价跟随资金与负债成本而非政策利率。
- **配置应用**：判断长债利率中枢时，以 DR/R 系列资金利率与银行负债成本为锚，而非仅盯 OMO 政策利率。
- **窗口内实例**：2026 年 10Y 向 1.7% 靠近而政策利率未降（✅ 2026.6）。

### 6. 期限利差与曲线框架（✅ 原文方向，阈值 ⚠️/❌）

- **定义**（✅ 2026.6 中期策略）：通过 10-1Y、30-10Y 期限利差判断曲线定价是否健康：
  - "资金和负债成本的视角来看，曲线定价较为健康"；
  - "目前 10-1Y 期限利差已经回到 2024 年之前的水平，30-10Y 期限利差更是回升到 2022 年的水平。但从基本面、信贷需求等视角来看，曲线结构反映的预期可能偏乐观，后续期限利差仍有压缩空间"；
  - "2024 年以来，名义经济走势在期限利差定价中的权重明显抬升，尤其超长期限利差"。
- **逻辑**：期限利差=基本面预期（名义经济）+ 资金面（负债成本）的映射；利差偏宽说明曲线定价偏乐观，存在压缩空间（长端相对有吸引力）。
- **配置应用**：期限利差有压缩空间 → 超长/长久期性价比抬升（呼应资产性价比排序）；利差压缩后 → 止盈。
- **窗口内实例**：2026.6"期限利差仍有压缩空间"判断（✅）。

## 第三层：结构定价

### 7. 机构行为定价框架（✅ 原文）

- **定义**（✅ 2026.6 中期策略 + 二永债框架）：机构行为是债市**边际定价**核心，分机构看：
  - **保险**："保险机构可能并未欠配债市"；2024 年以来因 I9 新准则（二永债无法过 SPPI 测试计入 FVTPL）对二永债配置力量系统性趋弱，收益率上行时配置（配置盘特征）；
  - **公募基金**："久期策略较为拥挤但短期并不一定反转"；收益率上行卖出、下行买入（交易盘特征）；
  - **理财**：2026Q1 末至今大量净买入 30Y 国债、转向哑铃策略；
  - **银行**：负债端量增价降，买债积极性抬升（大行更显著）；
  - **固收+基金**：2025 下半年快速扩容，对二永债等信用债需求走高。
- **逻辑**：配置盘（保险/银行）与交易盘（基金/券商）力量博弈决定中短期利率走向；机构负债稳定性决定波动幅度。
- **配置应用**：跟踪分机构二级净买入、竞买率；配置盘力量增强+交易盘止损 → 利差见底回升特征。
- **窗口内实例**：2026 年"公募基金久期拥挤但短期不一定反转"（✅）；"理财哑铃策略"（✅）。

### 8. 结构性资产荒框架（✅ 原文）

- **定义**（✅ 2026.6 中期策略）：新形势下的结构性资产荒 = **负债充裕 + 优质高票息资产供给不足**：
  - 汇率升值+结汇偏强 → 外汇占款扩张成为流动性边际补充，"存款不是通过贷款派生，而是通过外汇存款转化"；
  - 内需信贷需求不强 → 银行资产端"偏好于买债和出回购"；
  - 化债推进（"6+4+2"方案 2026 年进程 46%-70%）→ 资产荒压力进一步缓解（✅ 2025.11）。
- **逻辑**：资产荒的"质"从全面稀缺转为结构性错配——高票息资产（信用债）稀缺，利率债供给（政府债）相对充足。
- **配置应用**：负债充裕+资产荒 → 压利差行情延续；资产荒缓解（化债、财政放量）→ 利率下行受阻。
- **窗口内实例**：2026 年"实质性宽松环境下，压利差"（✅ 2026.6）。

## 第四层：策略落地

### 9. 二永债三位一体定价框架（✅ 原文）

- **定义**（✅ 2026.8.3《资产荒下的"必争之地"——银行二永债投资框架》）：银行二永债定价三层次：
  - **宏观层（核心，本质是利率择时）**：政策、资金、基准利率；利差见底回升的触发剂=国开债收益率触底回调 / 资金利率中枢边际抬升 / 套息空间不大；
  - **中观层（品种定价，供需）**：长期供需格局变化改变利差中枢，短期供需变化助推行情；跟踪**二级净买入、竞买率**（利差见底回升通常伴随基金净买入减弱、保险净买入增强、竞买率从高位回落）；
  - **微观层（个券定价）**：主体资质打分模型（基于 76 起不赎回案例，四维度：第三方评级/财务实力/经营环境/外部支持）；弱资质银行不赎回或违约风险更高、流动性更差、要求更高补偿。
- **量化工具**（✅ 原文）：
  - 信用利差滚动 1 年分位数：**70% 附近接近见顶、10% 附近接近见底**（2025 年后指示意义提高）；
  - **布林带**：触及上轨=超卖（利差有下行动力）→ 潜在参与信号；触及下轨=超买（利差触底反弹压力）→ 潜在获利了结信号；
  - 品种利差（永续-二债）：多数时间 5-20BP 运行；**>15BP 积极超配（弹性 1.4-1.5 倍）、8-15BP 适度超配、<8BP 超额不显著**（✅ 2026.8.10 品种轮动报告）；
  - 交易主力：3-5 年期（尤其 4-5 年）国股行二永债。
- **配置应用**：高等级二永债=利率波动放大器+类利率品种，兼具配置与交易价值；中小银行二永债=波动放大器，仅在利差收窄机会下关注中短久期、隐含 AA/AA-、资本充足率安全垫较高品种。
- **窗口内实例**：2026 年二永债净供给预计 ≥7000 亿元（✅）；"资产荒下的必争之地"（✅）。

### 10. 存单分析框架（✅ 原文）

- **定义**（✅ 2026.8.17 存单重塑报告）：同业存单是银行负债成本与资金面传导的中枢变量：
  - 核心指标：**1Y AAA 存单 - OMO7D 利差**（"低中枢低波动"新常态；脉冲走阔=银行负债压力=配置窗口）；
  - 前瞻组合："央行投放-存单量价"（加量投放后存单仍放量提价=结构性融资压力）；
  - 传导链：政策利率 → 货币市场 → 存单 → 长债（负债成本锚）。
- **逻辑**：存单利率反映银行负债端压力；央行通过 MLF/买断式回购替代存单融资需求（2025 年以来负相关、替代效应明显；截至 2026.6，MLF+买断式回购余额 12.8 万亿，占三者余额 40%，较 2024 年末提升 11 个百分点 ✅）。
- **配置应用**：存单利差脉冲走阔 → 负债压力释放后的配置窗口；利差收窄至低位 → 套息空间压缩。
- **窗口内实例**：2026 年存单"低中枢低波动"（✅）。

### 11. 信用债三层分析框架 + 双周期（✅ 原文）

- **定义**（✅ 2023.8.30《"资产荒"演绎下的信用债投资新论》）：信用债分析三层——
  - **宏观层**：货币信用周期定位（资产荒/资产短缺）；
  - **中观层**：供需格局（供给：城投/产业/金融；需求：配置盘/交易盘）；
  - **微观层**：个券资质（主体信用、流动性补偿）；
  - **双周期叠加**：信用周期 × 盈利周期。
- **逻辑**：资产荒下票息策略占优；信用利差中枢由供需决定。
- **配置应用**：资产荒延续 → 票息策略+中高等级下沉；资产荒缓解 → 提防利差走阔。
- **窗口内实例**：2023.8 推荐 3-4 年隐含 AAA-/AA+ 二永债（✅）。

### 12. 资产性价比排序与波段择时框架（✅ 原文）

- **定义**（✅ 2026.6 中期策略）：给出明确的资产性价比排序与节奏判断：
  - **当下资产性价比排序**：超长期国债 > 长久期国债、政金债 > 普信债、二永债 > 存单；
