# 黄伟平（申万宏源固收）债市分析框架技能

> 申万宏源研究董事总经理、债券首席分析师；执业编号 A0230524110002（申万）｜S0190514080003（兴业）。
> 时间窗口：2023.8–2026.8（资料以窗口内公开研究为准）。
> ⚠️ 机构归属：2023.8-2024 属兴业证券（固收首席）→ 2024 年加盟申万宏源至今；引用观点须标注任职期归属。

## 一、使用流程（先观点时效 → 再定位 → 再范式 → 后策略）

1. **先读 `assets/views.md` 顶部最新观点快照**（观点时效性第一原则：任何输出前核对最新观点，过期观点不得当作当前判断）
2. **核心矛盾定位**：信用收缩 → 资产配置再平衡 → 物价+资金流向（framework.md 框架 1-2）
3. **定价范式判断**：货币政策框架状态 + 流动性范式（从紧缺到充裕）+ 长债定价锚（政策利率→货币市场利率）（框架 3-6）
4. **结构定价**：机构行为 + 结构性资产荒（框架 7-8）
5. **策略落地**：资产性价比排序 + 二永债宏观-中观-微观定价 + 存单/曲线/品种选择（框架 9-12）
6. **运行信号**：`scripts/screen.py`（S1-S13 信号，见下）

## 二、触发场景速查表

| 用户问什么 | 调用 | 关键锚 |
|---|---|---|
| 债市往哪走？ | 核心矛盾定位 + 物价路径 | "物价+资金流向"阶段；通胀斜率 2-3 季度 |
| 利率中枢会下移吗？ | 货币政策转型 + 流动性范式 + 定价锚 | 利率走廊位置；大行净融出；长债定价锚 |
| 现在拉久期还是缩久期？ | 资产性价比排序 + 期限利差 | "倒N"形节奏；6-7 月 1.70-1.80% / 8-9 月防守 |
| 买什么品种？ | 二永债三位一体 + 存单 + 信用债 | 信用利差 70%/10% 分位；布林带；品种利差 |
| 怎么看银行二永债？ | 二永债定价框架 | 分位 70% 顶/10% 底；竞买率；机构净买入 |
| 当前资产什么最划算？ | 资产性价比排序 | 超长 > 长久期 > 普信二永 > 存单 |
| 什么时候防回调？ | 机构行为 + 物价 + 波段节奏 | 久期拥挤；7 月下旬-9 月政策观察期 |
| 黄伟平怎么看 XX？ | assets/views.md | 最新快照（顶部） |

## 三、数据获取

- **westock-data**：国债收益率（10Y、30Y、1Y）、DR001/DR007/R001/R007、1Y AAA 存单利率、5Y 二永债信用利差、社融、PPI/CPI、名义 GDP
- **westock-tool / neodata-financial-search**：自然语言查询宏观与固收指标、信用利差分位、存单利差
- 平台降级方案见 analyst-distill `references/domain-adapters.md` §三（数据源不可用时如实标注，不得伪造数据）
- `screen.py --data` 输入字段清单（必需）：dr001 / dr007 / omo7d / ncd1y / c10y / c30y / c1y / credit_spread / credit_spread_pctile / spread_btn / fund_netbuy / insur_netbuy / ppi_yoy / cpi_yoy / sf_yoy；extras：core_stage / pricing_anchor / supply_status / policy_stance

## 四、脚本使用

```bash
python scripts/screen.py                            # 演示模式（合成数据，验证流程）
python scripts/screen.py --data data.json           # 真实数据（月度字段→数组，最新在末尾）
python scripts/screen.py --data data.json --json-out  # stdout 输出 JSON（--json-out 为布尔标志）
python scripts/screen.py --schema                   # 输出输入契约（布尔标志）
```

S 信号（工程化编号系本技能设计，非黄伟平本人编号）：S1 核心矛盾阶段｜S2 物价斜率｜S3 货币政策框架状态｜S4 资金面松紧｜S5 存单利差脉冲｜S6 长债定价锚｜S7 期限利差｜S8/S9 二永债利差分位极值｜S10 布林带波段｜S11 品种利差轮动｜S12 机构行为异动｜S13 资产性价比排序。阈值来源分级（✅原文/⚠️外推/❌推断）见 `references/decision-rules.md` 与脚本参数区。

## 五、红线与注意事项

1. **观点时效性**：任何输出先读 views.md 最新快照；年度点位区间每年 11 月随年度策略、6 月随中期策略强制更新（不可静态使用历史区间）。
2. **机构归属**：黄伟平 2023.8-2024 任职兴业证券、2024 年起任职申万宏源；引用观点必须标注"截至 {日期} 黄伟平（{任职机构}）观点"。
3. **禁止虚假精确**：一切阈值/权重/参数带来源标注；❌ 推断值（分位窗口、σ 倍数、带宽阈值等）为最小假设可替换，不得冒充原文。
4. **观点与规则分离**：信号计算不依赖观点快照；冲突时优先遵循信号并说明分歧。
5. **分析师独立性**：本技能仅含黄伟平本人框架与观点，不与其他分析师对比。
6. **A股/债市惯例**：涨红跌绿、货币 ¥；债券收益率上行 = 债市走弱（价格反比）。
7. 本技能输出为分析参考，非投资建议。
