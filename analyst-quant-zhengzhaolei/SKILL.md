# 郑兆磊 · 兴业证券金融工程分析框架

本技能将兴业证券金融工程首席分析师郑兆磊的量化研究框架蒸馏为可执行的择时/配置/选股决策体系。
定位：**先总量（点位效率择时 + ERP 仓位锚）→ 再中观（风格/市值/行业轮动）→ 后微观（因子选股）**。

## 使用流程（按顺序执行）

1. **读取最新观点**：先打开 `references/views.md` 顶部，确认郑兆磊/兴证金工当前最新观点（截至日期）与机构归属。观点是时效的，勿直接使用历史快照。
2. **择时与仓位（第一层）**：运行 `scripts/screen.py`，计算点位效率长/中/短期上涨概率（S1）与 ERP 3.0 滚动 4 年分位仓位锚（S2）；再检查 LPPLS 拐点与趋势型指标（S6）。计算规则与阈值详见 `references/decision-rules.md`。
3. **风格判断（第二层·上）**：看成长-价值轮动（6 因子四维度，S3）与美债利率方向（S8）、换手率情绪（S7）。
4. **市值与行业（第二层·下）**：看大小盘拐点+趋势（S4）与行业轮动"分歧与共振"（S5）。
5. **微观选股（第三层）**：结合 `references/framework.md` 第三层——Alpha/风险因子分层、因子库四类来源（财务/预期/量价/另类 678 PIT 信号）、知识图谱增强——用 `westock-tool` 做个股筛选。
6. **输出规范**：所有观点引用必须注明日期（如"郑兆磊（兴业证券金融工程）2026-08 观点"）；信号与观点冲突时优先遵循信号并说明分歧；参数来源标注（✅原文/⚠️外推/❌推断）必须保留。

## 数据获取

- 择时类（上涨概率）：兴财富周报口径；无公开 API 直连时用指数动量+ATR 波段工程代理（❌），`_meta` 标注降级。
- 配置类（股息率、10Y 国债、社融/中长贷增速、10Y 美债、汇率）：用 `westock-data` 或 `neodata-financial-search` 查询宏观/利率/汇率数据，计算 ERP 3.0 与滚动 4 年分位。
- 风格类（申万高/低 PE 指数、美债、期限利差、换手率）：westock-data 查询；成长-价值轮动得分按 6 因子合成（权重 ❌ 推断）。
- 行业类（行业动量、业绩超预期、北向/主力资金、行业 ETF 资金流）：westock-data + westock-tool 查询。
- 个股/行业筛选：用 `westock-tool` 按 screen.py 输出的风格/市值/行业方向做筛选。
- 指标口径、频率、所属框架详见 `references/indicators.md`。

## 脚本使用

```bash
python scripts/screen.py                  # 演示模式（内置合成数据，验证流程）
python scripts/screen.py --schema         # 查看输入数据契约（先跑这个）
python scripts/screen.py --data macro.json   # 用真实数据计算信号
python scripts/screen.py --data macro.json --json-out  # 输出机器可读 JSON
```

- **输入契约**：运行 `python scripts/screen.py --schema` 获取字段清单，按 required 字段准备数据（字段→月份数组，最新在末尾）。除调试外不要读取脚本源码。
- 信号 S1-S8 编号为**工程化设计**（郑兆磊没有此编号体系），底层阈值来源见 `references/decision-rules.md` 各规则标注。

## 红线与注意事项

- 本技能输出为分析参考，非投资建议；量化框架历史表现不代表未来。
- 观点与规则分离：`references/views.md` 是时效快照（**观点时间线/口径校准层，不参与信号计算**），`references/` 是方法论，勿混用；信号基于 ✅ 原文规则 + 最新数据优先，观点冲突时输出分歧说明。
- **机构归属红线**：郑兆磊任职兴业证券金融工程研究中心（总经理/首席分析师）；引用观点须标注任职期归属，如发生离职/跳槽，其观点归属以任职期为准，禁止混用。
- **推断参数**：动态阈值（上涨概率 60/40）、±0.5σ、行业前 5、LPPLS 阈值 0.5 等均为 ❌ 推断最小假设，非分析师公布值，拿到真实参数应替换。
- **数据口径**：不同数据源绝对水平可能背离（如 ERP 绝对水平），仅分位/方向可用时不得跨口径比较绝对阈值；见 `_meta` 与 validation.md 标注。
- 时间窗口 2023.9-2026.8 内的方法论与观点为本技能知识边界；窗口外内容需另行检索核验。
- A 股惯例：涨红跌绿，货币符号用 ¥。
