## 框架总览：三层结构（按郑兆磊自身方法论分层）

郑兆磊是**金工体系化**分析师，自身方法论表述为"**宏观配置—中观轮动—微观选股**"三层，底层由"点位效率"理论统一支撑择时。框架调用顺序：

```
理论基石  点位效率理论（一个核心、三大假设、三个概念）
   ↓
第一层  总量配置（现在该不该买/买多少）
   ├─ 1. 点位效率择时体系（自适应波段 → 长/中/短期上涨概率）
   ├─ 2. 改进股债性价比 ERP 3.0（权益仓位锚）
   └─ 3. 趋势与极端拐点（趋势型 + LPPLS 拐点型风控）
   ↓
第二层  中观轮动（买什么风格/行业）
   ├─ 4. 成长-价值轮动（6 因子四维度）
   ├─ 5. 大小盘轮动（拐点+趋势）
   └─ 6. 行业轮动（旧三因子 → 新"分歧与共振"四维度）
   ↓
第三层  微观选股（个股层面）
   └─ 7. Alpha/风险因子分层 + 因子库四类来源
        └─ 8. 知识图谱改造传统因子（图谱系列）
```

## 理论基石：点位效率理论

### 0. 点位效率理论（"一个核心、三大假设、三个概念"，《花开股市，相似几何》系列）

- **定义**：市场价格走势由一系列"点位"构成，用**时间效率**（一段走势消耗的时间）与**价格效率**（一段走势走出的空间）二维刻画走势质量；以历史相似形态的条件概率外推未来涨跌。（✅ 原文，公开口径）
- **"一个核心"**：点位效率——判断当前走势"涨得有效率/没效率"。（✅ 原文方向；精确公式 ❌ 推断，原文全文未公开转载）
- **"三大假设、三个概念"**：公开转载未见原文逐条表述，Phase 2 按条件概率 + 时间/价格效率二维实现，细节标 ⚠️（有公开依据未逐字核对）。（⚠️ 外推）
- **逻辑**：有效率的上涨（快且持续）更可能延续；低效率上涨（慢且反复）更易反转。用历史区间统计"给定走势形态后继续上涨的条件概率"。
- **选股应用**：为择时体系提供概率底层——所有宽基的长/中/短期上涨概率都由此理论计算。
- **窗口内实例**：兴财富周报持续输出各宽基上涨概率与择时信号（2023.9 至今，周度跟踪 ✅ 原文）。

## 第一层：总量配置（择时与仓位）

### 1. 点位效率择时体系（核心框架，兴财富周报持续运行）

- **定义**：以点位效率理论为基础的自适应择时体系，四步：**自适应波段划分 → 长/中/短期上涨概率 → 概率指标模式 → 单边趋势模式**（✅ 原文）。
- **波段划分算法**（✅ 原文机制）：改进型 MACD（DIF/DEA 同号区间的累计差值）识别波段 + ATR 过滤噪音 + **异常端点自动修正**；据此把指数切成"上涨段/下跌段"。（精确参数 ❌ 推断：如 MACD 参数 12/26/9 为默认工程假设，可替换）
- **上涨概率**（✅ 原文）：对每个波段统计"该形态之后继续上涨"的条件概率，分**长期（长周期波段）/中期（中周期波段）/短期（短周期波段）**三档输出。
- **双模式输出**（✅ 原文）：
  - **概率指标模式**：上涨概率处于阈值区间时，用概率值多空；
  - **单边趋势模式**：概率进入极端区（持续单边），切换为趋势跟随，**动态阈值防过拟合**（具体阈值 ❌ 推断，脚本默认长期上涨概率 >60% 看多 / <40% 看空，最小假设可替换）。
- **回测绩效**（⚠️ 回测数字，取自公开报告，以原文为准）：择时多头策略年化收益约 ~9.8%–13.4%（不同口径/报告），显著跑赢同期指数。
- **窗口内实例**（✅ 观点实例，以当期报告原文为准）：兴财富周报 2023.9–2026.8 逐周输出看多/谨慎/谨慎偏乐观三级信号，2025 年以来多数时段偏多。

### 2. 改进股债性价比 ERP 3.0（权益仓位锚）

- **定义**：股债性价比的第三代指标（✅ 原文，《固收加系列之五》等）：
  - **1.0**：股息率 − 10Y 国债收益率（经典口径）；
  - **2.0**：股票端用**信用扩张**（社融/M2 等）调整盈利预期，债券端用**中美利率**（10Y 美债）调整，修正全球流动性影响；
  - **3.0**：新增**汇率**维度（人民币兑美元），捕捉外资风险偏好。
- **使用方式**：对 ERP 序列取**滚动 4 年分位数**（✅ 原文：滚动 4 年窗口）；分位极高 = 股票性价比突出（历史上对应长期上行周期起点），分位极低 = 股票性价比差（对应长期下行风险区）。
- **逻辑**：股债性价比是"风险溢价"视角——ERP 高分位意味着权益被过度悲观定价，均值回归向上；低分位反之。
- **选股应用**：ERP 分位 → 权益仓位中枢的锚；极端高分位 = 加仓权益，极端低分位 = 减仓权益。
- **窗口内实例**（✅ 观点实例，以当期报告原文为准）：2026-08 最新一期 ERP 3.0 分位 **35.4**（未触发减仓阈值），对应"总体乐观、小盘+价值占优"判断。

### 3. 趋势与极端拐点（趋势型 + 拐点型双轨风控）

- **定义**：把市场状态拆成两类指标（✅ 原文，《如何捕捉A股市场趋势与极端拐点？》2024-08-07）：
  - **趋势型指标**：信用扩张、汇率、宏观预期——**持续有效**，决定趋势方向；
  - **拐点型指标**：LPPLS（对数周期幂律）正负泡沫、地缘风险、股债性价比极端位——**仅极端态有效**，用于捕捉反转拐点。
- **LPPLS 机制**（✅ 原文）：拟合价格的对数周期幂律结构，识别泡沫（正泡沫：加速上涨见顶）与反泡沫（负泡沫：加速下跌见底）。
- **验证记录**（✅ 原文）：LPPLS 成功预判 **2022-04 反弹**、**2024-02 反弹**（负泡沫触底）。
- **选股应用**：趋势型指标定方向仓位；拐点型指标定"极端态反转"的加/减仓时点——两者冲突时以拐点型极端态提示为准（如负泡沫触发 = 抄底窗口）。
- **窗口内实例**（⚠️ 外推）：2024-02 LPPLS 负泡沫触发对应随后反弹；2026 年内兴证金工以 ERP 分位 + 拐点指标判断调整级别。

## 第二层：中观轮动（风格与行业）

### 4. 成长-价值轮动模型（6 因子四维度，风格层核心）

- **定义**：以申万高/低 PE 指数代表成长/价值风格，用 6 个因子四维度打分轮动（✅ 原文，《风格轮动系列七》2022-08-05 等）：
  - **技术面动量**：成长/价值相对净值动量（如相对强弱 RSI/均线乖离，具体构造 ❌ 推断）；
  - **国内流动性**：中长期贷款增速 + 期限利差（宽信用 → 利好成长）；
  - **海外流动性**：**10Y 美债利率**——"解释力极强"（✅ 原文），美债上行 → 利好价值，下行 → 利好成长；
  - **股市反弹期**：市场反弹初期/中期 → 成长弹性占优。
- **合成方式**（⚠️ 外推）：各因子标准化打分后加权合成（等权或按解释力加权，具体权重 ❌ 推断）；得分 > 0 → 成长占优，< 0 → 价值占优。
- **回测绩效**（⚠️ 回测数字，取自公开报告，以原文为准）：样本外年化 ~20.7%（2022-08 报告披露，含调仓摩擦前口径）。
- **窗口内实例**（✅ 观点实例，以当期报告原文为准）：2025 全年"成长占优"、2026-02"成长占优、TMT 主线"、2026-08 切换"**小盘+价值占优**"——风格信号在窗口内发生切换。

### 5. 大小盘轮动（拐点+趋势双轨）

- **定义**：大小盘（如沪深300/中证1000 或申万大小盘）相对强弱的两轨模型（✅ 原文，《基于拐点+趋势的大小盘轮动研究》2023-01-20）：
  - **趋势型**：期限利差+信用利差（国内流动性结构）、地产投资增速（经济结构）、相对净值均线突破（技术确认）；
  - **拐点型**：股债性价比极端位（宏观风险偏好反转）、大小盘相对换手率分位（交易拥挤反转）。
- **逻辑**：小盘占优 = 宽信用 + 经济弱复苏预期 + 流动性充裕；大盘占优 = 信用收缩/避险 + 经济强复苏或衰退防御。
- **选股应用**：趋势信号给基准仓位方向；拐点信号在拥挤度极端时反向修正（如小盘相对换手率进入历史极高分位 → 警惕小盘反转）。
- **窗口内实例**（✅ 观点实例）：2026-08"小盘价值占优"；2026-02"大小盘均衡"。

### 6. 行业轮动（两代模型）

- **定义**：行业层面量化轮动，两代（✅ 原文）：
  - **旧模型（三因子等权）**：盈余惊喜 + 残差动量 + 北向资金净流入，三因子等权打分选行业；
  - **新模型（2024"分歧和共振——直击行业轮动痛点"）**：四维度——**内生/溢出动量**（行业自身动量+跨行业溢出）、**真实/预期业绩**（业绩超预期程度）、**主力资金/ETF**（北向与主力资金流 + 行业 ETF 申购）、**CPI 发布日效应**（通胀数据发布日的行业反应）。
- **"分歧与共振"核心思想**（✅ 原文）：当**资金面（分歧）与基本面（共振）**方向一致时信号最强——资金持续流入且业绩超预期 → 高确信买入；仅资金流入但业绩不兑现 → 降级。
- **回测绩效**（⚠️ 回测数字，取自公开报告，以原文为准）：新旧模型行业轮动组合年化超额约 ~10.8%（旧三因子口径）。
- **窗口内实例**（✅ 观点实例，以当期报告原文为准）：2026-08 最新推荐行业 **机械/电力设备/家电/有色/传媒**（五行业）。

## 第三层：微观选股（Alpha/风险因子 + 图谱）

### 7. Alpha/风险因子分层与因子库

- **定义**：个股层因子体系分两类（✅ 原文，中证报访谈 2024-10 等）：
  - **Alpha 因子**：长期稳定有效的选股信号（多因子合成）；
  - **风险因子**：阶段性有效、主要起风险暴露管理作用（行业/风格/流动性暴露）。
- **因子库四类来源**（✅ 原文）：**财务**（盈利/质量/成长）、**预期**（分析师预期/超预期）、**量价**（动量/反转/换手）、**另类**（专利、产业链、ESG、财务附注——共 **678 个 PIT（Point-in-Time）信号**）。
- **逻辑**：Alpha/风险分层避免把"阶段性风险因子"当"长期 Alpha"用；PIT 信号避免未来函数（用当季已披露数据）。
- **选股应用**：多因子打分选股（IC/IR 加权或等权，具体权重 ❌ 推断），风险因子用于行业/风格中性化。
- **窗口内实例**（⚠️ 外推）：兴证金工季度金股/月度组合持续运行，2023.9–2026.8 因子有效性结构（哪些因子当期有效）以当期报告原文为准。

### 8. 知识图谱改造传统因子（图谱系列）

- **定义**：用上市公司间**知识图谱**（专利关联、产业链上下游、技术相似度）重构传统因子的关联结构（✅ 原文，图谱系列 17+ 篇）。
- **机制**：传统因子按行业/板块聚合 → 图谱按"技术-产业"真实关联聚合 → 得到**溢出效应**（关联公司动量相互传导）与更干净的因子暴露。
- **代表应用**（✅ 原文）：高频动量溢出因子、专利关联行业重构（如以专利相似度重新定义"行业"进行轮动）。
- **选股应用**：行业轮动/因子选股的"另类"增强层——当传统行业分类失真（跨领域公司、新产业）时，图谱分类替代行业分类。
- **窗口内实例**（⚠️ 外推）：图谱系列持续产出，具体因子表现以当期报告原文为准。
