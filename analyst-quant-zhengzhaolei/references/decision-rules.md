# 郑兆磊投资决策规则（decision-rules.md）

> 本文件将郑兆磊框架转化为**可执行的规则**：信号触发条件 → 动作。
> Phase 3 的 `scripts/screen.py` 依据本文件实现。
> 数据源：westock-data / neodata-financial-search / westock-tool 可查询行情、宏观与资金数据。

---

## 来源标注图例（全文件适用）

| 标记 | 含义 |
|---|---|
| ✅ 原文 | 郑兆磊/兴证金工公开研究报告中**明确给出**的数值、口径或约定（注明出处系列/报告） |
| ⚠️ 外推 | 有公开依据（口径/方向明确），但**具体数值/分档未经逐字核对**，属合理近似，使用时按原文复核 |
| ❌ 推断 | 郑兆磊**未公布**，为实现"可脚本化"而作的假设（最小假设），拿到真实值应替换 |

## 规则 0：信号分级与总原则

- **强信号**（改变仓位/大类配置）：点位效率长中期概率同向、ERP 3.0 极端分位、LPPLS 拐点触发
- **中信号**（结构调整）：成长-价值轮动得分切换、大小盘轮动切换、行业轮动打分排序
- **弱信号**（战术/验证）：短期上涨概率、换手率情绪、美债利率方向
- 总原则：**三层递进**——先总量（择时/仓位锚）→ 再中观（风格/行业）→ 后微观（个股因子）；**观点与信号分离**，信号基于 ✅ 原文规则 + 最新数据优先，最新观点冲突时输出分歧说明。（✅ 原文方法论结构）

## 规则 1：点位效率择时（S1 权益多空方向）

### 1.1 指标定义
- 长期上涨概率 P_L、中期上涨概率 P_M、短期上涨概率 P_S（点位效率理论条件概率，0–100%）（✅ 原文机制；兴财富周报周度输出）

### 1.2 计算步骤（周度更新）
1. 取宽基（万得全 A 或沪深300）三档上涨概率；
2. 判定**概率指标模式**：P_L 处于 [40, 60] 中性区 → 以 P_L 方向为主（❌ 推断：中性区上下界，动态阈值未公布，最小假设可替换）；
3. 判定**单边趋势模式**：P_L > 60 或 < 40 持续 N 期（❌ 推断：N=2 周，最小假设可替换）→ 切趋势跟随，忽略短期噪音；
4. 合成三级信号：看多 / 谨慎偏乐观 / 谨慎。

### 1.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 看多 | P_L > 60（趋势模式）或 55 < P_L ≤ 60 且 P_M 同向（❌ 推断阈值） | 权益多头方向，仓位进攻档（配合规则 2 定档） |
| 谨慎偏乐观 | P_L ∈ (50, 55]，或 P_L 与 P_M 背离 | 维持仓位、不加仓，等待共振 |
| 谨慎 | P_L < 40（趋势模式）或 P_L ≤ 45 且 P_M 同向（❌ 推断阈值） | 权益防御，减仓至规则 2 下限档 |

> 回测数字（择时多头年化 ~9.8%–13.4%）取自公开报告，以原文为准，不作为本规则参数。

## 规则 2：股债性价比 ERP 3.0 仓位锚（S2 权益仓位中枢）

### 2.1 指标定义
- ERP 3.0 = 经信用扩张调整的股票端（股息率）− 经中美利率/汇率调整的债券端（10Y 国债）；取滚动 4 年分位数 Q（✅ 原文：滚动 4 年窗口）

### 2.2 计算步骤（月度更新）
1. 计算 ERP 3.0 序列（口径 ✅ 原文；调整系数 ❌ 推断：原文未公布精确公式，默认股息率−10Y 国债 + 汇率项线性修正，最小假设可替换）；
2. 取滚动 4 年分位数 Q（0–100%）；
3. 分档映射仓位。

### 2.3 信号输出

| 状态 | 条件（Q 分位） | 动作 |
|---|---|---|
| 高性价比 | Q > 90%（⚠️ 外推：原文"极端高位"，90 为脚本档） | 权益仓位上限档（长期上行周期起点特征） |
| 中性偏多 | 70% < Q ≤ 90% | 权益标准配置档 |
| 中性偏空 | 30% < Q ≤ 70% | 权益标配偏谨慎档 |
| 低性价比 | Q ≤ 10%（⚠️ 外推：原文"极端低位"） | 权益减仓至下限档（长期下行风险区） |

> 2026-08 最新读数 Q=35.4（✅ 观点实例）→ 中性偏空档，未触发减仓——与"总体乐观"观点对应，信号不冲突。

## 规则 3：成长-价值轮动（S3 风格方向）

### 3.1 指标定义（✅ 原文，《风格轮动系列七》6 因子四维度）
- 技术面动量 M_tech（成长/价值相对净值动量）
- 国内流动性：中长贷增速 g_loan + 期限利差 TS
- 海外流动性：10Y 美债利率 r_us
- 股市反弹期 F_bounce（市场处于反弹初期/中期）

### 3.2 计算步骤（月度更新）
1. 各因子标准化（z-score，窗口 ❌ 推断：默认 12 个月，可替换）；
2. 加权合成风格得分 score_gv = w1·M_tech + w2·(g_loan) + w3·(TS) + w4·(−r_us) + w5·F_bounce（权重 ⚠️ 外推：原文未公布，默认等权 ❌ 推断，可替换；美债项方向为 ✅ 原文）；
3. 阈值判定。

### 3.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 成长占优 | score_gv > +0.5σ（σ 推断：得分标准差，最小假设） | 超配成长风格（高 beta、TMT、创业板） |
| 价值占优 | score_gv < −0.5σ | 超配价值风格（红利、低 PE、大盘价值） |
| 风格均衡 | −0.5σ ≤ score_gv ≤ +0.5σ | 均衡配置，等权持有（对应 2026-02"大小盘均衡"类观点） |

> ⚠️ 美债利率单因子"解释力极强"（✅ 原文）：r_us 单列规则 8 强化。

---

## 规则 4：大小盘轮动（S4 市值方向）

### 4.1 指标定义（✅ 原文，《基于拐点+趋势的大小盘轮动研究》2023-01-20）
- 趋势型：期限利差+信用利差（TS+CS）、地产投资增速 g_prop、大小盘相对净值均线
- 拐点型：股债性价比极端位（复用 Q）、大小盘相对换手率分位 H_rel

### 4.2 计算步骤（月度更新）
1. 趋势得分 score_cap = f(TS+CS, g_prop, rel_nav 均线)（各成分权重 ❌ 推断：默认等权，可替换）；
2. 拐点检查：Q > 90% 或 H_rel > 90% → 触发拐点修正（⚠️ 外推：极值阈值）；
3. 合成方向。

### 4.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 小盘占优 | score_cap > 0 且无拐点触发 | 超配小盘（中证1000/国证2000） |
| 大盘占优 | score_cap < 0 且无拐点触发 | 超配大盘（沪深300） |
| 拐点修正 | 小盘占优但 H_rel > 90% 或 Q 极端 | 降级为均衡，警惕小盘反转（拥挤度修正） |

> 窗口内实例：2026-08"小盘价值占优"（✅ 观点实例，见 views.md）。

## 规则 5：行业轮动"分歧与共振"（S5 行业推荐）

### 5.1 指标定义（✅ 原文，《分歧和共振——直击行业轮动痛点》2024）
- 内生/溢出动量：行业自身动量 + 图谱关联溢出动量
- 真实/预期业绩：业绩超预期程度
- 资金面：主力资金/北向 + 行业 ETF 资金流
- CPI 发布日效应

### 5.2 计算步骤（月度更新，对申万一级行业）
1. 每个行业计算四维度得分（各维度标准化，权重 ❌ 推断：默认等权，可替换）；
2. **共振判定**：资金维度与业绩维度同向为正 = "共振"加分；仅资金流入但业绩未超预期 = 降级；
3. 排序取前 N 行业（N ❌ 推断：默认 5，对齐 2026-08 五行业推荐口径）。

### 5.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 高确信买入 | 资金维度 + 业绩维度同向为正（共振）且总分前 5 | 纳入行业配置核心持仓 |
| 观察 | 仅资金维度为正（分歧未共振） | 纳入观察，不重仓 |
| 回避 | 总分后 20% 或业绩维度持续为负 | 低配/回避 |

> 回测数字（行业轮动年化超额 ~10.8%）取自公开报告，以原文为准。

---

## 规则 6：趋势与极端拐点风控（S6 风控/抄底）

### 6.1 指标定义（✅ 原文，《如何捕捉A股市场趋势与极端拐点？》2024-08-07）
- 趋势型：信用扩张（社融/中长贷增速）、汇率、宏观预期——持续有效
- 拐点型：LPPLS 正/负泡沫、地缘风险、股债性价比极端位——仅极端态有效

### 6.2 计算步骤（月度/事件更新）
1. 趋势方向：信用扩张上行 + 汇率升值 + 宏观预期改善 → 趋势偏多（✅ 原文方向；合成 ❌ 推断）；
2. 拐点检查：LPPLS 负泡沫触发（✅ 原文机制）→ 抄底窗口；LPPLS 正泡沫触发 → 见顶预警；
3. 极端态优先级：拐点触发时以拐点信号为准（与趋势冲突时）。

### 6.3 信号输出

| 状态 | 条件 | 动作 |
|---|---|---|
| 负泡沫抄底 | LPPLS 负泡沫触发（参照 2022-04、2024-02 ✅ 原文） | 分批加仓权益（与规则 2 高性价比共振更佳） |
| 正泡沫见顶 | LPPLS 正泡沫触发 | 减仓锁定收益 |
| 趋势偏多 | 信用扩张+汇率+预期同向改善 | 维持多头方向仓位 |
| 趋势偏空 | 三者同向恶化 | 防御仓位 |

> 局限（✅ 原文立场）：拐点型指标仅极端态有效，常态下不触发；本规则对"非极端态"不产生信号。

---

## 规则 7：换手率情绪（S7 情绪辅助）

- **指标**：万得全 A 换手率（✅ 原文：与**过去 2 年中位数**比较）
- **触发**：换手率 > 2 年中位数 → 情绪活跃 → 利好成长（✅ 原文）；近 10 年分位 >90% → 情绪过热警惕（⚠️ 外推）
- **动作**：作为规则 3 风格信号的加减分项（弱信号），不单独触发调仓。

---

## 规则 8：美债利率方向（S8 海外流动性）

- **指标**：10Y 美债利率月环比（✅ 原文："解释力极强"）
- **触发**：利率上行 → 利好价值 / 利空成长；利率下行 → 利好成长（✅ 原文）
- **动作**：作为规则 3 的独立确认信号；与规则 3 得分同向时升级为中信号，反向时保持弱信号并提示分歧。

---

## 规则 9：观点更新模板（非信号，结构占位）

> 时点观点（如"2026-08 推荐机械/电力设备/家电/有色/传媒"）一律进 `views.md`，本文件不固化。
> 使用流程：每次调用先读 `views.md` 顶部最新观点（确认日期/机构归属/有效期），再运行规则 1–8；最新观点与信号冲突时按规则 0 总原则输出分歧说明。

## S 信号触发汇总表（信号工程化编号系本技能设计）

| 编号 | 信号名 | 触发条件 | 强度 |
|---|---|---|---|
| S1 | 权益多空方向 | P_L >60 看多 / <40 看空（趋势模式）；概率模式用 P_L 方向 | 强 |
| S2 | 权益仓位锚 | ERP 3.0 滚动 4 年分位 Q：>90 加仓 / ≤10 减仓 | 强 |
| S3 | 风格方向 | score_gv >+0.5σ 成长 / <−0.5σ 价值 | 中 |
| S4 | 市值方向 | score_cap>0 小盘 / <0 大盘；H_rel>90% 拐点修正 | 中 |
| S5 | 行业推荐 | 资金×业绩共振且总分前 5 | 中 |
| S6 | 极端拐点风控 | LPPLS 负/正泡沫触发 | 强 |
| S7 | 情绪辅助 | 换手率 > 2 年中位数 → 利好成长 | 弱 |
| S8 | 海外流动性 | 美债上行 → 价值占优 | 弱→中 |

> 强度定义见规则 0。S1/S2 决定仓位档位（强），S3/S4/S5 决定结构（中），S7/S8 为验证/加减分（弱）。
