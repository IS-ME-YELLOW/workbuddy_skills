# 郭磊 · 广发宏观分析框架

本技能将广发证券首席经济学家郭磊的宏观研究框架蒸馏为可执行的选股/配置决策体系。
定位：**先判断宏观环境（总量→结构→择时→配置），再落地选股**。

## 使用流程（按顺序执行）

1. **读取最新观点**：先打开 `references/views.md` 顶部，确认郭磊当前最新观点（截至日期）。观点是时效的，勿直接使用历史快照。
2. **宏观体检（第一层·总量）**：调用 `references/indicators.md` 中的核心指标（BCI、PMI 系列、M1、PPI/CPI、供需比分项），判断经济处于四周期叠加的什么位置、供需格局松紧。框架详见 `references/framework.md` 第一层。
3. **择时判断（第三层）**：运行 `scripts/screen.py`，计算 M1-BCI-PPI 择时分、股债性价比分位、估值-宏观偏离度，得到 S1-S12 信号。计算规则与阈值详见 `references/decision-rules.md`。
4. **风格与结构判断（第二层）**：比较高技术行业 PMI vs 建筑业 PMI（新旧经济锚）、叙事周期阶段（CSAD/宽度/成交集中度），确定成长/价值倾向。
5. **配置与选股落地（第四层）**：结合 `references/views.md` 最新观点与信号汇总，输出：仓位建议、风格倾向、行业方向、个股筛选条件。
6. **输出规范**：所有观点引用必须注明日期（如"郭磊 2026-06-24 中期观点"）；信号与观点冲突时优先遵循信号并说明分歧。

## 数据获取

- 宏观指标（BCI、M1、PPI、PMI 系列、社融、固投、社零、出口等）：用 `westock-data` 或 `neodata-financial-search` 查询；缺失时用高频代理（南华工业品、生意社 BPI、沥青消费、水泥产量）或研报引用值。
- 个股/行业筛选：用 `westock-tool` 按 screen.py 输出的条件做筛选。
- 指标口径、频率、所属框架详见 `references/indicators.md`。

## 脚本使用

```bash
python scripts/screen.py                  # 演示模式（内置示例数据，验证流程）
python scripts/screen.py --data macro.json  # 用真实数据文件计算信号
python scripts/screen.py --json-out        # 输出机器可读 JSON
```

- screen.py 输入：宏观数据 JSON（字段见脚本内 `DATA_SCHEMA` 说明）；输出：S1-S12 信号表 + 仓位/风格/行业建议。
- 数据来源：优先 westock-data / neodata 查询结果，由调用方填入 JSON。
- 回测实证：`references/validation.md`（2023-08~2026-08，37 个月）：三因子∪赔率组合年化 +12.0% vs 买入持有 +6.8%，最大回撤 -11.1% vs -14.6%；供需比(S6/S11)与叙事(S9/S10)因数据缺口未参与验证，用前须知。

## 红线与注意事项

- 本技能输出为分析参考，非投资建议；宏观择时回测历史绩效不代表未来。
- 观点与规则分离：`references/views.md` 是时效快照，`references/` 是方法论，勿混用。
- 时间窗口 2023.8-2026.8 内的方法论与观点为本技能知识边界；窗口外内容需另行检索核验。
- A 股惯例：涨红跌绿，货币符号用 ¥。
