# 刘胜利 · 长江证券金融工程分析框架

本技能将长江证券金融工程首席分析师刘胜利的量化研究框架蒸馏为可执行的风格/因子/资产配置决策体系。
定位：**先定风格周期（三维框架 + 图谱）→ 再定风险层级与因子暴露（绝对收益三层）→ 后落到行业/选股与跨资产**。

## 使用流程（按顺序执行）

1. **读取最新观点**：先打开 `references/views.md` 顶部，确认刘胜利/长江金工当前最新观点（截至日期）与机构归属。观点是时效的，勿直接使用历史快照。
2. **风格方向（第一层）**：运行 `scripts/screen.py`，计算风格周期三维判断（S1：周期时间+宏观基本面+资金面）与风格轮动图谱方向打分（S2）。计算规则与阈值详见 `references/decision-rules.md`。
3. **风险层级（第二层·上）**：看因子风险分层（S3：低风险/非周期/高风险）与日历效应（S4），决定绝对收益策略的防御/进攻档位。
4. **行业与选股（第二层·下）**：看行业轮动分析师因子（S5）与神经网络因子（S6）、多因子组合（S7）。
5. **跨资产（第三层）**：看大类资产配置（S8：黄金/普林格周期），决定权益外配置。
6. **输出规范**：所有观点引用必须注明日期（如"刘胜利（长江证券金融工程）2026 观点"）；信号与观点冲突时优先遵循信号并说明分歧；参数来源标注（✅原文/⚠️外推/❌推断）必须保留。

## 数据获取

- 风格类（大小盘/成长价值指数、宏观因子库：利率/社融/CPI/PPI/出口等）：westock-data 查询，计算三维得分与图谱方向打分。
- 因子类（风险分层因子、日历效应、分析师超预期/预期增长/驱动）：westock-data + westock-tool 查询；分析师预期用一致预期数据。
- 神经网络因子（筹码分布 75 特征 + TCN）：需 Level1 行情数据，无公开直连 → 工程代理（❌），仅作方向参考。
- 跨资产（黄金、实际利率、地缘指数、央行购金、ETF 购金、普林格六阶段）：westock-data / neodata-financial-search 查询。
- 个股/行业筛选：用 `westock-tool` 按 screen.py 输出的风格/行业方向做筛选。
- 指标口径、频率、所属框架详见 `references/indicators.md`。

## 脚本使用

```bash
python scripts/screen.py                  # 演示模式（内置合成数据，验证流程）
python scripts/screen.py --schema         # 查看输入数据契约（先跑这个）
python scripts/screen.py --data macro.json   # 用真实数据计算信号
python scripts/screen.py --data macro.json --json-out  # 输出机器可读 JSON
```

- **输入契约**：运行 `python scripts/screen.py --schema` 获取字段清单，按 required 字段准备数据（字段→月份数组，最新在末尾）。除调试外不要读取脚本源码。
- 信号 S1-S8 编号为**工程化设计**（刘胜利没有此编号体系），底层阈值来源见 `references/decision-rules.md` 各规则标注。

## 红线与注意事项

- 本技能输出为分析参考，非投资建议；量化框架历史表现不代表未来。
- 观点与规则分离：`references/views.md` 是时效快照（**观点时间线/口径校准层，不参与信号计算**），`references/` 是方法论，勿混用；信号基于 ✅ 原文规则 + 最新数据优先，观点冲突时输出分歧说明。
- **机构归属红线**：刘胜利任职长江证券（金融工程首席分析师）；引用观点须标注任职期归属，如发生离职/跳槽，其观点归属以任职期为准，禁止混用。
- **推断参数**：风格得分阈值 0、分析师因子权重 0.5/0.3/0.2、RankIC 参考阈值 5%、普林格阶段映射等均为 ❌ 推断最小假设，非分析师公布值，拿到真实参数应替换。
- **数据口径**：不同数据源绝对水平可能背离，仅分位/方向可用时不得跨口径比较绝对阈值；见 `_meta` 与 validation.md 标注。
- 时间窗口 2023.9-2026.8 内的方法论与观点为本技能知识边界；窗口外内容需另行检索核验。
- A 股惯例：涨红跌绿，货币符号用 ¥。
