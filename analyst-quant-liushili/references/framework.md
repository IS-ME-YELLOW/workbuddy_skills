## 〇、框架总览（按方法论主体分层）

刘胜利（长江证券金融工程首席，SAC S0490517070006）的核心主张：**2025 年后传统因子规律阶段性失效**（行业轮动周期性减弱、量价/基本面因子 Alpha 下滑、多因子跟踪误差增大、指增超额回撤），因此**跳出单一因子视角，转向风格周期维度**。体系以"**风格周期三维判断**"为枢纽：周期时间 × 宏观基本面 × 资金面 → 风格方向（大小盘/价值成长），向下落为因子风险分层配置、行业轮动、AI 因子与多因子组合，向上升为大类资产配置：

| 层 | 框架 | 一句话定位 |
|---|---|---|
| 第一层 风格周期 | F1 风格周期三维框架 | 周期时间+宏观基本面+资金面 → 判断大盘/小盘、成长/价值（核心） |
| 第一层 风格周期 | F2 风格轮动图谱 | 五对风格 × 宏观因子库 → 环境归纳与风格择时 |
| 第二层 配置 | F3 因子风险分层与绝对收益策略 | 因子分低风险/非周期/高风险三类，底仓+增强+风险约束 |
| 第二层 配置 | F4 日历效应下的因子投资 | 年内风险偏好节奏（春季躁动/二季度放开/三四季度回落） |
| 第二层 配置 | F5 行业轮动：分析师因子 | 分析师预期变化/超预期/驱动三维度因子，行业与 ETF 轮动 |
| 第三层 选股 | F6 神经网络因子挖掘 | Level1 筹码分布+资金流模型，指数增强 |

## F1 风格周期三维框架（核心辨识度）

- **定义**：以"**周期时间 + 宏观基本面 + 资金面**"三维框架判断风格周期（✅ 原文，2026-01-28 复旦 FICC 论坛："跳出单一因子视角，转向风格周期维度去思考。通过周期时间+宏观基本面+资金面三维框架，判断 2026 年大概率偏向大盘成长风格"；2025 年度策略《风格切换下的因子投资》同源）。
- **逻辑**：
  - **周期时间**：价值成长轮动周期约三年（✅ 原文，2025 年度策略：通过重构价值成长指数发现"价值成长轮动周期约三年，2026 年偏向成长可能性较高"）；大小盘轮动周期不显著（周期钝化，✅ 原文）。
  - **宏观基本面**：高流动性+高景气度 → 成长收益较高；反之 → 价值收益较高（✅ 原文）；2026 年宏观预测高流动性、高景气 → 偏向成长（✅ 原文）。
  - **资金面**：机构化持续推进 → 大盘股占优；价值型机构（保险、社保）风险偏好提升 → 部分资金转向成长；成长型机构（公募、私募、外资）可能持续入市 → 推动成长股；融资余额占比较低 → 未来杠杆比可能提升（✅ 原文）。
- **应用**：每年年度策略输出下一年风格判断；2025 年度策略结论 = 2026 年大概率**大盘成长**（✅ 原文）。2026-05 圆桌观点："当前市场环境下成长股更具优势，稳健型投资者坚持分散投资"（✅ 原文）。
- **窗口内实例**：2025 年初判断 2026 偏成长（前瞻验证点）；2026 年实际市场风格验证见 Phase 4。
- **工程化要点**：三维各自需代理（周期位置=相对净值长窗口动量；流动性=利率/货币；资金面=机构资金代理），数值口径 ❌ 推断。

## F2 风格轮动图谱（宏观环境判别）

- **定义**：构建 A 股风格图谱，用**宏观因子库 → 环境归纳 → 择时测算**三步判断风格（✅ 原文，2020-05-18《风格轮动：A股风格图谱及宏观环境判别》，覃川桃/刘胜利）。
- **逻辑**：风格相对收益由宏观环境驱动（✅ 原文规则）：
  - 消费 vs 周期：消费价格越低、零售越好 → 越利于后期周期股；
  - 金融 vs 非金融：利率越高、投资越多 → 越利于后期金融股；
  - 科技 vs 传统：流动性越高、外贸越好 → 越利于后期科技股。
- **应用**：五对风格（大盘/小盘、价值/成长、消费/周期、金融/非金融、科技/传统）指数化跟踪 + 宏观环境打分切换。
- **工程化要点**：宏观因子库数值口径未逐字公开，screen.py 用利率/流动性/景气代理（❌ 推断）。

## F3 因子风险分层与绝对收益策略

- **定义**：将因子按**绝对收益层面的风险特征**划分为低风险/非周期/高风险三类（✅ 原文，2026-08-18《资产配置(四)：权益绝对收益策略》）：低风险因子构建基础选股池、非周期因子做股票池内增强、Beta 约束组合优化控制风险。
- **逻辑**：低风险因子（价格稳定、成交稳定、价值类）在市场下行时稳健、承担绝对收益底仓职能；高风险因子（成长、动量类）在风险偏好高时占优、承担弹性职能（✅ 原文，《多因子选股二十一：日历效应下的因子投资》）。
- **应用**：权益绝对收益策略三层结构（✅ 原文）：① 低风险因子基础选股池；② 非周期因子池内增强；③ Beta 约束组合优化。
- **窗口内实例**：2026-08-18 报告发布即应用（最新配置方法）。
- **工程化要点**：因子清单与 Beta 约束参数未公开，screen.py 用波动率/动量/估值代理分类（❌ 推断）。

## F4 日历效应下的因子投资

- **定义**：年内交易符合**风险偏好先高后低**规律：春季躁动后逐步上升、二季度全面放开、三四季度缓慢下降（✅ 原文，《多因子选股二十一：日历效应下的因子投资》）。
- **逻辑**：高风险因子（成长/动量）在二季度表现最佳，一三四季度相对较弱；春节前后"冰火两重天"（春节前风险偏好高、节后回落）；国庆前后跨节效应使所有因子策略减弱（✅ 原文）。
- **应用**：按月份调因子暴露：二季度加高风险因子、三四季度降风险；2025 年日历效应受成长风格强势影响被削弱（✅ 原文）。
- **工程化要点**：月份-因子暴露映射表未公开，screen.py 按月调仓方向代理（❌ 推断）。

## F5 行业轮动：分析师因子

- **定义**：从**分析师预期变化、分析师超预期、分析师驱动**三个维度构建分析师因子（✅ 原文，2026-05-07《行业轮动(十二)：分析师篇》）：分析师超预期 = 一致预期数据相对年报的同比；分析师预期增长 = 一致预期数据自身环比变化；分析师驱动 = 分析师首次覆盖后行情在量价上的表现。
- **逻辑**：分析师预期修正与股价未来收益分布相关；三类因子在行业轮动与 ETF 轮动上表现基本一致（✅ 原文）。
- **应用**：分析师超预期因子以"预期年报的增速"表现较好；预期增长因子以 FY1/FY2 预测年报期更有效但时序稳定性较弱；驱动因子以换手维度为主（✅ 原文）。
- **工程化要点**：一致预期数据无 westock 直连接口 → 用盈利预测代理（❌ 推断）或标注数据缺口。

## F6 神经网络因子挖掘与指数增强

- **定义**：基于 Level1 高频数据 + 深度学习的因子挖掘系列（✅ 原文，2025-11-30《神经网络因子挖掘(六)——筹码分布因子》）：构造 75 个逻辑化筹码衍生特征 + TCN 模型；升级 GRU-Transformer 资金流模型。
- **应用与回测**（✅ 原文，加 ~）：2019 至 2025-11 筹码因子 RankIC ~9.05%、多头超额 ~21.76%；合成因子在中证全指内平均超额 ~32.13%；指数增强组合国证2000 增强年化超额 ~28.42%。
- **工程化要点**：需 Level1 高频逐笔数据（westock 不可得）→ 本技能不落地真实筹码因子，用低频量价代理（❌ 推断），仅作方向参考。

## F7 多因子组合构建

- **定义**：在风格判断之上构建多因子组合（✅ 原文，2025 年度策略）：**大盘因子 + 成长因子 + 非周期因子（拥挤度、反转等）**。
- **逻辑**：不同风格环境下有效因子不同（✅ 原文）：成长风格下分析师预期/成长动量/质量因子有效；大盘风格下分析师质量/动量因子有效；价值风格下高频指标/价值因子有效。非周期因子（拥挤度/反转）降低组合尾部风险。
- **应用**：组合历史回测胜率更高、风险水平更低（✅ 原文）；与 2026 大盘成长判断配合。
- **工程化要点**：因子权重与回测细节未公开（❌ 推断）。

## F8 大类资产配置（黄金与跨资产）

- **定义**：黄金在大类资产配置中承担"**风险对冲**"与"**分散波动**"功能（✅ 原文，2025-12-22 长江观澜）：作为无息资产与生息资产相关性低，实际利率下行、地缘风险升温时对冲组合下行风险。
- **逻辑**：普林格周期视角——美国经济若进入复苏/繁荣周期，"经济扩张+通胀预期抬升+货币宽松"组合强化黄金战略地位（✅ 原文）；本轮（2022 以来）需求端以央行购金+ETF 购金为主力，实际利率与金价非对称关系显著。
- **应用**：跨资产配置参考（股票/债券/商品/黄金在各经济周期的历史平均收益比较，✅ 原文方法）。
- **工程化要点**：普林格周期判定与资产收益表未公开（❌ 推断）。
