# 刘胜利决策规则（decision-rules.md）

> 来源标注：✅ 原文 / ⚠️ 外推 / ❌ 推断（最小假设，可替换）。回测数字加 ~ 并注明"取自公开报告，以原文为准"。
> 本文件为可执行推理程序；时点观点一律见 views.md，不进规则区。
> 信号工程化编号（S1-S8）系本技能设计，对应 framework.md F1-F8。

## 规则 0：信号分级与总原则

- **信号强度**：`strong` = 规则基于 ✅ 原文阈值/框架且数据 ✅ 直连；`mid` = 规则框架 ✅ 但关键参数 ❌ 推断；`direction` = 仅方向性参考。
- **操作映射**（❌ 仓位比例为最小假设，可替换）：
  - 风格三维一致看多（如 S1 周期偏成长 + 高流动性 + 高景气）：权益超配档；
  - 风格分歧/日历效应走弱（S4 三四季度）：标配档降高风险暴露；
  - 风格三维转空（S1 周期偏价值 + 流动性收紧）：减配档/防御。
- **输出顺序**：先读 views.md 最新观点校准，再运行 S1→S8，最后输出"信号+观点对照+分歧说明"。
- **观点冲突处理**：基于 ✅ 原文规则+最新真实数据的高置信信号优先并说明；依赖 ❌ 推断参数的信号不得机械压过 views.md，标"低置信分歧"。
- **风格维度优先**：刘胜利体系以风格判断为枢纽（✅ 原文），S1 风格方向决定 S3/S7 的因子暴露取舍；两者冲突时以 S1 为准并说明。

## S1 风格周期三维判断（对应 F1，核心）

- **触发条件**：周期时间/宏观基本面/资金面三维代理数据可用。
- **计算步骤**：① 周期时间：价值成长相对净值长窗口动量（❌ 代理，代理"三年周期位置"✅）；② 宏观基本面：流动性（I-03）+ 景气度（I-04）合成；③ 资金面：机构资金结构（I-05）+ 融资占比（I-06）合成；④ 三维等权合成风格方向得分（❌ 等权最小假设）。
- **量化阈值**：成长得分 >0 = 偏成长、<0 = 偏价值；大盘得分（机构化代理）>0 = 偏大盘（✅ 原文"机构化推进→大盘占优"）；综合输出"大盘成长/大盘价值/小盘成长/小盘价值"四象限（✅ 2026 判断：大概率大盘成长）。
- **信号输出**：`偏大盘成长 / 偏大盘价值 / 偏小盘成长 / 偏小盘价值 / 中性`。

## S2 风格轮动图谱宏观环境（对应 F2）

- **触发条件**：宏观因子库字段齐全（I-07~I-12）。
- **计算步骤**：① 每对风格取对应宏观因子（✅ 原文规则）：消费价格/零售 → 消费 vs 周期；利率/投资 → 金融 vs 非金融；流动性/外贸 → 科技 vs 传统；② 因子方向打分合成（❌ 赋分推断）；③ 与 S1 输出交叉验证。
- **量化阈值**：消费价格低+零售好 = 周期加分（✅ 原文）；利率高+投资多 = 金融加分（✅ 原文）；流动性高+外贸好 = 科技加分（✅ 原文）；无绝对阈值，方向打分（❌）。
- **信号输出**：`消费/周期倾向、金融/非金融倾向、科技/传统倾向`（三对风格方向）。

## S3 因子风险分层配置（对应 F3）

- **触发条件**：因子分类（低风险/非周期/高风险）可计算。
- **计算步骤**：① 低风险因子（价格稳定/成交稳定/价值，I-13~I-15）构建基础选股池（✅ 原文）；② 非周期因子（拥挤度/反转，I-18/I-19）池内增强（✅ 原文）；③ Beta 约束组合优化控制风险（✅ 原文）；④ 高风险因子（成长/动量，I-16/I-17）仅在风险偏好高时提升暴露（✅ 原文）。
- **量化阈值**：绝对收益策略三层结构固定（✅ 原文）；Beta 约束参数未公开（❌ 推断：目标波动率档位映射）。
- **信号输出**：`底仓（低风险因子池）/ 增强（非周期因子）/ 弹性（高风险因子暴露档 0-3）`。

## S4 日历效应因子暴露（对应 F4）

- **触发条件**：日历月份/事件窗口可判定。
- **计算步骤**：① 月份节奏映射：一季度春季躁动→逐步上升、二季度全面放开、三四季度缓慢下降（✅ 原文）；② 事件窗口：春节前后"冰火两重天"、国庆跨节效应（✅ 原文）。
- **量化阈值**：二季度 = 高风险因子（成长/动量）加仓窗口（✅ 原文"表现最佳"）；三四季度 = 降风险暴露；春节后回落、国庆前后所有因子策略减弱 → 降档（✅ 原文）。
- **信号输出**：`高风险暴露建议（Q1 中 / Q2 高 / Q3-Q4 低 / 事件窗口特殊处理）`。

## S5 行业轮动：分析师因子（对应 F5）

- **触发条件**：分析师一致预期/覆盖数据可用（westock 无直连接口 → 用盈利预测代理 ❌ 或标注数据缺口）。
- **计算步骤**：① 分析师超预期 = 一致预期相对年报的同比（✅ 原文定义）；② 分析师预期增长 = 一致预期自身环比（✅ 原文定义）；③ 分析师驱动 = 首次覆盖后量价表现、以换手维度为主（✅ 原文定义）；④ 三类因子合成行业/ETF 轮动排序（✅ 原文：三类在行业轮动与 ETF 轮动上表现基本一致）。
- **量化阈值**：超预期因子以"预期年报的增速"口径较好、预期增长因子 FY1/FY2 期更有效但时序稳定性弱（✅ 原文）→ 用超预期为主、预期增长为辅交叉验证（❌ 权重推断）。
- **信号输出**：`行业轮动推荐清单 / ETF 轮动推荐清单`。

## S6 神经网络因子指增（对应 F6）

- **触发条件**：Level1 高频数据可用（westock 不可得 → 本技能以低频量价代理 ❌，仅方向参考）。
- **计算步骤**：① 筹码分布 75 个逻辑化特征（✅ 原文）；② TCN 模型训练输出因子（✅ 原文模型名）；③ 合成因子做指数增强（✅ 原文：国证2000 增强年化超额 ~28.42%，2019-2025-11，加 ~ 以原文为准）。
- **量化阈值**：筹码因子 RankIC ~9.05%（✅ 原文研究口径）；本技能不做真实落地，仅作"深度学习因子有效性"的方向参照（❌ 代理信号）。
- **信号输出**：`因子有效性方向参考（研究口径）`。

## S7 多因子组合构建（对应 F7）

- **触发条件**：风格方向（S1 输出）+ 因子库可用。
- **计算步骤**：① 按风格环境选有效因子子集（✅ 原文：成长风格→分析师预期/成长动量/质量；大盘风格→分析师质量/动量；价值风格→高频指标/价值）；② 组合 = 大盘因子 + 成长因子 + 非周期因子（拥挤度/反转）（✅ 原文 2025 年度策略）；③ 非周期因子降低尾部风险（✅ 原文）。
- **量化阈值**：因子权重未公开（❌ 推断：按 S1 风格方向加权）；组合目标：胜率更高、风险更低（✅ 原文）。
- **信号输出**：`组合因子构成与权重建议`。

## S8 大类资产与黄金配置（对应 F8）

- **触发条件**：实际利率/地缘/购金/普林格周期代理可用。
- **计算步骤**：① 实际利率下行 → 黄金加配（✅ 原文规则）；② 地缘风险升温 → 黄金对冲加配（✅ 原文规则）；③ 央行/ETF 购金持续 → 黄金战略地位强化（✅ 原文：2022 以来需求端主力）；④ 普林格周期阶段判定（复苏/繁荣 → "经济扩张+通胀预期+货币宽松" → 黄金战略配置，✅ 原文）；⑤ 黄金与生息资产低相关 → 分散波动功能（✅ 原文）。
- **量化阈值**：无公开数值阈值（❌ 推断：实际利率下行 + 购金持续 = 黄金超配）；跨资产比较用各经济周期历史平均收益表（✅ 原文方法）。
- **信号输出**：`黄金配置建议（超配/标配/低配）` + `跨资产周期参考`。
