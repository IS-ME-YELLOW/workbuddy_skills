# 张瑜 · 华创宏观分析框架

本技能将华创证券首席宏观分析师张瑜的宏观研究框架蒸馏为可执行的选股/配置决策体系。
定位：**先识别宏观核心矛盾（矛盾→资金→价格→配置），再落地选股**。

## 使用流程（按顺序执行）

1. **读取最新观点**：先打开 `assets/views.md` 顶部，确认张瑜当前最新观点（截至日期）。观点是时效的，勿直接使用历史快照。
2. **总量矛盾诊断（第一层）**：调用 `references/framework.md` 第一层，判断当下宏观核心矛盾——三螺旋解到什么程度？双周期困境挣脱到哪条路径？政策剧本走到第几步？用 `references/indicators.md` 中的一线房价/PPI/M1/产能利用率等指标，计算三螺旋五信号兑现数。
3. **资金流判断（第二层·张瑜核心辨识度）**：运行 `scripts/screen.py`，计算企业居民存款剪刀差（领先利润 12 个月）、居民存款/M2 三支箭阶段、非银存款/欠配资金、流动性三层分层状态。计算规则与阈值详见 `references/decision-rules.md`。
4. **价格与结构判断（第三层）**：检查五价格锚（煤价=吹哨人→钢价=识别器→光伏=测压仪→化工=排头兵→房价=开关器）；中游供需状态（需求同比−投资同比）；新旧经济黄金交叉位置。
5. **大类配置落地（第四层）**：结合 `assets/views.md` 最新观点与信号汇总，输出：股/债/金天平、仓位档位、行业方向（中游>消费>上游）、风格偏好（创业板>宽基）、个股筛选条件。
6. **输出规范**：所有观点引用必须注明日期（如"张瑜 2026-06 中期观点"）；信号与观点冲突时优先遵循信号并说明分歧；参数来源标注（✅原文/⚠️外推/❌推断）必须保留。

## 数据获取

- 存款类指标（企业/居民/非银存款同比、M1旧口径）：用 `westock-data` 或 `neodata-financial-search` 查询金融机构信贷收支表；**M1 必须用旧口径**（含居民活期会失真，张瑜 2025.9 原文）。
- 价格类（PPI/CPI/煤价/钢价/光伏/化工/房价）：westock-data 查询月度数据；煤价可用秦皇岛动力煤市场价。
- 市场类（夏普比率、股息率、国债收益率、成交额）：westock-data 查询万得全A/中债总财富指数。
- 杠杆率（政府/居民）：社科院/BIS 季度口径。
- GIORI：需自算 OLS 回归残差（1974-2025 五变量），或引用张瑜报告数据。
- 指标口径、频率、所属框架详见 `references/indicators.md`。
- 个股/行业筛选：用 `westock-tool` 按 screen.py 输出的条件做筛选。

## 脚本使用

```bash
python scripts/screen.py                  # 演示模式（内置示例数据，验证流程）
python scripts/screen.py --data macro.json  # 用真实宏观数据文件计算信号
python scripts/screen.py --json-out        # 输出机器可读 JSON
```

- screen.py 输入：宏观数据 JSON（字段见脚本内 DATA_SCHEMA 说明）；输出：S1-S12 信号表 + 仓位/风格/行业建议。
- 信号 S1-S12 编号为**工程化设计**（张瑜没有此编号体系），底层阈值来源见各规则标注。
- 数据来源：优先 westock-data / neodata 查询结果，由调用方填入 JSON。


## 红线与注意事项

- 本技能输出为分析参考，非投资建议；宏观框架历史表现不代表未来。
- 观点与规则分离：`assets/views.md` 是时效快照，`references/` 是方法论，勿混用。
- **M1 口径**：必须用旧口径（企业活期，不含居民活期与非银活期），新口径会失真。
- **参数来源标注**：所有阈值带 ✅/⚠️/❌ 标注——推断值（❌）不冒充原文，拿到真实值应替换。
- 时间窗口 2023.8-2026.8 内的方法论与观点为本技能知识边界；窗口外内容需另行检索核验。
- A 股惯例：涨红跌绿，货币符号用 ¥。
