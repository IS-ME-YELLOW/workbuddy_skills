## 三、数据口径与 22 字段回填清单

数据源：westock-data（`macro fundquantity` / `cpi_ppi` / `profit` / `capacity_utilization` / `investment` / `valueadded` / `kline` / `yield_curve` / `premium_curve`）+ 央行/PBOC 公开数据 + 统计局公开值。

| screen.py 字段 | 数据来源 | 口径标注 |
|---|---|---|
| `m1_yoy_old` | westock-data `fundquantity`（旧口径 M1 同比） | ✅原文 |
| `ppi_yoy` | westock-data `cpi_ppi` + 统计局公开值补齐 | ✅原文 |
| `ind_profit_yoy` | westock-data `profit`（工业企业利润累计同比→当月） | ✅原文 |
| `capacity_util` | westock-data `capacity_utilization`（季度→月度 ffill，缺失季度回退最新） | ✅原文 |
| `midstream_invest_yoy` | westock-data `investment`（制造业投资累计同比，中游投资代理） | ⚠️外推 |
| `midstream_demand_yoy` | westock-data `valueadded`（高技术产业增加值累计同比，中游需求代理） | ⚠️外推 |
| `ten_y_yield` | westock-data `yield_curve`（中债10Y 日频→月均） | ✅原文 |
| `div_yield` | westock-data `premium_curve`（股息率日频→月均） | ✅原文 |
| `stock_sharpe` | 中证全指 sh000985 月收盘（westock-data `kline`）→ 36 月滚动夏普（万得全A 代理） | ⚠️外推 |
| `bond_sharpe` | 10Y 收益率变动估算债券回报（久期 6.5）→ 36 月滚动夏普（中债总财富代理） | ⚠️外推 |
| `enterprise_dep_yoy` | 央行年度余额锚（2023-26H1）+ M1 月度模式：`年度均值 + 0.3×(M1−年度M1均值)` | ⚠️外推 |
| `resident_dep_yoy` | 央行年度余额锚 + M2 月度模式：`年度均值 + 0.15×(M2−年度M2均值)` | ⚠️外推 |

| `resident_dep_new_m2` | 居民新增存款/新增 M2，由年度增量+月度 M2 反推 | ⚠️外推 |
| `first_tier_house_yoy` | 公开一线城市房价指数（月度化） | ⚠️外推 |
| `coal_price` / `land_premium` / `house_excess_return` / `gov_lev_growth` / `res_lev_growth` / `policy_bank_gdp_pct` | 公开价格/估值的趋势代理 | ⚠️外推 |
| `giori` + `extras.gold_rate_real_rate_decoupled` | 金价-实际利率关系趋势代理（未做 OLS 回归） | ❌推断 |

**数据缺口**：企业/居民/非银存款分项、GIORI 指数、政策行投放/GDP 在 westock-data 无直接接口，为年度锚+月度外推或趋势代理——**绝对水平解释力弱于原文口径，但对剪刀差方向、分位与斜率的影响经 z-score/分位标准化后有限**。若后续接口补充存款分项与 GIORI，可直接在 `macro_real_zhangyu.json` 中替换对应字段重新回填。

## 五、验证结论

1. **剪刀差方向有效性成立**：下行段看空（2023-08、2024-04 后 3 月 -3.2%/-7.7%）、极值底反转（2024-08 → 924 行情 +22%/+26%），"领先 ~6 个月 + 极值反转"被真实行情印证。
2. **S7 降息条件精确命中政策拐点**：2024-08 触发后 2024-09-24 央行降准降息，为全部信号中与真实政策事件对应最准的一条。
3. **确认型信号（S1/S3）节奏正确**：底部左侧不触发、修复段触发（2025-08 S1✅、2026-05 S3✅ 4/5），避免左侧抄底；2026-07 M1 斜率转负后 S3 回落至 3/5，与 7 月回调同步降温。
4. **主要局限**：存款分项为年度锚+月度外推代理，月度绝对水平解释力弱；GIORI/杠杆率/政策行投放为趋势代理（❌推断）；样本仅 43 个月、覆盖一轮半周期（2023 下行→2024 政策底→2025-26 修复），未含完整长熊验证。
